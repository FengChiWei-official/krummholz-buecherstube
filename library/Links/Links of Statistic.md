### 一、 概率基础与随机事件模块

#### 1. 贝叶斯公式与全概率（离散事件版）
* **长什么样**：抓阄、工厂 A/B/C 次品率、体检假阳性，“已知结果反推原因”。
* **核心武器**：画**树状图**（先验概率 → 条件概率），分母用全概率公式展开，分子是其中一条对应路径。

#### 2. 独立性与相关性的判别（高频概念陷阱题）
* **长什么样**：给一个二维联合密度 `f(x, y)`，问 `X` 和 `Y` 是否独立？是否不相关？
* **核心武器**：
  * **判独立 1 秒杀招**：先看支撑集区域 `D` 是不是**横平竖直的矩形**（或无界全平面）！只要区域是三角形、圆（如 `x² + y² ≤ 1`）等边界相互纠缠的图形，**不用积分，直接判“不独立”**！若区域是矩形，再看 `f(x, y)` 能否因式分解成 `g(x)·h(y)`。
  * **判不相关**：算 `Cov(X, Y) = 0`（利用对称性常能直接看出 `E(XY) = E(X)E(Y) = 0`）。
  * **经典结论**：独立必不相关；不相关**未必**独立（除非是二维正态分布！）。

#### 3. 指数/几何分布的“无记忆性” & 次序统计量 `max / min`
* **无记忆性**：遇到“已经等了 `s` 小时没坏，再多等 `t` 小时的概率”，直接丢掉历史：`P(X > s + t | X > s) = P(X > t)`。
* **次序统计量**：多个独立变量求 `M = max(X₁, ..., Xₙ)` 或 `N = min(X₁, ..., Xₙ)` 的分布或期望。
  * **核心武器**：`F_max(z) = P(全部 ≤ z) = ∏ F_i(z)`；`F_min(z) = 1 - P(全部 > z) = 1 - ∏ [1 - F_i(z)]`。（特别地，独立指数分布的最小值还是指数分布，速率直接相加！）。

---

### 二、 极限定理模块（大数 & 中心极限）

#### 4. 切比雪夫不等式（估计概率界限）
* **长什么样**：**完全不告诉你是什么分布**，只给了均值 `μ` 和方差 `σ²`，让你估计 `P(|X - μ| ≥ ε)` 的上界，或 `P(|X - μ| < ε)` 的下界。
* **核心武器**：直接套 `P(|X - μ| ≥ ε) ≤ σ² / ε²`。

#### 5. 中心极限定理（CLT 近似算概率）
* **长什么样**：`n` 个（比如 100 个、400 个）独立同分布变量相加 `S_n = X₁ + ... + Xₙ`（或二项分布 `n` 很大、泊松分布 `λ` 很大），求 `P(a ≤ S_n ≤ b)`，或者反求最少需要多少样本 `n`。
* **核心武器**：
  1. 算出总和的均值 `E(S_n) = nμ` 和总标准差 `√Var(S_n) = √n · σ`；
  2. 强行标准化：`(S_n - nμ) / (√n · σ)` 近似服从 **`N(0, 1)`**；
  3. 转成你最熟悉的 **`Φ(...)`** 查表计算！

### 三、 数理统计后续模块（点估计之后）

#### 6. 三大抽样分布（`χ²`, `t`, `F` 分布）的构造与判别
这是数理统计考试里**分值最高、最爱出选择填空**的题型。
* **长什么样**：从正态总体 `N(μ, σ²)` 抽样 `X₁, ..., Xₙ`，给你一个由 `X̄` 和 `S²` 凑出来的怪异分式，问它服从什么分布，或者让你配一个常数 `c` 让它服从 `t` 分布 / `F` 分布。
* **核心武器**（死磕 4 条基石）：
  1. `Z ~ N(0, 1)`，独立的 `Y ~ χ²(n)`；
  2. `Z₁² + ... + Z_n² ~ χ²(n)`（注意必须是**标准正态**的平方和！）；
  3. `Z / √(Y / n) ~ t(n)`（分子标准正态，分母根号下卡方除以自由度，且分子分母独立）；
  4. `(Y₁ / n₁) / (Y₂ / n₂) ~ F(n₁, n₂)`（两个独立卡方各自除以自由度再相除）；
  5. **正态样本铁律**：`X̄ ~ N(μ, σ²/n)`，`(n-1)S² / σ² ~ χ²(n-1)`，且 **`X̄` 与 `S²` 相互独立**！

#### 7. 估计量评选标准、置信区间与假设检验
* **估计量评选（衔接你的点估计）**：
  * **无偏性**：验证 `E(θ̂) = θ`（极常配合 `E(X²) = Var(X) + [E(X)]²` 来算！）。
  * **有效性**：谁的方差 `Var(θ̂)` 小谁有效。
  * **一致性（相合性）**：常用“若 `E(θ̂_n) → θ` 且 `Var(θ̂_n) → 0`，则依概率收敛于 `θ`”。
* **置信区间**：核心就是找一个含 `θ` 的**枢轴量**（就是第 6 点的 `Z`、`t`、`χ²` 统计量），套进双侧分位数不等式里反解出 `θ` 的上下限。
* **假设检验 & 两类错误**：
  * 找检验统计量 + 拒绝域（本质就是置信区间的逆操作）；
  * 算两类错误概率：`α = P(落入拒绝域 | H₀ 为真)`，`β = P(未落入拒绝域 | H₁ 为真)`（算 `β` 时切记把均值换回 `H₁` 给的新 `μ₁` 重新标准化成 `Φ(...)`！）。
