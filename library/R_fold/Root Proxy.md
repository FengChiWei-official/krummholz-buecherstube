## Definition

递归函数**不返回**子树的摘要，而把状态放在两个地方之一：往下的**参数**、或函数外的**全局量**。根结点收口时，它代表的不是自己，而是整棵树。

## 两种写法

- **参数往下发**：`dfs(u, depth)`——层数、已累计的和、路径上的栈，都随参数走。前驱决定后继看到什么（2014·41 WPL 的深度就是这么下来的）。
- **全局量累积**：`ans/cnt/prev` 声明在函数外，递归只改不读参数；中序判 BST 的 `prev`、统计结点数都是这种（2022·41）。

## 与「自底向上聚合」的分界

| | 根节点代理 | 自底向上聚合 |
|---|---|---|
| 状态放哪 | 参数 / 全局量 | 返回值 |
| 什么时候收口 | 根节点访问时 | 每个父节点合并时 |
| 适合 | 只需累计、不需要兄弟之间比较 | 需要子树摘要（高、和、是否存在） |

## 判据

题面要求「所有满足条件的 X 的个数 / 最大值 / 是否存在」，且判定只沿一条根到叶的路径就能做 → 代理；要求「每个子树自己的结果」→ 聚合。

## 复杂度

$O(n)$ 时间 / $O(h)$ 递归栈；全局量是 $O(1)$ 的额外空间。

## 真题

2014·41（WPL 的层数走参数）、2022·41（prev 走全局）、2026·41（BST 剪枝同时用区间参数与全局答案）。
