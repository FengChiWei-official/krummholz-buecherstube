## Definition

两个指针同向走、角色不同：`read` 每步都前进，`write` 只在「这个元素要保留」时前进并写入。用于原地删除、去重、压缩。

## 骨架

```c
int w = 0;
for (int r = 0; r < n; r++)
    if (keep(a[r]))       // 保留条件
        a[w++] = a[r];    // 写指针只在保留时前进
return w;                 // 新长度
```

## 与相向双指针的区别

| | 相向 | 同向读写 |
|---|---|---|
| 谁动 | 两端各向内 | 读一直动，写按条件动 |
| 前提 | 有序或对称 | 无序也可，只要「保留条件」可逐个判 |
| 保序 | 不一定 | **一定保序**（按原顺序写回） |

## 判据

题面出现「原地、$O(1)$ 空间、保持相对顺序」三者同时成立时，就是它；不要求保序时可以直接用末尾元素覆盖（$O(1)$ 删除）。

## 复杂度

$O(n)$ 时间 / $O(1)$ 空间。
