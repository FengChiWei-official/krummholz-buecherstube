## Definition

不比较关键字大小，按位分配-收集：从最低位到最高位，每一位做一次**稳定**的桶排序（LSD）。

## 骨架

```
for (d = 最低位; d <= 最高位; d++)
    countingSortByDigit(a, n, d);   // 每一位的计数排序，必须稳定
```

## 为什么必须「低位优先 + 稳定」

低位先排，高位后排在上一轮结果上重排；若某一位的排序不稳定，前一轮排好的低位次序被打乱，最终结果就错。所以基数排序的稳定性**不是可选性质，是正确性前提**。

## 判据

关键字能拆成有限位（整数、定长字符串）、位宽 $d$ 已知、值域 $k$ 不爆炸。$d$ 大而 $n$ 小时不如比较排序。

## 复杂度

时间 $O(d(n+k))$，$k$ 为每位值域；空间 $O(n+k)$。链表实现可以免掉搬运，$d$ 轮各 $O(n)$。

## 真题

考纲第八章拓展题（$O(n)$ 时间排 $n$ 个整数）。
