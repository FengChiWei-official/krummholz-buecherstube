## Definition

An [[Executable and Linkable Format|ELF]] can be a [[Executable File]], [[Relocatable File]] or a [[Shared Object File]].

- [[Executable File]] main
- [[Relocatable File]] main.o
- [[Shared Object File]] lib.so

### How to lookup

``` bash

❯ file /home/mia/.local/bin/omp

/home/mia/.local/bin/omp: ELF 64-bit LSB executable, x86-64, version 1 (SYSV), dynamically linked, interpreter /lib64/ld-linux-x86-64.so.2, for GNU/Linux 3.2.0, BuildID[sha1]=588d7307f333293c728b74df19b7323c20736899, not stripped
```
