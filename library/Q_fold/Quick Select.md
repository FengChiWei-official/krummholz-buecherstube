## Definition

求第 $k$ 小（或第 $k$ 大）而不排序：每次 [[Partition]] 后只往答案所在的那一侧收缩。

## 骨架

```
while (l < r) {
    p = partition(a, l, r);
    if (p == k) return a[k];
    if (p <  k) l = p + 1; else r = p - 1;
}
```

## 判据

只需要「第 $k$ 小 / 中位数 / 两侧数量差最小」而不需要整体有序时用它；要整体有序才用排序。

## 复杂度

期望 $O(n)$、最坏 $O(n^2)$；空间 $O(1)$。与排序的 $O(n\log n)$ 差在「只排一侧」。

## 真题

2016·43：划分使 $|n_1-n_2|$ 最小、$|S_1-S_2|$ 最大——等价于找第 $\lfloor n/2\rfloor$ 小。
