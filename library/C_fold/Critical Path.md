## Definition

AOE 网上求「哪些活动拖延会拖整个工期」：两条点量 + 一条边量，余量为 0 的边就是关键活动。

## 两遍点 + 一遍边

1. **正推** $ve$（按拓扑序）：源点 0，$ve(j)=\max\{ve(i)+d\}$——要等**所有**前驱完成。
2. **逆推** $vl$（按逆拓扑序）：汇点 $vl=ve$，$vl(i)=\min\{vl(j)-d\}$——要满足**所有**后继要求。
3. **边**：$e=ve(\text{尾})$、$l=vl(\text{头})-d$；余量 $l-e$，为 0 即关键活动。

## 易错

- 点与边不能混用：点只有发生时刻，边才有开始/完成；把 $ve(\text{头})$ 当成活动完成时刻是错的。
- 加速**任意**关键活动不一定缩短工期——只有同时出现在所有关键路径上的活动才有效。

## 复杂度

正推 + 逆推 $O(n+e)$；手算版本按拓扑序填表。

## 真题

2011·41（关键路径 + 邻接矩阵）、2025·42（关键路径 + 拓扑）。
