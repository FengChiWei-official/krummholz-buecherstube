## Definition
A [[Binary Tree]] of depth `i` is a [[Complete Binary Tree|CBT]] if:
1. All levels of the Tree is filled, except the **last level**.
2. - The last level has all nodes as far **left** as possible.

所以能直接顺序存储：层序编号即可，父子关系由下标算出，见 [[Binary Tree]] §顺序存储。
