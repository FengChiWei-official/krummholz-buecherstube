## Definition

CPU 可以看成一个复杂的状态机：**状态** = 寄存器组（PC、标志位等）+ 地址空间；**转移** = f(状态)，由指令编码与译码逻辑定死；**节拍** = 时钟；**外部输入**只有「值由外部决定的那段地址空间」；**输出** = 总线事务。

> 原句：先考虑单处理器系统，cpu 可以看成一个复杂的状态机，有时间信号、指令、数据这些外部输入状态，内部有寄存器这种状态（包括 pc、标志位等），还有一种特殊的不用寄存器存的是控制流选择，和输入的指令有关，输出是各种可以暴露的寄存器的状态。最早的非时间的状态输入来自主板，他会让硬件按照默契加载和运行特殊位置的指令，而这些指令的控制流形成了一个可以一直运作的指令状态机器，让其他指令可以通过它的代理来更好执行。

## 修正（AI 补边）

- **指令不是外部输入**：指令从地址空间里被取出来（PC 索引）。原模型漏了内存，取指就无处可取。
- **控制流选择属于转移函数，不属于状态**：PC 是控制流选择的**结果**（它在寄存器里）；选择的**规则**（指令编码 + 标志位 → 下一条 PC）是硬件定死的部分。所以控制流不是第四种东西，它是 `f(state)` 的求值。
- **时钟不是输入**：它定义「何时」求值 f，不进入 f 的参数。时钟的物理根是组合逻辑的传播延迟。
- **输出不是寄存器快照**：可观察输出 = 总线上的读写事务。
- **MMIO 之后「内部状态 / 外部输入」的界线消失**：分类标准不是内/外，而是**值由谁决定**。
