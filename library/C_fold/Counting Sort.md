## Definition

不开比较：值域小的时候直接数每个值出现几次，再按顺序铺回去。

## 骨架

```c
for (i = 0; i < n; i++) cnt[a[i]]++;      // 计数
for (i = 1; i <= k; i++) cnt[i] += cnt[i-1];   // 前缀和 → 定位置（这一步决定稳定性）
for (i = n-1; i >= 0; i--) b[--cnt[a[i]]] = a[i];  // 倒着放，稳定
```

## 两处易错

- **不加前缀和**：只能得到「每个值有几个」，拿不到有序位置。
- **正着放**：相等元素的相对次序被颠倒，稳定性丢了。

## 判据

题面给了值域上界 $k$，且要求 $O(n)$ 级时间——这是考纲第八章拓展题的形状；没给值域就不能用。

## 复杂度

时间 $O(n+k)$；空间 $O(n+k)$。$k$ 远大于 $n$ 时退化成浪费。
