## Definition

CPU 对外只发**物理地址**（虚拟→物理的翻译在片内完成）。**物理地址是机器的全局身份，虚拟地址是每个进程的局部身份**；MMU 是一台「改名机」，而配置它的人正是 OS。

> 原句：从 cpu 中心的视角，它就在一个总线上，用地址指定对象，用数据总线交流。cpu 实际上只和北桥用物理地址交流。

## 修正（AI 补边）

- **「北桥」是 2008 年的拓扑，不是结构**：2009 起内存控制器进 CPU 片内，北桥作为独立芯片消失（剩下的芯片组是 PCH）。判据要落在**功能**（谁译码地址），不落在**芯片**。
- **物理地址 ≠ 内存地址**：物理地址空间里混着 DRAM 与设备寄存器（MMIO）；x86 另有**独立 I/O 端口空间**（`in`/`out`）——即考纲的**统一编址 vs 独立编址**。
- **总线是多主的**：DMA 控制器、网卡也是主设备，需要仲裁。所以那不是「CPU 与北桥的对话」。
- **写不一定到内存**：写回式缓存下写可能只停在缓存；事务内容 = {物理地址, 读/写, 数据, 控制}，别的缓存会**窥探**（一致性）。
- **翻译的成本是隐藏的**：TLB 缺失触发页表遍历——翻译本身要访存，计入时间但不外显（不变量 4）。
