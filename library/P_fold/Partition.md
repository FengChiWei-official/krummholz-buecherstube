## Definition

选一个 pivot，一趟扫描把区间切成两段（$<pivot$ | $\ge pivot$），或三路切成三段（$<$ | $=$ | $>$）；返回分界下标。

## 骨架

```c
int i = l - 1;
for (int j = l; j < r; j++)
    if (a[j] < p) swap(a[++i], a[j]);
return i;          // [l..i] 是小于区
```

- 只用一个写指针 `i` 记「小于区的右边界」，读指针 `j` 往前走。
- pivot 取端点即可；随机化只改最坏情况，不改代码形状。

## 用途

- 快速选择的每一步（2016·43 找第 $n/2$ 小）。
- 荷兰国旗三路划分；链表按值分两段。

## 复杂度

一趟 $O(n)$ / $O(1)$ 额外空间。

## 注意

与 [[Partition Problem]] 同名不同义：那一篇是背包式的「集合划分」，不是本义的一趟划分。
