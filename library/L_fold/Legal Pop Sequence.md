## Definition

给一个入栈序列，判断某个出栈序列是否合法；数合法出栈序列的个数。

## 判定（模拟）

```
j = 0;
for (i = 0; i < n; i++) {
    push(in[i]);
    while (!empty(s) && top(s) == out[j]) { pop(s); j++; }
}
return j == n;
```

## 计数（卡特兰数）

$n$ 个元素入栈序列固定时，合法出栈序列数是 $\dfrac{1}{n+1}\dbinom{2n}{n}$——不是 $n!$。

## 易错

- $n!$ 是所有排列数，后进先出会排除一部分。
- 判定题的关键是「能弹就弹」，弹完再看下一个输入。

## 复杂度

模拟 $O(n)$ 时间 / $O(n)$ 栈空间。

## 真题

2026·42（判断序列、数个数）。
