## Definition

两条链表长度不等时，先各自量长，让长的那条先走「长度差」步，之后两指针同步前进才可能同时到达。

## 骨架

```c
int la = len(a), lb = len(b);
while (la > lb) { a = a->next; la--; }
while (lb > la) { b = b->next; lb--; }
while (a != b) { a = a->next; b = b->next; }   // 同步走
```

## 判据

- 题面出现「共同后缀 / 相交起点 / 对齐」这类**同一位置**的语义，且两条链长度可能不同。
- 若题目保证等长（如同步输入的两条串），对齐这一步可以省。

## 复杂度

$O(n+m)$ 时间 / $O(1)$ 空间；量长本身要两遍扫描。

## 真题

2012·42：两个单词链表的共同后缀起点。
