## Definition

支持 `push / pop / min` 三个操作都在 $O(1)$ 的栈：主栈之外再挂一个**同步的辅助栈**，栈顶始终是当前最小值。

## 骨架

```
push(x):  s.push(x); m.push(min(x, m.empty() ? x : m.top()))
pop():    s.pop();   m.pop()
min():    m.top()
```

## 两条规范

- **同步**：辅助栈与主栈同高、同进同出——不搞「只在更小时才压」的变体，那种写法 `pop` 时要判等，反而多一个分支。
- **空栈**：`min` 前先判空，与 [[How to Use Stack]] 的规则一致。

## 复杂度

三个操作均 $O(1)$；空间 $O(n)$（多一倍栈）。
