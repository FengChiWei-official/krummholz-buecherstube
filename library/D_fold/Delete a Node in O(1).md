## Definition

只给待删结点 `p`（不给前驱）时，把后继的值抄进 `p`，再摘掉后继——**改的是值，不是链**。

## 骨架

```c
void deleteNode(struct Node *p) {   // p 不是尾结点
    struct Node *q = p->next;
    p->data = q->data;              // 1. 值前移
    p->next = q->next;              // 2. 摘掉后继
    free(q);
}
```

## 两个前提

- **`p` 不是尾结点**：尾结点没有后继可抄，必须回到量长/找前驱的办法，$O(n)$。
- **题目允许改值**：若要求「不动值、只动链」，这条路走不通——语义上被删的是后继，值只是搬了个家。

## 复杂度

$O(1)$ 时间 / $O(1)$ 空间；代价是牺牲了「尾结点」这一种情况，所以完整版仍要写 $O(n)$ 的兜底。
