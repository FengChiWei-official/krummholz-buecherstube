## Definition

每个顶点挂一条边表（或数组 + 链表），只存真实存在的边。空间 $O(n+e)$。

## 两种写法

- **数组 + 链表**：`head[i]` 指向第 $i$ 个顶点的边表。
- **数组 + 边数组**（链式前向星）：`to[]/next[]/head[]` 三个数组，不用指针。

## 与 [[Adjacency Matrix]] 的取舍

| | 矩阵 | 邻接表 |
|---|---|---|
| 空间 | $O(n^2)$ | $O(n+e)$ |
| 查边 | $O(1)$ | $O(\deg)$ |
| 遍历邻居 | $O(n)$ | $O(\deg)$ |
| 数入度 | 数一列 | 要遍历全表 |

## 注意

邻接表**不唯一**：同一张图按不同的输入顺序建表，表就不同——所以「邻接表唯一」是错答。

## 复杂度

建表 $O(n+e)$；DFS/BFS 整个图 $O(n+e)$。
