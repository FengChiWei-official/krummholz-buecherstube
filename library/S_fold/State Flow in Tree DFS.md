## Definition

树（或图）上的 DFS，完整范式是一条两段的状态流：

1. **自上而下**：父亲把状态传给当前节点，当前节点按需求更新本地状态。到此完成本节点上的向下传递。
2. **继续向下**：按顺序要求处理子树，向下阶段的状态变化继续。
3. **拐点**：到某个地方，状态变化转为自下而上。
4. **自下而上**：一个或者多个子树更新完状态后，本节点完成自下而上的更新，提交给上级，继续自下而上更新。

两个钩子各有位置：进入节点（preorder）与退出节点（postorder）。拐点之前只有前者携带信息，之后只有后者；叶节点的两个钩子重合。

```
dfs(u, ctx) -> sub:
    local = enter(u, ctx)                  # 向下：父 → 本节点
    for c in order(u):
        sub_c = dfs(c, derive(local, c))   # 继续向下
    return leave(u, local, [sub_c])        # 向上：子树 → 本节点 → 父
```

## 拐点在哪里

- 叶节点：进入即拐点。
- 剪枝：条件满足就提前返回，拐点提前到返回处。
- 中序：拐点落在两棵子树之间——左子树返回、本节点动作、右子树。顺序要求决定的是钩子的**位置**，不只是方向。

## 一般只保留一半

判据：答案在进入节点时是否已经足够。

| 保留 | 条件 | 典型 |
|---|---|---|
| 自上而下 | 进入时信息已够，子树只是继续向下的通道 | BST 查找、根到叶路径和、深度与祖先关系、visited 标记、懒标记 push-down |
| 自下而上 | 必须等一个或多个子树全部返回 | 高度、子树大小、平衡性、子树和、直径、[[Tree DP]] |

结构上两个钩子都在；「只保留一半」指的是只有一半**携带信息**，另一半是空操作。

## 两段都留：两趟，不是反例

- 换根 DP：先自下而上求全树，再自上而下换根。
- 线段树 lazy：向下 push-down，向上 pull-up。
- 树上差分：先自下而上累加，再自上而下取前缀。

这几次都是同一棵树走两遍；单趟 DFS 仍然只承载一个方向的信息。

## 状态的载体

- **传值**：路径前缀、上下文快照；兄弟之间互不污染。
- **传引用 + undo**：路径向量、visited；进入时标记，退出时恢复。
- **全局累加器**：没有返回值，答案写在外部。

载体决定「只保留一半」是否安全：向下的可变状态忘记恢复会污染兄弟；在子节点全部返回前合并，摘要不完整。

## 代理

有时节点不做合并，而是把子树槽位让给遍历前驱：自己的返回就是前驱留下的状态（last-wins 折叠），状态沿遍历顺序线性流动，而不是沿树结构向上汇聚。到根时，根作为整个遍历的代理，摘要退化为「遍历位置」。

例子：把树摊平成链（right 指针指向后继）、线索化 / Morris、填充 next 指针、BST 转有序链表（中序前驱）。

## 图的边界

图上没有真正的子树：`order(u)` 只是未访问邻居，向上摘要覆盖的是 DFS 树的一棵子树；无向边的回边会让同一状态被重复合并，所以 visited 的标记时机（入栈/入队标记 vs 返回时标记）是这套范式在图上多出来的约束。
