## Definition

从右往左扫一遍，随时维护「当前位置右侧的最值」；答案依赖右侧信息时，正着扫不出来，倒着扫一次就够。

## 骨架

```c
int suf = a[n-1];                 // 后缀最值
for (int i = n-2; i >= 0; i--) {
    res[i] = f(a[i], suf);        // 先用「右侧」信息
    if (a[i] > suf) suf = a[i];   // 再把 a[i] 并入后缀
}
```

顺序不能反：先用旧的后缀最值，再更新它。

## 判据

- 每项的结果只依赖「当前项 + 右侧全部项的一个摘要」（最值、和、是否存在），不是依赖右侧全部元素本身。
- 摘要可增量维护 → 逆序一遍 $O(n)$；不可增量 → 只能用单调栈或后缀结构。

## 复杂度

$O(n)$ 时间 / $O(1)$ 额外空间（答案数组不计）。

## 真题

2025·41：`res[i] = max{ A[i]·A[j] : j ≥ i }`，取后缀最大值（含符号要分情况）即一遍。
