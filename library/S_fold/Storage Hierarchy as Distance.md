## Definition

内存中的是**被放在远处的状态**，外存就更远；它们都要进入寄存器才能被**运算**作用。**存储层次是距离，不是层。**

> 原句：内存中的是被放在远处的状态，外存就更远，它们都要进入寄存器才能从潜能变成实在。cache 就是对刚才论调的拓展，用缓存换速度，就要忍受不一致。

## 修正（AI 补边）

- **不是层，是距离**：存储层次不是洋葱层（封装与委托），而是同一权衡（快↔贵↔小）的逐级重复。距离是**访问成本**，不是位置。
- **Cache 使「内存」成为多副本**：同一份状态在寄存器/Cache/主存/外存各有一份副本 → 状态不「在」某处。
- **不一致的根源是「写」，不是缓存**：只读副本永远一致；多副本 + 写 ⇒ 必须**管理**不一致（写策略、失效、一致性协议）。「忍受」是被动语态，掩盖了整章内容。
- **「都要进入寄存器」要限定**：**运算**必须在最近端发生，**搬运**不必——DMA 从不经过 CPU 寄存器。这正是 DMA 存在的理由。
- **外存不只是更远**：多了非易失这一整个维度，且访问方式质变（块设备、要经控制器与命令协议）。
- **物理根**：传播延迟 → 必须分节拍 → 一个节拍走不到远处 → 必须分层搬运。
