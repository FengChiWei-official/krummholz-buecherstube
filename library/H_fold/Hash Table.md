## Definition

用散列函数把关键字映射到表地址；冲突用两族办法处理——开放定址（表内另找空位）与拉链（同址串成链表）。

## 两族的分界

| | 开放定址 | 拉链 |
|---|---|---|
| 存储 | 表本身 | 表 + 链表结点 |
| 装填因子 | 必须 $<1$ | 可 $>1$ |
| 删除 | 要墓碑标记 | 直接摘链 |
| 查找失败 | 沿探测序列走到底 | 走到空链 |

## 手算题的两个量

- **成功的 ASL**：每个关键字的比较次数求和除以元素数。
- **失败的 ASL**：按散列函数的**值域**（不是表长）逐个起点算「找空要几次」，再求平均。
- 见 [[ASL]]、[[Open Addressing]]。

## 复杂度

期望 $O(1)$ 每次查找；最坏退化成 $O(n)$（全冲突）。
