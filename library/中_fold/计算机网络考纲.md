# 计算机网络考纲

408 计算机网络考纲整理，共六章；每章分「考纲要点 / 复习提示 / 小结与疑难点」三块。

## 第一章 计算机网络体系结构

### 考纲要点

本章考纲共两个大点。

**一、计算机网络概述**：计算机网络的概念、组成与功能；计算机网络的分类；计算机网络的性能指标。

**二、计算机网络体系结构与参考模型**：计算机网络分层结构；协议、接口、服务的概念；ISO/OSI 参考模型和 TCP/IP 模型。

### 复习提示

本章介绍计算机网络体系结构的基本概念，要在理解的基础上适当记忆。重点掌握三种数据交换方式的特点及相关计算；协议、接口和服务的概念；ISO/OSI 参考模型和 TCP/IP 模型各层的基本功能；熟悉网络性能指标，特别是时延、带宽、速率等的计算。

### 小结与疑难点

1. **互联网用无连接的 IP，为什么不把网络设计成可靠的？** 传统电信网用电话通信，普通电话是哑终端、不具备智能处理能力，可靠性只能由网络本身保证。互联网在设计之初的前提相反：终端本身足够智能，可靠性可以交给端系统负责，让网络结构更简单、成本更低、可扩展性更强。这就是端到端可靠传输的设计哲学——网络无连接、不可靠，传输层用面向连接的 TCP 在端到端上实现可靠交付，降低基础设施的复杂性和成本，同时确保应用所需的可靠通信。

2. **端到端通信和点到点通信有什么区别？** 由物理层、数据链路层和网络层构成的通信，负责主机到主机的通信服务；传输层负责主机上应用进程之间的端到端通信服务。点到点指数据在主机到主机之间传递，不针对具体的应用，它只负责从一台主机传输到另一台主机。端到端通信建立在点到点通信的基础上，通过多段点到点链路串联，实现不同主机上应用程序之间的通信。

3. **如何理解传输速率和传播速度？** 传输速率是主机、路由器发送数据的速度，单位 bit/s；传播速率是电磁波在物理介质中向前传播的速度，单位 m/s。例如链路传播速度为 $2\times10^8$ m/s（即每微秒 200 m），带宽为 1 Mb/s（即每微秒可发送 1 bit）：第 0 微秒发出第 1 个比特，第 1 微秒时它已传 200 m，第 2 微秒发出第 2 个比特时，第 1 个比特跑到 400 m。链路上的瓶颈是发送速率（带宽），比特在链路上的位置由传播速度决定。

## 第二章 物理层

### 考纲要点

本章考纲共三点。

1. **通信基础**：信道、信号、带宽、码元、波特、速率、信源、信宿等基本概念；奈奎斯特定理与香农定理；编码与调制；电路交换、报文交换和分组交换；数据报与虚电路。
2. **传输介质**：双绞线、同轴电缆、光纤与无线传输介质；物理层接口特性。
3. **物理层设备**：中继器和集线器。

### 复习提示

物理层考虑的是如何在连接各台主机的传输介质上传输数据比特流，而不是具体的传输介质。本章概念多、易出选择题，复习时应抓住重点：奈奎斯特定理与香农定理、编码与调制技术、物理层接口的特性、物理层设备的功能与特点等。

### 小结与疑难点

1. **传输介质属于物理层吗？它与物理层有何区别？** 传输介质不属于物理层，尽管与物理层紧密相关：从网络体系结构看，它位于物理层之下，同时与数据链路层紧密关联。介质承载电信号和光信号，无法区分信号所代表的比特值；物理层通过定义电气、机械、功能和过程特性，将原始信号解释为有意义的比特流供上层使用。也就是说，通信介质是信号的通道，物理层赋予其具体的语义。

2. **什么是基带传输、频带传输和带宽传输？它们有什么区别？**
   - 基带传输直接发送数字信号，不经过调制，把整个信道带宽用于短距离通信，编码方式包括不归零编码和曼彻斯特编码（不归零编码用高电平表示 1、低电平表示 0）。
   - 频带传输是在需要远距离或无线传输时，把基带信号加载到高频载波上（即调制），转换后的信号适合在模拟信道中传输。它让数字信号能在传统电话系统中传输，还支持多路复用以提高信道利用率；调制之后可以用一个码元表示多个二进制位。电话线上网、WiFi 都属于频带传输。
   - 宽带传输在传统通信语境中指利用频分复用等方法，把一条物理线路划分为多个频带信道，每个信道可以独立进行频带传输且互不干扰，多路并行传输提升线路容量。例如有线电视能一边上网一边看电视，就是利用宽带传输技术。

3. **奈氏准则和香农定理的主要区别是什么？对数据通信的意义是什么？** 奈氏准则只考虑信道带宽的限制，给出带宽下码元传输速率的上限，只限制波特率，不限制每个码元所携带的比特数（可用高阶调制提升每码元比特数）。香农定理适用于有噪声的实际信道，给出了带宽与信噪比共同决定信道极限速率的关系：理论极限不突破，意味着要提高通信速率只能增加带宽或改善信噪比。二者从不同角度构成数字通信系统设计的理论基础。

4. **信噪比明明是 $S/N$，为什么用 $10\log_{10}(S/N)$ 表示？** 这是两种不同的单位：$S/N$ 是线性比值，分贝是它的对数表示。例如信号功率 100、噪声功率 1，信噪比为 100:1；用 dB 表示则为 $10\log_{10}100=20$ dB。数值等价，而分贝更实用。

## 第三章 数据链路层

### 考纲要点

本章考纲共八点。

1. 数据链路层的功能
2. 组帧
3. 差错控制：检错编码和纠错编码
4. 流量控制和可靠传输机制：流量控制、可靠传输与滑动窗口机制；停止等待协议；后退 N 帧协议（GBN）；选择重传协议（SR）
5. 介质访问控制：
   - 信道划分：频分复用、时分复用、波分复用、码分复用（及英文缩写）
   - 随机访问：ALOHA 协议、CSMA 协议、CSMA/CD 协议、CSMA/CA 协议
   - 轮询访问：令牌传递协议
6. 局域网的基本概念与体系结构：以太网与 IEEE 802.3、IEEE 802.11 无线局域网（WLAN）的基本概念与基本原理
7. 广域网的基本概念；点对点协议（PPP）
8. 数据链路层设备：以太网交换机及其工作原理

### 复习提示

本章是历年考试的重点。在了解数据链路层基本概念和功能的基础上，重点掌握滑动窗口机制、三种可靠传输协议、各种 MAC 协议，特别是 CSMA/CD、CSMA/CA 协议和以太网帧格式，以及局域网的争用期和最小帧长的概念、二进制指数退避算法。此外，中继器、网卡、集线器、网桥和局域网交换机的原理及区别也要重点掌握。

### 小结与疑难点

1. **为什么连续 ARQ 在接收窗口为 1、用 $n$ 比特编码时，发送窗口最多只能是 $2^n-1$？** 在连续 ARQ 协议中，若接收窗口大小为 1、发送窗口大小超过 $2^n-1$，则新帧和重传帧可能无法区分，导致错误。

2. **为什么 PPP 不采用帧编号和确认机制来实现可靠传输？** 主要有两方面原因：其一，在因特网中 PPP 承载的是 IP 数据报，即使数据链路层实现可靠传输，后续仍可能因为拥塞被丢弃，数据链路层的可靠性无法保证端到端可靠交付；其二，现代物理链路误码率很低，引入重传和确认机制会增加开销和延迟，得不偿失。实际上 PPP 通过 FCS 字段对每帧做 CRC 校验，发现差错立即丢弃、绝不向上层传递错误数据，真正的差错恢复由高层 TCP 在端到端基础上完成。因此 PPP 采用「有错即弃、靠上层负责」的设计，实现轻量高效，符合端到端原则。

3. **在以太网中，为什么说若一个帧在冲突窗口内未发生冲突，则后续不会再发生冲突？** 在 CSMA/CD 下，节点发送前会侦听信道，仅在空闲时开始发送；冲突窗口是检测冲突的最晚时限，若存在冲突，最迟到该时间也被感知。若在争用期内没有检测到冲突，说明帧的首部已经到达所有节点，各节点侦听到之后不会发起新的发送，所以不可能再有冲突。

4. **将以太网速率从 10 Mb/s 提升到 100 Mb/s 时，为满足 CSMA/CD 冲突检测要求需要做什么调整？** 要求最短帧的发送时间不小于冲突窗口。速率提升十倍后，若网段长度不变、信号传播时延不变，那么同样长度帧的发送时间缩短到原来的 10%。为此 100Base-T 将以太网网段最大长度从 500 m 缩短到 100 m，把帧间最小间隔从 9.6 μs 缩短到 0.96 μs，从而保证最短帧发送时间不小于冲突窗口，且最短帧长不变。

## 第四章 网络层

### 考纲要点

本章考纲共八点。

1. 网络层的功能：异构网络互联、路由与转发、SDN 的基本概念、拥塞控制
2. 路由算法：静态路由与动态路由（指距离向量算法与链路状态算法）、层次路由
3. IPv4：IPv4 分组；IPv4 地址与 NAT；划分子网与子网掩码；CIDR、路由聚合；ARP、DHCP 和 ICMP
4. IPv6：主要特点、IPv6 地址
5. 路由协议：自治系统、域内路由与域间路由；RIP 路由协议、OSPF 路由协议、BGP 路由协议
6. IP 多播：多播的概念和 IP 多播地址
7. 移动 IP：概念和移动 IP 通信过程
8. 网络层设备：路由器的组成和功能、路由表和分组转发

### 复习提示

本章是历年考察的重中之重，尤其容易结合第三章、第五章、第六章出综合题，其中 IPv4 和路由相关的知识是核心，每年真题都有涉及，必须牢固掌握其原理，还要多做题以便灵活应用。本章其他知识如 IPv6、IP 多播、移动 IP 也要有所了解。

### 小结与疑难点

1. **「尽最大努力交付」有哪些含义？** 共五点：不保证 IP 数据报无差错到达目的；不保证在规定时间内交付；不保证按顺序交付；不保证不重复交付；不主动丢弃数据报，仅在首部检验和出错或因缓存满而无法处理时丢弃。

2. **局域网中计算机 A 广播 ARP 请求以获取计算机 B 的硬件地址，此时由谁发送 ARP 响应、返回的是谁的硬件地址？** 若 A 与 B 在同一局域网，B 收到 ARP 请求后向 A 单播 ARP 响应，返回 B 自己的硬件地址。若 B 不在 A 的局域网，A 的 ARP 请求无法到达 B，因此连接该局域网的路由器（往往是 A 的默认网关）会代理响应，向 A 返回路由器在该局域网内的硬件地址。

3. **数据报首部只有源和目的 IP 地址，未规定下一条路由，如何确定转发路径？能不能在路由表中直接用硬件地址以避免 ARP 查询？** 路由器收到数据报后根据路由表查出下一跳 IP 地址，但不改变 IP 数据报的内容；该 IP 地址随后交给数据链路层，通过 ARP 解析为对应的 MAC 地址并填入 MAC 首部，从而在物理网络中正确地把帧送达下一跳。不能在路由表中直接使用硬件地址：IP 地址的抽象性屏蔽了底层网络差异，是互联网可扩展性的基础；若路由表直接用硬件地址，表项数量会剧增、管理复杂，得不偿失。

4. **「路由器实现了物理层、数据链路层、网络层」是什么含义？** 指路由器具有处理物理层、数据链路层和网络层协议的能力：在物理层能接收和发送比特流；在数据链路层能识别帧结构、解析 MAC 地址，并完成帧的解封装和重新封装；在网络层能读取 IP 数据报首部，根据目的 IP 地址查询路由表并做出转发决策。因此路由器转发数据时，会先解封输入帧提取出 IP 数据报，再根据下一跳接口重新封装适合输出链路的新帧。这种能力使路由器可以互联底层技术不同的网络（如以太网与 PPP 链路），与仅工作在物理层的中继器、仅工作在数据链路层的交换机有本质区别。

## 第五章 传输层

### 考纲要点

本章考纲共三点。

1. 传输层提供的服务：传输层的功能；寻址与端口；无连接服务与面向连接服务
2. UDP：UDP 数据报、UDP 校验
3. TCP：TCP 数据报、TCP 连接管理、TCP 可靠传输、TCP 流量控制与拥塞控制

### 复习提示

传输层是整个网络体系结构中的关键层次，要求掌握传输层在计算机网络中的功能、工作方式及原理，掌握 UDP 及 TCP 的首部格式、可靠传输、流量控制、拥塞控制、连接管理等。其中 TCP 报文分析、连接管理、流量控制与拥塞控制机制出选择题、综合题的概率均较大，应透彻掌握其工作原理，以便在具体题目中灵活运用。

### 小结与疑难点

1. **MSS 设置得过大或过小会有什么影响？**
2. **TCP 使用后退 N 帧还是选择重传？** 表面上看，TCP 使用累积确认，类似 GBN；但 TCP 还支持 SACK，启用 SACK 之后重传行为更类似 SR。因此 TCP 的重传机制可以看成 GBN 和 SR 的混合体。
3. **为什么超时事件发生时 cwnd 被设置为 1，而收到三个冗余 ACK 时 cwnd 减半？** 两种事件反映的网络拥塞严重程度不同。
4. **为什么不采用两次握手建立连接？** 主要是为了防止已失效的连接请求报文段突然传送到服务器，导致错误地建立连接。
5. **为什么 TCP 建立连接时不能每次都选择相同的、固定的初始序号？**
6. **假设互联网中所有链路的传输都不出现差错、所有节点都不出现故障，此时 TCP 的可靠交付功能是否多余？** 不多余。
