### 附二｜易混词对

判据：换一个字就换对象；每组只记一句判据。

| A | B | 判据 |
|---|---|---|
| 使用价值 | 价值 | 有用性 vs 人类劳动凝结；商品是二者统一 |
| 具体劳动 | 抽象劳动 | 创造使用价值 vs 形成价值 |
| 不变资本 | 可变资本 | 只转移价值 vs 带来剩余价值 |
| 绝对剩余价值 | 相对剩余价值 | 延长工作日 vs 缩短必要劳动时间 |
| 固定资本 | 流动资本 | 价值逐次转移 vs 一次转移 |
| 社会必要劳动时间 | 个别劳动时间 | 决定价值量 vs 决定盈亏 |
| 生产力 | 生产关系 | 人与自然 vs 人与人 |
| 经济基础 | 上层建筑 | 生产关系总和 vs 政治与观念 |
| 社会存在 | 社会意识 | 决定 vs 反作用 |
| 真理的绝对性 | 真理的相对性 | 客观性与无限性 vs 条件性与近似性 |
| 两个必然 | 两个决不会 | 趋势 vs 条件与长期性 |
| 空想社会主义 | 科学社会主义 | 道德设想 vs 两大发现 |
