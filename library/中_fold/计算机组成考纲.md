# 计算机组成原理考纲

408 计算机组成原理考纲整理，共七章；每章分「考纲要点 / 复习提示 / 待解问题」三块。

## 第一章 计算机系统概述

### 考纲要点

**一、计算机系统层次结构**

1. 计算机系统的基本组成
2. 计算机硬件的基本组成
3. 计算机软件和硬件的关系
4. 计算机系统的工作原理：「存储程序」工作方式；高级语言程序与机器语言程序之间的转换；程序和指令的执行过程

**二、计算机性能指标**

吞吐量、响应时间；CPU 时钟周期、主频、CPI、CPU 执行时间；MIPS、MFLOPS、GFLOPS、TFLOPS、PFLOPS、EFLOPS、ZFLOPS。

### 复习提示

要求形成比较完整的知识体系。

### 待解问题

- 主频高的 CPU 一定比主频低的 CPU 性能好吗？
- 翻译程序、汇编程序、编译程序和解释程序的区别与联系是什么？
- 不同级别的编程语言所编写的程序有何差异？哪类语言可以被硬件直接执行？
- 什么是透明性？计算机体系结构和计算机组成的区别与联系是什么？
- 基准程序执行得越快，说明机器性能越好吗？

## 第二章 数据的表示和运算

### 考纲要点

**一、数制与编码**

- 进位计数制及其相互转换
- 定点数的编码表示

**二、运算方法和运算电路**

- 基本运算部件：加法器、算术逻辑部件 ALU
- 加/减运算：补码加减运算器、标志位的生成
- 乘除运算：乘除运算的基本原理、乘除法电路的基本结构

**三、整数的表示和运算**

- 无符号整数的表示和运算
- 有符号整数的表示和运算

**四、浮点数的表示和运算**

- 浮点数的表示：IEEE 754 标准
- 浮点数的加/减运算

### 复习提示

本章理解起来有一定难度。往年真题涉及 C 语言中各种数字类型（包括 `char` 类型）的实现，及其表示范围、运算规则、溢出与转换；IEEE 754 浮点数要求掌握表示特点与加减运算，包括最大值、最小值和非规格化数。

### 待解问题

- 在计算机中为什么采用二进制表示数据？
- 计算机字长足够的情况下，能精确表示每一个数吗？
- 字长相同的情况下，浮点数和定点数的表示范围与精度有什么区别？
- 用移码表示浮点数的阶码有什么好处？
- 如何表示一个数值数据？计算机的数值数据都是二进制数吗？
- 什么是无符号整数的溢出？
- 相同位数的定点数和浮点数，可表示的浮点数个数比定点数多吗？
- 现代计算机是否考虑原码加减法？

## 第三章 存储系统

### 考纲要点

本章考纲共七点。

**一、存储器的分类**

**二、层次化存储器的基本结构**

**三、半导体随机存取存储器（RAM）**

SRAM、DRAM、Flash 存储器。

**四、主存储器**

DRAM 芯片与内存条；多模块存储器；主存与 CPU 之间的连接。

**五、外部存储器**

磁盘存储器（HDD）、固态硬盘（SSD）。

**六、高速缓冲存储器（Cache）**

Cache 的基本工作原理；Cache 与主存之间的映射方式；Cache 中主存块的替换算法；Cache 写策略。

**七、虚拟存储器**

虚拟存储器的基本概念；页式虚拟存储器（基本原理、页表、地址转换、TLB（快表））。

### 复习提示

本章是重点，尤其是 Cache 和虚拟存储器，经常出综合题。此外需掌握：存储器的特点与扩展（芯片选择、连接方式、地址范围）；交叉存储器、Cache 的相关计算与算法；替换算法、虚拟存储器和 TLB 容易出选择题。需要掌握 Cache 和 TLB 的地址翻译与 Cache 映射问题，并与操作系统相结合。

### 待解问题

- 存储系统为什么要分这些层次？计算机如何管理这些层次？
- 影响 Cache 性能的因素有哪些？
- 虚拟存储系统的页面设置得大一些好还是小一些好？
- Cache 与命中率之间的关系是什么？发生取指令 Cache 缺失时的处理过程是什么？

## 第四章 指令系统

### 考纲要点

本章考纲共六点。

**一、指令系统的基本概念**

**二、指令格式**

**三、寻址方式**

**四、数据的对齐和大小端存放方式**

**五、CISC 和 RISC 的基本概念**

**六、高级语言程序与机器级代码之间的对应**

编译器、汇编器与链接器的基本概念；选择结构语句的机器级表示；循环结构语句的机器级表示；过程（函数）调用对应的机器级表示。

### 复习提示

应掌握各种寻址方式的特点和有效地址的计算，三种偏移寻址的地址计算方法比较重要；以及 CISC 和 RISC 的区别。注意 22 年考纲新增机器级表示相关内容，机器级代码题型多次出现，需要有阅读汇编的能力。本章知识点可以按选择题方式给出，也可能结合其他章节内容考察，与指令格式、指令寻址方式和 CPU 指令执行过程关系密切，需重点掌握。

### 待解问题

- 什么是指令？什么是指令系统？为什么要引入指令系统？
- 一般来说，指令由哪些部分组成？各个部分的作用是什么？
- 对一个指令系统而言，寻址方式多或少会带来什么样的影响？
- 简述各种常见指令寻址方式的特点和适用情况，并举出一个具体的例子。
- 一个操作数在内存中可能占多个单元，怎样在指令中给出操作数的地址？
- 装入和存储型指令（RISC 指令系统中的两条访存指令）有什么特点？

### 考纲要点

**一、CPU 的功能和基本结构**

**二、指令执行过程**

**三、数据通路的功能和基本结构**

**四、控制器的功能和工作原理**

**五、异常和中断机制**

异常和中断的基本概念；异常和中断的分类；异常和中断的检测与响应。

**六、指令流水线**

1. 指令流水线的基本概念
2. 指令流水线的基本实现
3. 结构冒险、数据冒险和控制冒险的处理
4. 超标量和动态流水线的基本概念

**七、多处理器的基本概念**

SISD、SIMD、MIMD、向量处理器的基本概念；硬件多线程的基本概念；多核处理器的基本概念；共享内存多处理器（SMP）的基本概念。

### 复习提示

中央处理器（CPU）是计算机的核心，也是本章的难点。数据通路的分析、指令执行阶段的节拍与控制信号的安排，以及流水线结构和性能分析，经常出大题及综合题；各种寄存器的特点、各种指令执行的周期和特点、控制器相关的概念、流水线相关的概念，经常出选择题。

### 待解问题

- 指令和数据均存放在内存中，计算机如何从时间和空间上区分它们是指令还是数据？
- 什么是指令周期和时钟周期？它们之间有什么关系？
- 什么是微指令？它和第四章谈到的指令有什么关系？
- 什么是指令流水线？指令流水线和传统体系架构相比优势是什么？

**易混淆**

- 流水线段数越多，并发度就越高吗？执行指令越快吗？
- 读后写相关（WAR）与写后写相关（WAW）。

## 第七章 输入/输出系统

### 考纲要点

**一、I/O 接口（I/O 控制器）**

I/O 接口的功能和基本结构；I/O 端口及其编址。

**二、I/O 方式**

1. 程序查询方式
2. 程序中断方式：中断的基本概念；中断响应过程；中断处理过程；多重中断和中断屏蔽的概念
3. DMA 方式：DMA 控制器的组成；DMA 传送过程

### 复习提示

I/O 方式是本章的重点和难点，每年都会以选择题形式考查概念和原理，也可能以综合题形式考查，特别是 I/O 方式的效率相关的计算、中断方式的原理与处理过程、中断屏蔽、DMA 方式的特点与传输过程、DMA 与中断方式的区别。

### 待解问题

- 设备有哪些编址方式？各有何特点？
- CPU 响应中断应具备哪些条件？

**易混淆**

- 在开中断的情况下，CPU 检测到中断就一定会立即响应吗？
- 向量中断、中断向量、向量地址三个概念是什么关系？
- 程序中断和调用子程序有什么区别？（从触发时机、服务关系、实现机制和嵌套级别四个方面分析）
