## Definition

二叉树 + 有序约束：左子树全部 $<$ 根 $<$ 右子树全部。等价于**中序遍历严格递增**。

## 两个判据

- **中序 + prev**：中序访问时与上一个访问值比较，不递增就不是 BST（2022·41 顺序存储版同一个写法，只是换成下标访问）。
- **区间约束**：递归往下传 $(min,max)$，每个结点必须落在区间内（2026·41 找 $|data-K|$ 最小即用 BST 有序性剪枝）。

## 代价

- 查找 / 插入 / 删除都是 $O(h)$；$h$ 在随机形状下 $O(\log n)$，退化成链时 $O(n)$。
- 不需要额外空间就能保持有序——这是它相对 [[Heap]] 的唯一优势（堆只保证根最小）。

## 常见坑

判 BST 只比较「父子」是错的：必须保证整棵子树的范围，否则「右孩子的左孩子小于根」这类反例查不出来。
