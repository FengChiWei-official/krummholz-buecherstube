## Definition

找出现次数超过一半的元素：维护一个候选与一个计数——遇到相同就加一，不同就减一，减到 0 换候选。

## 骨架

```c
int cand = a[0], cnt = 1;
for (int i = 1; i < n; i++) {
    if (cnt == 0) { cand = a[i]; cnt = 1; }
    else if (a[i] == cand) cnt++;
    else cnt--;
}
// cand 只是候选：过半必须再验一遍
```

## 正确性来源

**不同元素两两抵消**：真过半的元素即使一直和别的元素对冲，剩下的也一定是它。

## 注意

- 算法给的是**候选**；「是否真的过半」要再扫一遍计数，题面没保证过半时不能省。
- 只有「超过一半」成立；求「超过 $1/3$」要把候选扩成两个，计数逻辑随之改写。

## 复杂度

$O(n)$ 时间 / $O(1)$ 空间。

## 真题

2013·41：主元素（出现次数 $>n/2$）。
