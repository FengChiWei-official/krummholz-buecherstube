## Definition

多路平衡查找树：$m$ 阶 B 树每个结点最多 $m$ 个孩子、$m-1$ 个关键字；所有叶在同一层。

## 三条规则

- **分裂**：结点关键字数溢出（$>m-1$）时，中间关键字上移到父结点，两侧各成一个结点。
- **合并**：删除后关键字数不足（$<\lceil m/2\rceil-1$）时，向兄弟借；兄弟也不够就与兄弟 + 父结点里的分隔关键字合并。
- **根**：根的分裂会让树长高一层；根只剩一个关键字时可以降层。

## 为什么要它

磁盘 I/O 以「块」计价，B 树的结点大小对齐一块——树高 $O(\log_m n)$，即访问磁盘的次数。这是与 [[Binary Search Tree]] 的本质差别。

## 复杂度

查找 / 插入 / 删除 $O(\log_m n)$ 层，每层 $O(m)$ 次比较（块内）。

## 真题

选择题常考插入删除后的形态。
