## Definition

每个结点至多两个孩子，且左右有序——只有单子树时也区分左右，这是它与 [[ADT Tree]] 下其它树形的差别。

## 顺序存储

按**完全二叉树的层序位置**落进一组连续单元：父子关系由下标算出，边一个都不存。

- **帧由题面给**：根从 1 起时左 $2i$ / 右 $2i+1$ / 父 $\lfloor i/2\rfloor$；根从 0 起时左 $2i+1$ / 右 $2i+2$ / 父 $\lfloor (i-1)/2\rfloor$。教材叙述多用 1 起（0 号单元闲置），真题给的是 0 起。
- **空位要哨兵**：不存在的结点在数组里填一个标记值（真题用 `-1`），只有在「真实值」取不到该值时两者才分得开。
- **补空补到哪**：可以补成满形，也可以截到最后一个非空位置——真题用 `ElemNum` 记实际占用个数，数组长度不等于满形长度。
- 代价：随机访问 $O(1)$、零指针；非完全形要补空，结构一改就得搬元素。

## 链式存储

- **二叉链表**：`lchild` / `data` / `rchild`。找子 $O(1)$，找父要遍历 $O(n)$。
- **三叉链表**：二叉链表 $+$ `parent`，找父降到 $O(1)$，代价是多一个指针。

一般树与森林的存储见 [[Storage of Tree]]。
