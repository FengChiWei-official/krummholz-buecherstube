# 希腊字母 → 拉丁字母 → 英语字母:演变法与名字字面义

> AI 原始材料,供消化后用自己的话写成卡片。不要直接当 own-voice 内容用。
> 记号:`⚠️` = 有争议;`[C]` = 有据推论(非直接文献)。

## 0. 一句话

一条链:

**腓尼基辅音字母**(22 个,名字都是具体物:牛、房子、手……) → **希腊人**借形借名,挪用 5 个辅音字母当元音,另造 φ χ ψ ω → **伊特鲁里亚人**过滤(无浊音对立,重排音值) → **罗马人**继承并再分化(C/G、V/U、I/J、W) → **英语 26 字母**。

关键结论:希腊字母名几乎全是**腓尼基词的音译**,希腊人自己也不懂其意思(alpha 对他们只是"a 的名字",不是"牛")。真正"有意义"的名字只有希腊人后来**自己造的描述性名字**:omicron/omega、epsilon/upsilon。这就是为什么"omega = 大 o""ypsilon = 简单的 i"这类解释只对后一类成立。

## 3. 真正"有意义"的名字:四个描述性词

希腊人把两对同音/近音字母用**形容词**区分,这才是"名字字面义"的来源:

- **ὂ μικρόν omicron** = ὂ + μικρόν「小」 → 「小 o」。
- **ὦ μέγα omega** = ὦ + μέγα「大」 → 「大 o」。
  - 二者古代音值不同(/o/ vs /ɔː/),现代希腊语都读 /o/,区别只剩拼写。
- **ἔ ψιλόν epsilon** = ἔ + ψιλόν「光秃的、单纯的」 → 「简单的 e」,对立于双元音拼法 **αι**(也读 /e/)。
- **ὖ ψιλόν upsilon** = ὖ + ψιλόν → 「简单的 **u**」,对立于 **ου**(读 /u/)。
  - ⚠️ 用户记忆里的"ypsilon = 简单的 i"**只说对一半**:字面义是"简单的 u"(字母 ὖ 读 /u/)。
  - 之所以听着像 i:现代希腊语 υ 已并入 /i/(**iotacism**),名字读作 [ˈipsilon];再加上拉丁把 Υ 写作 Y、英语 Y 又叫 "why"。音变 + 转写一起造成了这个印象。

同类还有:**Θ θ theta** 的名字只是 ṭēt 的希腊化,不是"th 的意思";**Φ Χ Ψ** 的名字多为拟声/模仿音值。

## 4. 拉丁字母自己的演化(关键分叉都在这一步)

### 4.1 伊特鲁里亚过滤

伊特鲁里亚语**没有 /b d g/ 的浊音对立**,只有不送气/送气对立。于是希腊 **Γ gamma** 到了伊特鲁里亚变成 /k/,罗马人继承后 **C 同时表示 /k/ 和 /g/**(古拉丁 C = 两个音)。同理:
- **Q** 只在 **V 前**保留(qv = /kw/),**K** 几乎被 C 挤掉(只剩 Kalendae 等)。
- **H** 来自希腊 **Η eta**——伊特鲁里亚还保留 /h/,罗马继承为 H;而希腊本土的 eta 已变成元音 /ɛː/。**同一字母,音值在两支里分家。**
- **F** 来自 **Ϝ digamma**(希腊 /w/)——伊特鲁里亚用它表示 /f/(有 f 无 w),罗马继承为 F。**一个 /w/ 字母变成了 /f/ 字母。**
- **V U** 来自希腊 **Υ upsilon**(西部希腊值 /u/)。
- **X** 来自**西部希腊 Χ**(西部值 /ks/);东部/标准希腊的 Χ 是 /kʰ/。见 §4.2。

### 4.2 希腊 Χ / Ξ / Ψ 的分裂(最容易搞混)

| 字母 | 西部(→伊特鲁里亚/拉丁) | 东部/标准希腊 | 拉丁怎么处理 |
|---|---|---|---|
| Χ chi | **/ks/** | /kʰ/ | 形状 → 拉丁 **X**;音值 /kʰ/ → 转写 **ch** |
| Ξ xi | /ks/ | **/ks/** | 拉丁无此字母,希腊词转写用 **x** |
| Ψ psi | /kʰ/ | **/ps/** | 拉丁无此字母,转写用 **ps** |

所以:**拉丁字母 X 继承自希腊 Χ 的形状与西部音值,但希腊语里的 ξ 转写成 x**——两个来源都指向 "x",别混。

### 4.3 拉丁字母表的增删

1. **古拉丁 21 字母**:A B C D E F Z H I K L M N O P Q R S T V X。
2. **Z 被删**(约前 300 年,传为监察官 Appius Claudius Caecus;因拉丁 /z/ 经 rhotacism 变 /r/,字母闲置)。
3. **G 诞生**(约前 230 年,Spurius Carvilius Ruga):在 C 上加一竖,补进 Z 空出的第 7 位。**C 从此只管 /k/,G 管 /g/。**
4. **Y 与 Z 复归**(前 1 世纪,为拼希腊借词),按希腊顺序**追加在队尾**——这就是为什么 Y、Z 排在最后。
5. 结果:**23 字母**:A B C D E F G H I K L M N O P Q R S T V X Y Z。
6. **V/U 分裂**:古典拉丁 V 一字兼 /u/ 与 /w/(IVLIVS = Iulius);晚期/中世纪才分 U(元音)/ V(辅音)。
7. **I/J 分裂**:古典 I 兼 /i/ 与 /j/;文艺复兴(16 世纪)人文主义者引入 J 形。
8. **W**:中世纪(约 7–11 世纪)用双写 V(VV)表示日耳曼语 /w/,名 **double-u**(英语名字的字面义就在这)。
9. **英语 26 字母** = 拉丁 23 + 把 I/J、U/V 各算两字 + W。

### 4.4 字母名(拉丁 → 英语)的字面义线索

| 字母 | 拉丁名 | 英语名 | 字面义线索 |
|---|---|---|---|
| Y | ī Graeca | why | **「希腊的 i」**(graeca = 希腊的);英语 "why" ← 法语 "ui" |
| Z | zēta | zed / zee | 直接沿用希腊 zeta;美式 "zee" 是后起类比 B/C/D |
| W | — | double-u | **「双 U」**,V/U 同形的化石 |
| H | hā | aitch | ← 古法语 "ache" |
| R | er | ar | ← 古法语 "ere" |

## 6. 易错点清单

- **"omega = 大 o"成立,"upsilon = 简单的 i"不成立**(字面是"简单的 u");现代读音 /i/ 是 iotacism。
- **η ≠ e**:希腊 η 的**字形**给了拉丁 H,但**音值**给了拉丁/英语的 e/i(如 ἥρως → heros → hero)。
- **希腊 ξ → 英语 x,但拉丁字母 X 来自希腊 Χ**:同名不同源,见 §4.2。
- **F 的祖先不是 /f/**,是希腊 digamma /w/(伊特鲁里亚改值)。
- **Q、K 是 C 的"剩余"**:罗马把 /k/ 统一给了 C,Q 只活于 qu-,K 只活于少数词。
- **Y、Z 在队尾**不是任意排的:它们是 1 世纪才补进来的希腊借词字母。
- **J、U 不是新字母**,是 I、V 的分裂;**W 才是**新造的。
- 希腊字母名(alpha、beta……)对希腊人是**无义词**;有义的是 omicron/omega/epsilon/upsilon 这类描述性名字。
