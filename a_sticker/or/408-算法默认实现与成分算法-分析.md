# 408 算法：默认实现与成分算法 · 分析卡

> 位置：`a_sticker/or/`（AI 散文的合法家），**不是 library 正文**。
> 锚：`a_sticker/or/408 数据结构-算法设计题考点地图.md`（2009–2026 共 18 年）与 `a_sticker/or/标准错误答案清单.md`。每条真题锚写成年份·题号，可 grep 复核；查不到原文的标 **推测**，不编造。
> 用法：把已出真题当难度标尺，按**同结构 × 同下界 × 同骨架**外推同类算法族（§1）；再把跨族复用的最小动作抽成成分算法（§2），每族都指到确定的成分编号；最后定语言层默认写法（§3）。2026-11-27/28 已按本卡补齐 35 张库内卡（见 §5）。

## 0 三个判据：什么叫「同等难度」

- **A 下界**：读入即下界——$O(n)$ 或 $O(\log n)$；矩阵题 $O(n^2)$ 已是下界。不许靠高级数据结构（树套树、平衡树）换复杂度。
- **B 骨架**：六个之一——一遍扫描 / 双指针 / 二分 / 一趟划分 / 递归遍历 / 栈或队列驱动。
- **C 体量**：主体 ≤ 30 行，单函数，或「全局量 + 递归」两件套。

**A ∧ B ∧ C 同类 = 一族。** 只满足 A 的叫「同复杂度、不同族」：摩尔投票与快速选择都 $O(n)$，一个单趟计数、一个划分加收缩，实现难度不同，不并族。

两个关于「信息怎么流」的子结构，都长在 DFS 骨架上：

- **沿前驱-后继传递**（自顶向下）：状态跟着递归参数走，前驱决定后继看到什么，返回值可有可无。
- **通过根节点代理**（自底向上）：子树先在内部合完，根只做最后一次合并——所以「根返回的值」语义上是整棵树，不是根本身。

## 3 语言层规范（多种实现里选一种，定了就不换）

408 只要求手写 C/C++、不要求可编译，所以规范的目标不是「能跑」，是**阅卷人能一遍读懂、变量不重名、结构不歧义**。

1. **局部变量提升为全局，文件头统一声明一次。** `visited[]`、`ans`、`prev`、计数器一律放函数外；递归里只写「用」不写「声明」，避免内层重名遮蔽，也避免每次递归把累加量重新初始化。
2. **`malloc` 与 `free`。** C 写 `malloc(sizeof(Node))`，C++ 写 `new`；试卷不要求可编译，**`free`/`delete` 可以省**，但删除结点必须写「摘链」那一步（`prev->next = p->next`）。`del` 是 Python 写法，408 不用；伪代码要释放就与语言一致地写 `free(p)` / `delete p`。
3. **一句话 push。** 栈：`s[++top] = x` 入栈、`x = s[top--]` 出栈；队列：`q[rear] = x; rear = (rear+1) % m` 入队、`x = q[front]; front = (front+1) % m` 出队。不写完整 ADT——考纲第五章的原话就是「声明结构体后摘关键语句直接嵌入解题代码」。
4. **结构只在使用处声明。** 线性表、树靠语义就够（`p->next`、`p->lchild`），不必写完整定义；**图必须声明存储方式**——邻接矩阵与邻接表的写法完全不同，不声明就有歧义。链表结点写 `struct Node { int data; struct Node *next; };`。
5. **复杂度两句话都要给。** 时间 + 空间，且必须与代码一致；谎报 $O(n)$ 会在正确性上扣分（考点地图 §11）。
6. **命名固定一套。** 下标 `i/j/k`、规模 `n/m`、指针 `prev/cur/next`、二分 `lo/hi/mid`、栈队列 `top/front/rear`、答案 `ans`。帧（0/1 起、半开/闭）在注释里写明——与 `or/index 运算规范化-参考资料卡.md` 同一条纪律。
