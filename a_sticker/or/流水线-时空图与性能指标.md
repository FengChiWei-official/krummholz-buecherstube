# 指令流水线：时空图与性能指标

> **原材料（or/）**：用户给的时间式「$k$ 倍相邻任务非重叠长度 $+$ 第一个任务多出来的部分」＋ 计组 ch5「指令流水线（基本概念、实现、冒险、超标量）」的教材口径。**作图与指标稿**：只给画法与公式，不押题。
> 一句话：**总时间 $=$ 一个任务填满管道的时间 $+$ 之后每个任务只多出一个「流水线周期」。**其余所有指标都是这句话的除法。

## 0. 一条主公式（三种写法，同一件事）

$$T=(n-1)\cdot\tau+\sum_i s_i,\qquad \tau=\max_i s_i$$

- **通用形**：$\tau$ = 最慢段（含锁存器）的时长 = 相邻任务**不重叠**的那一段；$\sum_i s_i$ = 第一个任务从进到最后一段出。
- **均匀形**（$k$ 段等长）：$\sum s_i=k\tau$，于是

$$T=(n-1)\tau+k\tau=(n+k-1)\tau$$

- **你那个写法**：把上式拆成「$n\tau$ $+$ $(k-1)\tau$」——即 **$n$ 个相邻任务非重叠长度，加上第一个任务多出来的 $(k-1)$ 个 $\tau$**。三项恒等，考场按题目给的谁方便用谁。

非均匀段时**只能**用通用形：第一个任务的时间是 $\sum s_i$，不是 $k\cdot\max s_i$。这是这类题最常见的失分点。

## 1. 时空图怎么画

三条画法约定：

| 约定 | 内容 |
|---|---|
| 行 | 一个**段**（或一个部件），行数 $=k$ |
| 列 | 一拍（长度 $\tau$），任务从进到出跨 $k$ 列 |
| 格 | 写「指令号」，空格 = 该段空闲（**气泡**） |

$k=4$、$n=4$ 的均匀流水线：

```
段\拍  1  2  3  4  5  6  7
IF    I1 I2 I3 I4  ·  ·  ·
ID     · I1 I2 I3 I4  ·  ·
EX     ·  · I1 I2 I3 I4  ·
WB     ·  ·  · I1 I2 I3 I4
                └── 从第 4 拍起每拍完成一个
```

读图要点：

1. **对角线**是同一个任务；**竖列**是同一拍（拍内各段并行）。
2. 第一个任务在 $(4,4)$ 格结束 → 填满管道用 $k\tau$；之后每拍吐出一个 → 再加 $(n-1)\tau$。
3. 段间有锁存器 → 每段占一整拍；若题给「段时 $+$ 锁存」，$\tau$ 取两者之和的最大值。
4. 冒气泡（冒险停顿）时**在对应行插空格**，空格不缩短 $T$：一条 $b$ 拍的气泡把 $T$ 直接加 $b\tau$。

## 2. 六个指标（都从主公式推出）

| 指标 | 公式 | 说明 |
|---|---|---|
| **流水线周期** $\tau$ | $\max_i(s_i+\text{锁存})$ | 由最慢段定，改其它段无效 |
| **总时间** $T$ | $(n-1)\tau+\sum s_i$ | 均匀时 $=(n+k-1)\tau$ |
| **吞吐率** $TP$ | $\dfrac{n}{T}$ | $n\to\infty$ 时趋近 $1/\tau$（理论峰值） |
| **加速比** $S$ | $\dfrac{n\sum s_i}{T}$ | 均匀时 $=\dfrac{nk}{n+k-1}$，上界 $\to k$ |
| **效率** $E$ | $\dfrac{S}{k}=\dfrac{n\sum s_i}{k\,T}$ | 均匀时 $=\dfrac{n}{n+k-1}$ |
| **建立时间** | $k\tau$ | 与 $n$ 无关；$n$ 小则它占比大 |

三条恒等关系（记一条就能推其余）：

$$TP=\frac{n}{T},\qquad S=\frac{T_{\text{串行}}}{T}=\frac{n\sum s_i}{T},\qquad E=\frac{S}{k}$$

**效率的几何意义**：时空图里被占格数 $\div$ 总格数。所以「效率 $=1$」只可能发生在 $n\to\infty$——短程序跑流水线效率天然低，不是设计缺陷。

## 3. 算例

$k=5$、$n=100$、每段 $2$ ns：

| 量 | 值 |
|---|---|
| $T$ | $(5+100-1)\times2=208$ ns |
| $S$ | $100\times5\times2\div208=4.81$（上界 5） |
| $E$ | $4.81\div5=96.2\%$ |
| $TP$ | $100\div208\approx0.48$ 条/ns |

同一组参数若段不均匀（$3,2,4,2$ ns）：$\tau=4$，$\sum s_i=11$ → $T=11+99\times4=407$ ns，比均匀版慢近一倍——**慢段的时长被每个任务各付一次**。

## 4. RISC 五段式：模型、失效与三类冒险

先立模型（4.1），再定义「失效」是什么（4.2），然后逐类给判据与解法（4.3）。

### 4.1 RISC 五段式模型

| 段 | 做什么 | 用到的部件 | 该段产生的值 |
|---|---|---|---|
| **IF** 取指 | $PC\to$ 指令存储器，$PC+4$ | PC、I-Cache | 指令字、下一条 PC |
| **ID** 译码 | 译码、读两个源寄存器、生成立即数 | 寄存器堆（读口）、译码器 | 两个操作数、控制信号 |
| **EX** 执行 | ALU 运算 / 算地址 | ALU、立即数扩展 | 运算结果、条件 |
| **MEM** 访存 | load / store | D-Cache、MAR/MDR | 读出的数据 |
| **WB** 写回 | 写目的寄存器 | 寄存器堆（写口） | 寄存器更新 |

两条容易漏的口径：

- **寄存器堆「前半拍写、后半拍读」**：所以 WB 与 ID 落在同一拍也不冲突；这不是冒险，不必停。
- **I-Cache 与 D-Cache 分离**是 5 段式能成立的前提之一（否则 IF 与 MEM 抢同一个存储器，见 4.3 结构冒险）。

```
段\拍   1   2   3   4   5   6   7
IF     I1  I2  I3  I4  I5   ·   ·
ID      ·  I1  I2  I3  I4  I5   ·
EX      ·   ·  I1  I2  I3  I4  I5
MEM     ·   ·   ·  I1  I2  I3  I4
WB      ·   ·   ·   ·  I1  I2  I3
```

### 4.2 流水线失效（stall）

这里的「失效」指**停顿**：某段该干活的那一拍干了空转，图上表现为空格（气泡）。它不影响正确性，只折损性能——与硬件故障无关，别混。

定量很干脆：**一个气泡 $=$ 一个 $\tau$**。

$$T=(n-1)\tau+\sum s_i+b\tau,\qquad b=\text{气泡数}$$

于是三类冒险的全部差别，只在「$b$ 是几」和「这个 $b$ 能不能被转发/预测消掉」。

### 4.3 三类冒险：判据、代价、解法

**结构冒险（资源冲突）**：两个段同一拍要同一个部件。

| 典型冲突 | 处理 | 剩余代价 |
|---|---|---|
| IF 取指 vs MEM 访存（单存储器） | I-Cache / D-Cache 分离；或停顿一拍 | 分离后 0；否则 1 拍 |
| 寄存器堆单写口却要写两个 | 加写口；或串行化 | 1 拍 |
| 单总线机器 | 加总线；或分时 | 每冲突 1 拍 |

**数据冒险（RAW 为主）**：后指令要读的寄存器正好在前指令的目的里。

| 指令对 | 需要的解 | 代价 |
|---|---|---|
| ALU → ALU（相邻） | **转发**（EX/MEM 或 MEM/WB 的值旁路到 ALU 入口） | 0 拍 |
| load → 紧接着用 | 转发救不了（数据在 MEM 末才出），**必须停 1 拍**，再转发 | 1 拍 |
| ALU → store 的数据口 | 转发到 MEM 段入口 | 0 拍 |

其他手段：**编译调度**（把无关指令插进空档，零硬件成本但要编译器看得见冒险）、**寄存器重命名**（消除名相关 WAR/WAW，乱序执行才需要）。

> 转发在图上就是几根「往回走的线」：从 EX/MEM 锁存器、MEM/WB 锁存器引到 ALU 的两个入口 MUX——这正是 [[数据通路-读图与填空]] §1.1 里 MUX 的典型用途。

**控制冒险（分支）**：取指时还不知道往哪走，已取进的指令可能作废。

| 判据在何时得出 | 要清掉几条 | 处理 |
|---|---|---|
| **ID** 段（提前比较 + 目标地址在 ID 算） | 1 条 | 停顿 1 拍 |
| **EX** 段（常规） | 2 条 | 停顿 2 拍 |
| 有**预测**且猜对 | 0 条 | 静态（总跳/总不跳）或动态（历史表） |
| 有**延迟槽** | 0 条（缺口填有用指令） | 编译器排一条必执行指令 |

三类的共同结构：**检测时机越早，代价越小**——因为可以少清几条。所以「把比较器挪到 ID 段」「把目标地址加法器挪到 ID 段」这类改造题，答案永远是「省一拍」。

它们在时空图上各自留下不同的痕迹：

| 冒险 | 图上的样子 | 为什么是这个样子 |
|---|---|---|
| 结构 | 某行出现**本不该空的格** | 部件被别的段占着，本段只能空 |
| 数据（未转发） | EX 之后插一段空格 | 等前一条写回、或等 MEM 段出数 |
| 数据（已转发） | 格子对齐、无空格，但多一条**往回走的线** | 值走旁路，不经过锁存器 |
| 控制 | IF 段整段空格 | 已取的指令作废，取指停摆 |

一张时空图能同时回答「停了几拍」和「停在哪一段」——所以这类题先画图再算指标，比先套公式可靠。

## 5. 超标量与超流水（两个方向，两套图）

| 形态 | 做法 | 图上变化 | 对 $S$ 的影响 |
|---|---|---|---|
| 超标量 | 每拍发多条指令 | 一行内每拍多个格子（多条通道） | 理想 $S\to m\cdot k$（$m$ 条/拍） |
| 超流水 | 段切得更细，$\tau$ 更小 | 列变窄、行变多 | 峰值 $TP$ 提高，但锁存开销占比升 |
| 动态调度 | 乱序执行 | 对角线被打断又接上 | 分析题不要求算，只考概念 |

## 6. 七条易错

1. **非均匀段乘 $k$**：正确是 $\sum s_i$，不是 $k\cdot\max s_i$。
2. **效率分母写错**：$E=S/k$，不是 $S/n$ 或 $T_{\text{串行}}/T$。
3. **加速比当成无界**：上界是 $k$（超标量 $m\cdot k$），且 $n$ 很小时远达不到。
4. **气泡忽略不计**：停顿拍直接进 $T$；「转发后省几拍」就是气泡数。
5. **锁存器漏加**：题给「段执行 $+$ 锁存」时 $\tau$ 是两者之和，漏加会让 $S$ 虚高。
6. **吞吐率与 $TP_{\max}$ 混**：$n/T$ 是实测，$1/\tau$ 才是峰值。
7. **以为转发万能**：`load` 后紧接着用，转发也省不掉那 1 拍——数据在 MEM 段末才出，必须停。
