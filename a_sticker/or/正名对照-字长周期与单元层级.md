# 正名对照：字长 · 周期 · 单元层级（元参考）

> **原材料（or/）**：把计组与 OS 里成族的名字摆在一起对照——同一族内谁大谁小、由谁定、怎么换算。**元参考**：不新增考点，只消掉「同名不同物、同物不同名」。单点错答原文见 [[标准错误答案清单]]；存储元那一族见 [[存储芯片-位拓展字拓展与交叉编址]] §8。
> 一句话：**正名不是背定义，是先分坐标系**——器件、CPU、OS 三套坐标里，同一个「字」「周期」指的不是一个量。

## 0. 三问正名（对所有族通用）

| 问 | 为什么先问它 | 例子 |
|---|---|---|
| 谁定的？ | 决定它随什么变 | 存储字长随**编址方式**变；机器字长随 CPU 微架构变；页大小随 OS 变 |
| 起止点在哪？ | 周期类的唯一判据 | 存取时间到「数据稳定」，存取周期到「可再次启动」 |
| 与相邻量的换算？ | 是否整数倍、是否含恢复时间 | 机器周期 = k × 时钟周期；存取周期 = 存取时间 + 恢复时间 |

凡是正名题，答不出这三问中的任何一问，名字就是猜的。

## 1. 字长族：四个「字长」加两个「宽度」

| 名 | 定义 | 由谁定 | 与其他量 | 常见越界 |
|---|---|---|---|---|
| **机器字长** | CPU 一次整数运算的位数（寄存器 / ALU 宽度） | CPU 微架构 | 常 = 数据线宽；可 = 存储字长的整数倍 | 被当成「存储单元宽度」 |
| **存储字长** | 一个存储单元的位数 = **编址单位宽度** | 编址方式 | 按字节编址 → 8 | 被当成固定值（其实由编址方式决定） |
| **指令字长** | 一条机器指令的位数 | 指令集 | 常 = 机器字长，也可为其 1/2 或 2 倍 | 与「机器字长」混 |
| **数据字长** | 一次数据传送的位数（数据线根数） | 总线 / 接口 | 决定一次访存取几个存储单元 | 与机器字长混（可不等） |
| **地址宽度** | 地址线根数 $n$ | 存储器 / MMU | 地址空间 $=2^n$ **个单元**，不是 $2^n$ 字节 | 「32 位地址 = 4 GB」只在按字节编址时成立 |
| **总线宽度** | 数据线根数 | 总线规范 | 与地址线根数无关 | 把「32 位总线」理解成地址也 32 位 |

由这张表推出的两条换算：

- 一次访存取几个存储单元 = 数据线宽 ÷ 存储字长（常写成 机器字长 ÷ 存储字长）。
- 指令字长 ÷ 存储字长 = 一条指令占几个存储单元；指令字长 ÷ 字节 = 一条指令几个字节。

「字」单独出现就是歧义词——必须带定语（机器字 / 存储字 / 指令字 / 数据字），否则这句话不可判对错。

## 2. 周期族：五个周期，起止点各不相同

| 名 | 起止 | 谁定 | 与相邻量 | 典型考点 |
|---|---|---|---|---|
| **时钟周期** $T_{clk}$ | 一个主频周期（$=1/f$） | 主频 | 最小计时单位；= 节拍 | 与机器周期换算 |
| **机器周期 / CPU 周期** | 完成一个基本操作（取指、访存、执行一步） | 微架构 | $=k\times T_{clk}$ | 指令周期的组成部分 |
| **指令周期** | 取指 → 间址 → 执行 →（中断），一条指令走完 | 指令集 | $=\sum$ 机器周期 | 各类指令周期长短不同的原因 |
| **总线（传输）周期** $\tau$ | 一次总线传送：地址期 + 数据期 | 总线 | 决定低位交叉的吞吐 | 交叉编址公式里的 $\tau$ |
| **存取时间** $T_a$ | 给出地址 → 数据稳定 | 存储器器件 | $<T_m$ | 「存取时间」单独出现时只算一次 |
| **存取周期** $T_m$ | 一次访问开始 → **可再次启动** | 器件 + 恢复时间 | $=T_a+$ 恢复时间 | 交叉编址公式里的 $T$ |
| **刷新周期** | 两次刷新的间隔 | DRAM 规格（教材常取 2 ms，题面为准） | 与存取周期无关 | 刷新开销计算 |
| **磁盘：寻道 / 旋转延迟 / 传输** | 移臂 / 等扇区转到 / 读扇区 | 机械结构 | 平均旋转延迟 = 半圈时间 | 平均访问时间三项相加 |

三条最容易错的边界：

1. **存取时间 ≠ 存取周期**：后者多一段恢复时间，所以「存取周期 ≥ 存取时间」恒成立，等号只在理想题设里出现。
2. **机器周期 ≠ 时钟周期**：前者是「完成一个基本操作」，后者是节拍；一条指令的机器周期数随指令变，时钟周期数还要乘 $k$。
3. **低位交叉的 $T$ 是存取周期、$\tau$ 是总线周期**：$T=m\tau$ 是「一体的恢复期正好够 $\tau$ 转一圈」，写成 $T=m\times$ 时钟周期就错。

## 3. 单元层级族：四条链，四种切分依据

| 链 | 从小到大 | 切分依据 | 谁定 |
|---|---|---|---|
| 存储（物理） | 存储元（1 位）→ 存储单元（1 个地址）→ 存储体 | 编址方式与阵列组织 | 器件 + 编址 |
| 编址（软件可见） | 位 → 字节 → 存储字 → 块 / 页 | 谁需要这个粒度 | 硬件 / OS |
| 存储介质 | 扇区 → 簇 → 分区 → 盘 | 物理结构 → 文件系统 → 管理 | 磁盘 / FS |
| 指令（执行） | 微指令 → 机器指令 → 程序 | 控制层 → ISA 层 → 程序层 | 微架构 / 编译器 |

四条链之间的对应关系只有两句话：

- **越靠「物理」的链，等长越严格**（存储元 1 位、扇区 512 B/4 KB 都是硬约定）；越靠「软件」的链越可变（簇、页、段）。
- **跨链时只有整数倍才等长**：页 = 整数个块，块 = 整数个扇区；否则要拼接，就产生碎片（段的变长正是外部碎片的来源）。

粒度对照速查：

| 单位 | 量级 | 由谁定 | 失效时谁处理 |
|---|---|---|---|
| Cache 块 | 几十字节 | 硬件 | 硬件 |
| 页 | 4 KB 级 | OS | OS（缺页） |
| 段 | 变长 | 程序 / 编译器 | OS（越界/缺段） |
| 磁盘扇区 | 512 B / 4 KB | 磁盘规范 | 控制器 |
| 文件系统块 / 簇 | 数个扇区 | 文件系统 | FS |

## 4. 速率族：四个「快」不是一个量

| 名 | 单位 | 公式 | 别与谁混 |
|---|---|---|---|
| **主频** | Hz | $=1/T_{clk}$ | 不等于性能；CPI 差的主频无用 |
| **CPI** | 周期/指令 | — | 与「每周期指令数 IPC」互为倒数 |
| **MIPS** | 百万指令/秒 | $f/(\mathrm{CPI}\times10^6)$ | 不同 ISA 之间不可比 |
| **总线带宽** | B/s 或 bit/s | 宽度 × 传输频率 | 与「存储器带宽」混 |
| **存储器带宽** | B/s | 数据宽度 ÷ 存取周期 | 低位交叉提高的正是它 |
| **加速比** | 倍 | 顺序时间 ÷ 流水时间，理想上界 = 段数 $k$ | 与「吞吐率提高倍数」混 |
| **执行时间** | s | 指令数 × CPI × $T_{clk}$ | — |

一条口诀够用：**主频是节拍，CPI 是每条的拍数，MIPS 是每秒几条，带宽是每秒几位**。四者互相推不出来，除非另外两项给定。
