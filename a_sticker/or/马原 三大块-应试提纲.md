# 马原 三大块 · 应试提纲

> **原材料（or/）**：仿 [[习思想 总纲骨架-应试提纲]] 的反向骨架，按三大块（哲学 / 政治经济学 / 科学社会主义）立格，不按教材章序分。格名只做检索键，卷面写官方术语。
> **口径**：格位是材料侧的坐标系，不是答案骨架；答案骨架仍是 🅰「是什么 → 为什么 → 怎么办」（[[政治背诵方法论]] §4.1）。马原首动作是**定位原理名**，不是套 🅰（[[政治背诵方法论]] §4 主表）。
> **证据级别**：`官方·`＝经典原著 / 教材定论；`二手·`＝教辅口径；`待核·`＝未回原文，不得当判据。未标级别按 `二手·` 读。
> **红线**：口诀不上卷；条文不改字；马原答题先写原理名，再展开，再落材料。

## 0. 这套提纲在整卷里的位置

- 马原是第 34 题与客观题的原理库；它不跟习思想的 0–17 编号走，单独一套坐标系。
- 三大块不是并列三章，是**同一套世界观的三次展开**：哲学给方法，政经给资本主义的解剖，科社给结论。
- 块内格序＝答题时的检索顺序：先判块，再判格，再取原理名。

## 1. 三大块与总格序

| 块 | 格数 | 格序（检索键） | 本块一句话 |
|---|---|---|---|
| 导论 | 1 | 0 马克思主义总论 | 三个组成部分、三个来源、两个「最」 |
| 哲学 | 6 | 辩证唯物主义 → 物质与意识 → 矛盾 → 普遍联系 → 实践与认识 → 历史唯物主义 | 世界是什么、怎么发展、怎么认识、社会怎么动 |
| 政治经济学 | 5 | 商品与价值规律 → 资本与剩余价值 → 资本循环与周转 → 平均利润与垄断 → 资本主义历史趋势 | 商品→货币→资本→剩余价值→趋势 |
| 科学社会主义 | 2 | 社会主义的发展及规律 → 共产主义 | 两大发现、基本特征、两个必然 |

**块序不能换**：哲学 → 政经 → 科社 是「方法 → 解剖 → 结论」；把科社放前面，答题会先给结论后补论证。

## 5. 词对（马原侧）

| A | B | 判据 |
|---|---|---|
| 使用价值 | 价值 | 一个管有用性，一个管人类劳动凝结；商品是二者的统一 |
| 具体劳动 | 抽象劳动 | 一个创造使用价值，一个形成价值 |
| 不变资本 | 可变资本 | 一个只转移价值，一个带来剩余价值 |
| 绝对剩余价值 | 相对剩余价值 | 一个延长工作日，一个缩短必要劳动时间 |
| 固定资本 | 流动资本 | 一个价值逐次转移，一个一次转移 |
| 社会必要劳动时间 | 个别劳动时间 | 一个决定价值量，一个决定盈亏 |
| 生产力 | 生产关系 | 一个管人与自然，一个管人与人 |
| 经济基础 | 上层建筑 | 一个管生产关系总和，一个管政治与观念 |
| 社会存在 | 社会意识 | 一个决定，一个反作用 |
| 真理的绝对性 | 真理的相对性 | 一个管客观性与无限性，一个管条件性与近似性 |
| 两个必然 | 两个决不会 | 一个讲趋势，一个讲条件与长期性 |
| 空想社会主义 | 科学社会主义 | 一个靠道德设想，一个靠两大发现 |

## 6. 出口与自测

- 出口：合书默三大块与 14 格；任给设问 5 秒内说出「块—格—原理名」。
- 自测 1：默三大规律、五对范畴、货币五职能、资本三阶段两条件。
- 自测 2：默词对表，每组说一句判据。
- 自测 3：给一段材料，先写原理名，再展开，再落材料句；缺任一段判负。
- 自测 4：给「为什么能 / 为什么必然」，走哲学依据还是政经依据，二选一，并说明为什么不走另一块。
