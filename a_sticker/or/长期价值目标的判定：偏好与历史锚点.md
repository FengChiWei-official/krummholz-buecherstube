## 一、三个偏好（抽象代号）

| 代号 | 偏好 | 定义 |

| **偏好 B** | 底层与通用技能的复利偏好 | 选不随工具更替而贬值的能力（数学、系统、算法），而非工具链专长 |

**A 与 B 的张力**：A 的最优解是应用型、易发文、单卡可完成的方向；B 的最优解是底层数学或系统方向。当前执行中的函数是 A——即「先拿到确定性产出，再谈长期价值」。

## 五、判定

| 命题 | 判定 |
|---|---|
| 「继续深造 → 提出架构级方法（Transformer / Mamba / 残差 / 流形假设 / ReAct 级）」按字面表述 | **不成立** |
| 「继续深造 → 进入研究轨道，产出可积累、可验证、有复利的中等成果」 | **有条件成立** |
| 「继续深造」这一动作本身是否合理 | **成立**（它是当前处境下能拿到产出链与训练的最短路径） |

**不成立的理由**：决定成果上限的不是年限（锚点里的 4–13 年区间并不荒谬），而是**位置**——算力、顶会产出链、博士训练三件套；基率显示这个位置不会随时间自然获得（学术界占比已降到约 10%，而 >95% 的顶尖研究者在最初 5 年内就已进入优势环境）。

**有条件成立的条件与可观测判据**

| # | 条件 | 判据 |
|---|---|---|
| C1 | 进「有真实产出链」的组，而不是「好毕业」的组 | 导师近 2 年 ≥2 篇 CCF-A/中科院 1 区，且组内 ≥1 名在读生的论文能读懂并复现 |
| C2 | 把目标函数从「发明级成果」改为「可积累的中间产物」 | 毕业前：≥1 篇可复现工作 + 1 个公开代码库 + 1 页「下一步问题清单」；三年拿不出则字面目标自动作废 |
| C3 | 补一次完整研究闭环 | 入学前独立完成一次「读论文 → 复现 → 改动 → 写作」并留下产物 |
| C4 | 算力现实性硬筛 | 代表性论文若需 >8 卡训练，则该方向从「发明级清单」中划掉（可替代：量化、推理侧、模型压缩、底层视觉、小模型系统） |
| C5 | 解决「独学而无友」 | ≥2 名可长期交流的同侪 + 1 个定期 review 的外部关系；判据：近 3 个月有过一次互看代码/推导 |
| C6 | 保留一条不依赖平台的能力线 | 数学纵深（微分几何/优化/概率任一条，≥30 张自己的卡）或系统线（读通 vLLM/DeepSpeed 源码并写复现实验）之一做到可展示 |

**一句话结论**：年限不是瓶颈，位置是。若 C1、C4 不满足（大概率），字面目标作废，但 C2+C6 仍成立——即「拿到研究/工程能力与一个可展示的产物」这条路可靠，而「提出架构级方法」需要的算力与产出链位置，不是靠更多努力单独能买到的变量。
