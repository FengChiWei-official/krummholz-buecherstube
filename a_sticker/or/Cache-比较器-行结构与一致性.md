# Cache-比较器-行结构与一致性

> 暂存稿（`a_sticker/or/`）。用途：补上 [[Cache-TLB-页替换-同构与分界]] 缺的那一层——那篇讲**三张表的对照**，本篇讲**一台 cache 的硬件长相**：比较器到底比较什么、一行里存了什么、三种映射怎么变成同一个参数的两个端点、替换位住在哪、多核时多出来的那个字段（一致性状态）在防什么。
> 状态：**只讲不写**。口径：[[计算机组成考纲]] 第三章「六、Cache」与第五章「七、多处理器的基本概念」（408 只到概念级，MESI 是实现细节）。

## 〇 结论先行

1. **比较器 = 一个等值判断电路**：输入是「地址的 tag 字段」与「行里的 tag」，输出 1 位「相等」。它不做减法、没有进位链——判断相等不需要知道大小。
2. **命中 $=E\wedge V$**：比较器只回答「这一路像不像」，有效位才回答「这一行算不算数」。比较器个数由**路数**定，不由组数定。
3. **一行 = 有效位 + tag + 数据块 + 脏位 + 替换信息（+ 一致性状态位）**。前四样是 408 必算，后两样随写策略与多核才出现。
4. **直接映射、组相联、全相联是同一参数空间的两个端点**：组数 $=1$ → 全相联；路数 $=1$ → 直接映射。区别只在**并行比较几份候选**——这正好是上一篇 [[并行技术-通用性质与各自的指标口径]] 的「并行度换灵活性」。
5. **替换只在组内选，只影响冲突 miss**；**一致性不改变查表，只改变「谁能写」**——两者与比较器无关，别混在同一张图里。
6. **写策略是两个正交开关**：写命中 → 全写 / **写回（默认）**；写未命中 → **写分配（默认）** / 非写分配。默认配对「写回 $+$ 写分配」，另一对默认「全写 $+$ 非写分配」（§5）。

## 一 比较器：cache 里唯一在做判断的部件

### 1.1 是什么

一个 $t$ 位**等值比较器**：逐位同或（XNOR）再全部相与（AND 树），输出 1 位。

```
 addr_tag[t-1..0] ──┬─[XNOR]──┐
                    │         ├─[AND]─ ... ─[AND]──> E (相等)
 line_tag[t-1..0] ──┴─[XNOR]──┘
```

| 项 | 值 |
|---|---|
| 输入 A | CPU 地址的 **tag 字段**（$t$ 位，同一组内所有路**共用一份**） |
| 输入 B | 该**行 tag 存储**的输出（$t$ 位，每行一套） |
| 输出 | 1 位相等信号 $E$ |
| 宽度 | $t$ = tag 位数 $=$ 地址位 $-$ 组号位 $-$ 块内偏移位 |
| 同频 | 所有路**同时**比，故命中判定与路数无关 |
| 成本 | $t$ 个 XNOR $+\ O(t)$ 个 AND；面积 $\propto$ 路数 $\times t$ |

**它不是减法器**：ALU 比大小要先做减法再看符号/零标志，减法有 $O(t)$ 的进位链；等值判断无进位传播，纯组合，所以便宜且快。这也是 tag 用等值比较、不用「相减取零」的原因。

### 1.2 输出接到哪：一次命中的完整通路

```
              ┌── CMP_0 ── E_0 ─┐
 组号 ─> 组内 │── CMP_1 ── E_1 ─┤  E_i ∧ V_i ─> OR ──> HIT
 选组    n 路 │      ...        │      │
              └── CMP_{n-1} ────┘      └─> 编码器 ─> 路号 ─> 多路选择器 ─> 数据
```

三个下游各要一样东西：

| 下游 | 要什么 | 由什么给 |
|---|---|---|
| 命中信号 | 有没有一路「tag 相等且 $V=1$」 | 各路 $E_i\wedge V_i$ 取或 |
| 数据通路 | 取哪一路的块 | 编码器把命中向量转成路号，送 $n$ 选 1 MUX |
| 替换逻辑 | 若要换，换谁 | 与命中无关，见 §4 |

**比较器个数**（本组最常错，见 [[标准错误答案清单]] §三章）：

| 映射 | 同时比较的个数（每组） | 全 Cache 物理个数 |
|---|---|---|
| 直接映射 | 1 | 行数 $=$ 组数 |
| $n$ 路组相联 | $n$ | 行数 $=$ 组数 $\times n$ |
| 全相联 | 行数 | 行数（$=$ 组数 $\times$ 路数，组数 $=1$） |

教材说「比较器个数 = 路数」，指**同一次访问里并行工作的那 $n$ 个**；物理上每个行各有一套（tag 存储也是每行一套），所以总数恒等于行数。两个极端互校：直接映射 1 个/组、全相联「组数 $=1$ 所以路数 $=$ 行数」。

### 1.3 为什么可以「同时比」

tag 存储是**每行独立**的一小块 SRAM/寄存器，读出互不干扰；比较器是纯组合逻辑。所以 $n$ 路相联的命中判定延迟几乎不随 $n$ 涨——增加的是**面积、功耗与后面的选择逻辑**（编码器 + MUX）。

这就是组相联存在的理由：用面积换「同一组内多个块共存」，把直接映射的冲突 miss 压下去，而**不把命中延迟拉长**。收益在 8 路附近饱和，正是面积/冲突两条曲线的交点。

## 二 一行里到底存了什么

```
┌───┬─────────┬──────────────────────┬───┬──────────────┬────────────┐
│ V │  tag t  │  数据块 B 字节（8B 位）│ D │ LRU / 替换位  │ 一致性状态  │
└───┴─────────┴──────────────────────┴───┴──────────────┴────────────┘
 1 位   算出来        块大小 × 8          1 位   每组一份/每行一份   2 位
```

| 字段 | 何时存在 | 谁读写 | 作用 |
|---|---|---|---|
| **V 有效位** | 恒有 | 装入置 1，失效清 0 | 上电后行内容是随机残留，只有装过的行才算数 |
| **tag** | 恒有 | 装入时写 | 与地址 tag 比较；宽度 = 地址位 $-$ 组号位 $-$ 块内偏移位 |
| **数据块** | 恒有 | 装入/写命中 | 本体，宽度 = 块大小（408 常 64 B） |
| **D 脏位** | **只有写回**（§5） | 写命中置 1，换出清 0 | 换出时决定要不要写主存；**不参与命中判断** |
| **替换信息** | 路数 $>1$ | 每次命中/装入 | 计数器：每行 $\lceil\log_2 n\rceil$ 位；CLOCK：每行 1 位 $+$ 组内指针 |
| **一致性状态** | 仅多核（MESI） | 本核访问 $+$ 总线事务 | M/E/S/I，见 §6 |

### 2.1 容量题的唯一算法

$$\text{行数}=\frac{\text{数据容量}}{\text{块大小}},\qquad
\text{tag 位}=A-\log_2(\text{组数})-\log_2(\text{块大小})$$

$$\text{总位数}=\text{行数}\times(\underbrace{8B}_{\text{数据}}+\underbrace{t}_{\text{tag}}+\underbrace{1}_{V}+\underbrace{1}_{D})+\underbrace{\text{组数}\times n\lceil\log_2 n\rceil}_{\text{LRU 计数}}$$

反推必用：$\text{组数}=\text{行数}/\text{路数}$。题面给「Cache 32 KB」通常指**数据**容量；问「共多少位」才把 tag、V、D 加上。算例：32 位地址、64 B 块、4 路、32 KB → 512 行、128 组（组号 7 位）、块内偏移 6 位、tag $32-7-6=19$ 位、LRU 每组 $4\times2=8$ 位。

## 三 三种映射：一个参数，两个端点

同一条地址，三种切法只差「组号」那一段有多宽：

| 映射 | 地址切分 | 组数 | 路数 | 比较器/组 | 硬件代价 |
|---|---|---|---|---|---|
| 直接映射 | `tag │ 行号 │ 块内偏移` | $=$ 行数 | 1 | 1 | 最省：无选择器、无替换逻辑 |
| $n$ 路组相联 | `tag │ 组号 │ 块内偏移` | 行数$/n$ | $n$ | $n$ | 中：$n$ 比较器 $+$ $n$ 选 1 |
| 全相联 | `tag │ 块内偏移` | 1 | $=$ 行数 | 行数 | 最贵：行数个比较器，无组号译码 |

**判据**：组号位数 $=\log_2(\text{组数})$；组数 $=1$ 时该段消失 → 全相联；路数 $=1$ 时组数 $=$ 行数 → 直接映射。所以三者不是三个设计，是**一个设计的三个刻度**——固定行数，把「组数 $\times$ 路数」在两端之间挪。

### 3.1 映射方式改变的是哪种 miss

| miss 类型 | 来源 | 哪种映射能减 |
|---|---|---|
| 强制（compulsory） | 块第一次被访问 | 都不能（只能预取） |
| 容量（capacity） | 工作集 $>$ cache | 都不能（只能加容量） |
| 冲突（conflict） | 几个块映射到同一位置 | **提高相联度**（直接 → 组相联 → 全相联） |

这张表是「为什么要有组相联」的全部答案，也是判断题「加大相联度能否提高命中率」的判据：**只有当 miss 里含冲突成分时才有用**；纯容量型程序加相联度一点不动。全相联没有冲突 miss，代价是行数个比较器与无法索引（只能全表并行比）。

## 四 替换：只在组内选，只花在冲突上

| 策略 | 每行/每组开销 | 精确度 | 场地 |
|---|---|---|---|
| 直接映射 | 0 位（无选择） | — | 无 |
| FIFO | 指针/队列 | 不看访问 | 便宜 |
| LRU 计数器 | 每行 $\lceil\log_2 n\rceil$ 位 | **近似**（饱和后无法区分同老的行） | 主流 |
| LRU 栈式 | 每组 $\lceil\log_2(n!)\rceil$ 位 | 精确 | 理论/仿真 |
| CLOCK | 每行 1 位 $+$ $\log_2 n$ 位指针 | 近似，实现最省 | 大相联度 |

三条不变量：

1. **只在组内选**：组号只负责选中一组，替换是局部决定；位宽由路数定，组数只进总量的乘法。
2. **只在 $V=1$ 里选**：空行直接占用，不触发替换。
3. **只在冲突 miss 上有效**：强制/容量 miss 换谁都一样——所以「换 LRU 能不能提高命中率」先问 miss 构成。

$$\text{AMAT}=t_{\text{hit}}+m\times T_{\text{miss}},\qquad
\text{多级：}\ AMAT=t_1+m_1\,(t_2+m_2\,T_{\text{mem}})$$

写策略是**另一组两个开关**，与替换并列但互不推导，见 §5。

## 五 写策略：命中与未命中各一次二选一

写一个字节要回答两个**互不蕴含**的问题：命中时改哪里、未命中时块进不进来。四个名字就在这两个格子里。

### 5.1 两个开关

| 场合 | 二选一 | 默认 | 动作 | 代价 |
|---|---|---|---|---|
| **写命中** | **全写**（写直达, write-through） | | cache 与主存同拍写，配**写缓冲**藏等待 | 每次写都占总线；主存恒新 |
| 写命中 | **写回**（write-back） | ✔ | 只改 cache、置脏位 $D$，换出时才写主存 | 主存可能旧；换出时多一次写 |
| **写未命中** | **写分配**（write-allocate） | ✔ | 先调入整块再写（写 miss 退化成一次读 miss） | 为写几个字节读入一整块 |
| 写未命中 | **非写分配**（no-write-allocate） | | 不进 cache，直接写主存 | 后续对同块的写还得再上总线 |

**默认口径**：题面不特别说明就按「写回 $+$ 写分配」算——脏位存在、换出要写回、写 miss 先取块再写。「全写 $+$ 非写分配」是另一对默认，成对出现的理由见 5.2。

### 5.2 为什么这样配对

| 配对 | 共同点 | 买到什么 | 408 场合 |
|---|---|---|---|
| **写回 $+$ 写分配** | 都「延迟到必要时」：写回把主存写推迟到换出，写分配把块调入以便后续写命中同一块 | 一块改多次只写主存一次 | 主流题面：问脏位、问写回次数、问总位数 |
| **全写 $+$ 非写分配** | 都「不占 cache、不留延迟」 | 主存恒新、无 $D$ 位、无换出写回 | 写直达题、DMA、简单嵌入式 |

交叉配对合法但少见：全写 $+$ 写分配 = 每次写都上总线还要调块（流量最大，只适合「写完还要接着读」的块）；写回 $+$ 非写分配 = 写 miss 直接写主存而 cache 里没有这块（块确实不在时才安全，需额外确认）。

### 5.3 三条常考结论

1. **$D$ 位只属于写回**：全写法下主存恒新，不需要脏位——这是 §2 行结构里 $D$ 标「只有写回」的原因。
2. **写缓冲不改变写次数**：它只把「等主存」的时间藏起来；全写仍是每次写都写主存。把写缓冲当写回，是把「藏延迟」误读成「减流量」。
3. **写 miss 的代价随开关变**：写分配下一次写 miss $=$ 一次读 miss 的代价 $+$ 写命中；非写分配下 $=$ 一次主存写，且不占 cache 行（流式写、`memset` 这类一次性写因此更适合非写分配）。

$$写回法写主存次数=\text{脏块换出次数},\qquad 全写法写主存次数=\text{写次数}$$

判据：**写回与全写之差只在「主存何时变新」；写分配与非写分配之差只在「写 miss 时块进不进来」**——两个开关正交，「写回 $+$ 写分配」不是同义反复。

衔接 §6：写回 $+$ 监听的一致性协议必须靠显式总线事务（BusRd/BusRdX）才让写可见；全写 $+$ 非写分配让每次写都上总线，监听者顺手失效，一致性天然成立但流量大。

## 六 一致性：多核时多出来的那个字段

### 6.1 问题从哪来

单核时 cache 是主存的**只读副本 $+$ 延迟写回**，一致性由单点保证。多核共享内存后，同一物理地址在每个核的私有 cache 里各有一份副本——**一核写，别的核的副本就成了旧值**。这不是映射或替换的问题：查表逻辑完全正确，错在「写没有被所有副本看见」。

两个层面必须分开：

| | 管什么 | 粒度 | 408 |
|---|---|---|---|
| **一致性 coherence** | 单个地址：读必须看到最近一次写；写对所有核有序 | 一个地址（实际按**行**实现） | 概念级 |
| **一致性模型 consistency** | 不同地址之间，全局观察顺序（SC / TSO / 弱序） | 整个内存 | 不考 |

### 6.2 两条实现路线

| | 监听（snooping） | 目录（directory） |
|---|---|---|
| 记账在哪 | 无中心表；每个 cache 监听总线所有事务 | 集中目录：每行记「谁有副本」 |
| 通信 | 广播，$O(N)$ 流量 | 点对点，按目录查 |
| 适用 | 小规模 SMP（核少、总线） | 大规模（NUMA、众核） |
| 408 | SMP 的默认模型 | 概念提及 |

监听能成立的前提是**总线是广播介质**——这与 §1 的比较器是同一个思路的放大：单机里「并行比所有候选」，多机里「并行听所有事务」。

### 6.3 MESI：四个状态就是两个问题

状态 = (本核有没有独占权, 数据脏不脏)：

| 状态 | 含义 | 内存里的值 |
|---|---|---|
| **M** 修改 | 只有我有，且已改 | 旧（脏） |
| **E** 独占 | 只有我有，未改 | 同 |
| **S** 共享 | 多核都有，未改 | 同 |
| **I** 无效 | 我这份不算数 | — |

| 当前 | CPU 读 | CPU 写 | 听见 BusRd | 听见 BusRdX |
|---|---|---|---|---|
| M | 命中 | 命中 | 写回 $\to$ S | 写回 $\to$ I |
| E | 命中 | 静默 $\to$ M | $\to$ S | $\to$ I |
| S | 命中 | BusUpgr $\to$ M | 不变 | $\to$ I |
| I | BusRd $\to$ S/E | BusRdX $\to$ M | 不变 | 不变 |

读四件事：**E 的存在是为了让「独占写」不必上总线**（静默升级）；**M 的写回发生在别人要读的那一刻**，不是换出时；**写直达也能做一致性**（每次写都上总线，别人顺手失效），只是流量大；**协议的一切动作都发生在 miss 或写共享行时**，命中不改状态——所以它不影响 §1 的比较器通路。

### 6.4 两条易错

1. **伪共享（false sharing）**：两个核写**同一行的不同变量**，逻辑上无共享，物理上按行失效 $\to$ 该行在两核间来回弹（ping-pong）。判据：**一致性粒度是行，不是变量**。这是「按行管理」的代价，与 §2 的行结构直接相关。
2. **TLB/页表侧的一致性**另一套：改页表后要 TLB shootdown（失效对应项）或靠 ASID 隔开进程；那是软件维护的一致性，与 cache 的硬件协议不是一件事。

## 七 一张计算口径表

| 要求 | 公式 | 易错点 |
|---|---|---|
| tag 位 | $A-\log_2(\text{组数})-\log_2(\text{块大小})$ | 用行数当组数 |
| 组数 | 行数 / 路数 | 「组的大小」与「组数」混 |
| 比较器 | 路数（并行）/ 行数（物理） | 用组数 |
| 块内偏移 | $\log_2(\text{块大小})$ | 与页内偏移（12 位）混 |
| LRU 位 | 每组 $n\lceil\log_2 n\rceil$ | 用组数乘 |
| 总位数 | 行数 $\times(8B+t+1+1)$ $+$ LRU | 漏 V/D |
| AMAT | $t_{\text{hit}}+m\,T_{\text{miss}}$ | 多级漏 $m_2$ |
| 写主存次数 | 写回：脏块换出次数；全写：写次数 | 把写缓冲当写回 |
| 相联度收益 | 只减冲突 miss | 当成万能的 |

## 八 五句可背的判据

1. **比较器比 tag，不比地址；比相等，不比大小。**
2. **命中 $=E\wedge V$；脏位只管换出，不管命中。**
3. **组数 $=1$ → 全相联；路数 $=1$ → 直接映射**——同一根刻度尺的两端。
4. **相联度买命中率（只买冲突那部分），一致性买正确性**——两笔账不通用。
5. **写回 $+$ 写分配是默认；写回/全写管「主存何时变新」，写分配/非写分配管「写 miss 时块进不进来」**——两个开关，四格都合法。
