## 0. 题面形态与地址算术（总纲）

[[x86_assembly_reading_tutorial]]


挂点：硬件层「取指/译码」工位 · 合同① ISA · 根张力「通用性」· 不变量 #5（表示先于电路）第 1 次实例化（指令编码 → 字段）

组织轴 = 合同① ISA 的定义面，不是「一条指令的一生」；后者只在 §13 当 20 分钟穿越 drill 用。
粒度：本节只收「读题需要的判据与语义」；Cache 映射方式、替换算法、地址位数留在章内其他笔记。
读法：先判题面形态（下表），再算地址/拆字段，最后才翻译语义；顺序反了会在细节里丢主线。

| 形态 | 真题 | 题面给什么 | 要你答什么 |
|---|---|---|---|
| 反汇编对照表 | 2023/44、2017/44、2019/45 | 行号 + 虚拟地址 + 机器码 + 汇编，四列对照 | 下一条地址、寻址方式、目标地址、变量含义、大小端、CISC/RISC |
| 自定义指令格式 | 2024/43 | 字段表（IR 位段）+ 数据通路 + 控制信号 | 字段宽度理由、ALUBsrc/Ext/ALUctr、补码地址、编码唯一性 |
| 概念选择 | 2016/12、2022/20、2025/17 | 一句定义或一组叙述 | 编译链哪一步、RISC 哪条说错、伪指令/微指令辨析 |

**地址推进只有一条公式**：按字节编址时

$$\text{addr}_{k+1}=\text{addr}_k+\text{len}(\text{machine code}_k)$$

三个「字长」必须在同一题里分开：

| 口径 | 定义 | 2024/43 | 2017/44 |
|---|---|---|---|
| 指令字长 | 一条指令的二进制位数 | 32 位定长 | 1–7 字节不等（8/16/24/56 位） |
| 机器字长 | CPU 一次整数运算的位宽 | 32 位 | 32 位 |
| 存储字长 | 一个存储单元的位数（常指 MDR 宽度） | 32 位 | 32 位 |

两个必须写死的演算：

- 2023/44 第 19 条从 `0040 10AEH` 起、机器码 11 字节 → 第 20 条 `0040 10AEH + 0BH = 0040 10B9H`。
- 2017/44 首条 `0040 1020H`、末条 `ret`（`C3`）在 `0040 107FH` → 长度 `0040 107FH − 0040 1020H + 1 = 0040 1080H − 0040 1020H = 60H = 96` 字节。

边界：题面若按字编址，地址增量要除以编址单位；若指令字长大于存储字长，一条指令跨多个存储字，取指要多个存储周期。三个字长可以相等，也可以不等，题面没写就按「按字节编址 + 指令字长如表中」处理。

## 1. 指令格式与字段

挂点：合同① ISA 的定义面 · 根张力「复用与代价」· 不变量 #5 第 2 次实例化（字段宽度 = 编码的代价预算）

2024/43 的字段表（原格式，逐位照抄）：

| 指令 | IR[31:25] | IR[24:20] | IR[19:15] | IR[14:12] | IR[11:7] | IR[6:0] | 功能 |
|---|---|---|---|---|---|---|---|
| `add` | `0000000` | `rs2` | `rs1` | `000` | `rd` | `0110011` | `R[rd] ← R[rs1] + R[rs2]` |
| `slli` | `0000000` | `shamt` | `rs1` | `010` | `rd` | `0010011` | `R[rd] ← R[rs1] << shamt` |
| `lw` | `imm[11:5]` | `imm[4:0]` | `rs1` | `010` | `rd` | `0000011` | `R[rd] ← M[R[rs1] + imm]` |

逐字段回答「为什么是这个宽度」：

- `rd`/`rs1`/`rs2` 各 5 位 → $2^5=32$ 个通用寄存器。4 位只有 16 个，寄存器分配不够用；6 位要 64 个，多出的位只能从操作码或立即数里抢。
- `shamt` 5 位 → 移位量 0–31，正好覆盖 32 位字的全部位置；6 位允许 32–63，对 32 位字无意义。
- `IR[6:0]` 7 位 → 128 个基本操作码；`IR[14:12]` 3 位 → 同一操作码下 8 个变体（`funct3`）。
- `IR[31:25]` 是**一段位、两种解释**：R 型当 `funct7`，`lw` 当 `imm[11:5]`。译码器先看 `opcode`，再决定这段位算哪类字段——这是「复用」在编码层的直接体现。

**操作码扩展（自造算例）**：定长 16 位指令字。

| 格式 | 划分 | 可表示指令数 |
|---|---|---|
| 三地址 | OP 4 位 + 3×4 位地址 | $2^4=16$ |
| 二地址 | OP 8 位 + 2×4 位地址 | $2^8=256$ |
| 一地址 | OP 12 位 + 4 位地址 | $2^{12}=4096$ |
| 零地址 | OP 16 位 | $2^{16}=65536$ |

地址码每少 1 位，操作码多 1 位，指令数翻倍、可寻址寄存器数减半；上表每次少一个 4 位地址字段，操作码多 4 位，指令数 ×16。这就是「操作码不够用」的标准解法：**用地址码的宽度换操作码的宽度**。

边界：扩展操作码要求前缀不冲突——短操作码不能是长操作码的前缀，否则译码器无法唯一判定；题面若同时给两种长度，必须检查前缀关系。

指令字长、存储字长与对齐的关系：

- 单字长指令 = 指令字长等于存储字长；双字长指令要占两个存储单元，取指两次。
- 指令地址不要求按指令字长对齐（按字节编址时），但很多 ISA 要求 4 字节对齐；RISC 的定长 32 位指令通常要求 4 字节对齐。
- PC 相对寻址时，「PC 已指向下一条」是 x86 的口径；有的教材定义 PC 指向当前指令。**看题面声明**，2023/44 与 2019/45 都按「下一条」算。

边界：定长 ≠ RISC，变长 ≠ CISC（见 §4）；对齐要求也可能只影响性能、不影响正确性（见 §3）。

## 2. 寻址方式

挂点：硬件层「译码/算 EA」工位 · 合同① ISA · 根张力「复用与代价」· 不变量 #1（一切运算归约为加法+移位：EA 就是加法）第 1 次实例化

| 方式 | 有效地址 / 操作数 | 取操作数访存次数 | 用途 | 408 常见问法 |
|---|---|---|---|---|
| 立即 | 操作数在指令里，无 EA | 0 | 常量、`a[i][j]=10` 的 10 | 「源操作数采用什么寻址方式」→ 立即 |
| 直接 | $EA=A$（地址字段就是地址） | 1 | 全局变量 | 地址字段宽度决定寻址范围 |
| 间接 | $EA=M[A]$ | 2 | 指针的指针 | 为什么慢：多一次访存 |
| 寄存器 | 操作数在寄存器 | 0 | 运算、传参 | 与寄存器间接区分：有没有再访存 |
| 寄存器间接 | $EA=R$ | 1 | 指针 `*p` | `[eax]` |
| 基址 | $EA=(BR)+A$ | 1 | 重定位、栈帧 | BR 由 OS 设，程序不改 |
| 变址 | $EA=(IX)+A$ | 1 | 数组、循环 | IX 由程序改 |
| 相对 | $EA=PC+A$ | 1 | 转移指令、位置无关码 | 目标 = 下一条 + 位移 |
| 基址变址 | $EA=(BR)+(IX)+A$ | 1 | 二维数组、结构体 | 2023/44 的 `[ecx+edx*4+00422000H]` |
| 堆栈 | $EA=(SP)$，SP 隐含 | 1 | `push`/`pop`、过程调用 | 操作数地址由 SP 隐含 |

两个 EA 模板：

```
x86:     EA = base + index*scale + disp      ; scale ∈ {1,2,4,8}
RISC:    EA = R[rs1] + sign_extend(imm)      ; 2024/43 的 lw
```

访存次数 → 执行阶段的链条：立即/寄存器（0 次）可在执行段直接进 ALU；寄存器间接/直接/基址/变址（1 次）要多一个「取操作数」段；间接（2 次）要两段。这就是「寻址方式多 → 执行阶段多 → CPI 高」的硬件来源（接 §11）。

2023/44 落地：

- 第 2 条 `jmp`（`EB 09`，地址 `0040 1079H`）与第 7 条 `jge`（`7D 32`，地址 `0040 1088H`）都是**相对寻址**。目标 = 下一条地址 + 位移：
  - `0040 1079H + 2 = 0040 107BH`，`0040 107BH + 9 = 0040 1084H`。
  - `0040 1088H + 2 = 0040 108AH`，`0040 108AH + 32H = 0040 10BCH`。
- 第 19 条 `mov [ecx+edx*4+00422000H], 0Ah`：目标操作数是**基址 + 变址×比例 + 偏移**；源操作数 `0Ah` 是**立即寻址**。`edx = j`，`ecx = i×64×4 = i×256`（行首字节偏移）；套 `a[i][j] = base + i×行字节数 + j×4`。

边界：`EA = base + index*scale + disp` 是 x86 的公式，RISC 的 `lw` 只有 `rs1 + imm`，没有 scale；题面给自定义指令系统时按题面的 EA 公式，不套 x86。访存次数不含取指；若题目问「执行一条指令共访存几次」，要把取指算进去。

## 3. 对齐与大小端

挂点：合同① ISA 的数据语义 · 根张力「复用与代价」· 不变量 #5 第 3 次实例化（表示先于电路：字节序与对齐是「选好的编码」，不是电路产物）

**大小端只认机器码字节序**，不认数值写法：

- 2023/44 第 19 条的 disp 字节是 `00 20 42 00`，读成 `0042 2000H` → 低字节在前 → **小端**。
- 若是大端，同样四个字节应写成 `00 42 20 00`；题面给 `00 20 42 00` 就是在说「低地址放低字节」。
- 2019/45 的 `call` 偏移字节 `D6 FF FF FF` 读成 `FFFFFFD6H = −2AH`，也是小端；大端会写成 `FF FF FF D6`。
- 数据的判据同理：`1234 5678H` 在小端机器上按地址递增是 `78 56 34 12`。

自然对齐与结构体填充：

| 类型 | 大小（32 位） | 自然对齐 | 说明 |
|---|---|---|---|
| `char` | 1 | 1 | 无填充 |
| `short` | 2 | 2 | 地址为偶数 |
| `int` / `float` | 4 | 4 | 地址为 4 的倍数 |
| `double` | 8 | 8（x86-64）/ 题面可能写 4 | 32 位 x86 的栈上对齐常放宽到 4，看题面 |
| 指针 | 4（32 位）/ 8（64 位） | 同大小 | 与机器字长绑定 |

结构体规则：成员按声明顺序放，每个成员放在「自身对齐」的倍数上；结构体总大小向上取到「最大成员对齐」的倍数。自造例子：

```c
struct T { short a; char b[5]; int c; };   // 自造
```

`a` 占 0–1；`b` 占 2–6；`c` 要对齐 4，跳过 7，占 8–11；总大小 12（已是 4 的倍数）。`sizeof(struct T) = 12`，其中 1 字节是填充。

- x86-64 System V：调用前 `rsp` 16 字节对齐，`call` 压入 8 字节返回地址后，被调用者入口 `rsp ≡ 8 (mod 16)`；编译器用 `sub rsp, 8` 之类的奇数调整补齐。
- RISC-V：非对齐的 `lw`/`sw` 可能触发异常（取决于执行环境）；408 题面默认「按边界对齐」。

边界：题面若声明「允许非对齐访问」，对齐只影响性能、不影响正确性；但默认口径是硬件要求（否则可能异常或由硬件拆成两次访问）。大小端只影响多字节数据的字节顺序，不影响字节内部的位顺序。

## 4. CISC / RISC

挂点：硬件层「控制器」工位 · 合同① ISA · 根张力「复用与代价」· 不变量 #3（控制即数据）第 1 次实例化（微程序 = 用小机器控制大机器）

| 判据 | CISC | RISC | 题面证据长什么样 |
|---|---|---|---|
| 指令长度 | 变长 | 定长（常见 32 位） | 同一段代码里 1/2/3/7 字节混排 vs 每条都 4 字节 |
| 格式规整度 | 多格式、字段位置随指令变 | 少量格式、字段位置固定 | 操作码/寄存器号是否总在同一段位 |
| 寻址方式数 | 多（十几种） | 少（寄存器、立即、基址+偏移为主） | 是否出现 `[base+index*4+disp]` 这类复杂 EA |
| 访存限制 | 任意指令可直接访存 | 只有 load/store 访存 | 是否出现 `add [mem], reg` |
| 通用寄存器数 | 较少（8/16） | 多（32 个以上） | 寄存器号字段是否 5 位 |
| 控制器 | 微程序为主 | 硬布线为主 | 题面是否提「微指令/控制存储器」 |
| 流水线友好度 | 较难 | 较易 | 定长 + 规整字段 → 译码和流水段对齐 |
| 指令条数与 CPI | 条数少、CPI 高 | 条数多、CPI 低（常为 1） | 题目问「同样功能谁的程序更长」 |

三真题判法（必须落到题面证据）：

- **2017/44 判 CISC**：机器码长度 1/2/3/7 字节不等（`55`、`D1 E2`、`39 4D F4`、`C7 45 F8 00 00 00 00`）；`cmp dword ptr [ebp-0Ch], ecx` 让运算指令直接读内存；格式不规整。三条证据分别指向「变长」「可访存」「多格式」。
- **2024/43 判 RISC**：32 位定长；`rs1`/`rs2`/`rd` 各 5 位 → 32 个寄存器；只有 `lw` 访存，`add`/`slli` 全在寄存器间；格式只有三种且字段位置固定。
- **2025/17 判 RISC 叙述**：题干问「关于 RISC 的叙述，错误的是」。错项的长相有两类：把 CISC 的特征套给 RISC（指令多、寻址方式多、指令变长、必用微程序），或把 RISC 的流水线友好性说反（「RISC 难以采用流水线」）。不背选项原文，按判据表逐条对。

考纲待解问题「装入/存储型指令有什么特点」的答题点：

1. 只有 load/store 能访存，运算指令全在寄存器之间；
2. 因此格式可以规整、定长，译码并行；
3. 访存延迟可被编译器调度到其他指令之后，流水线不必为每条指令都留访存段；
4. 代价是指令条数变多，`a = b + c` 要先 `lw` 两次再 `add` 再 `sw`。

边界：RISC 指令少 ≠ 程序短（RISC 程序通常更长）；「CISC 必微程序 / RISC 必硬布线」是教材口径，不作绝对断言；定长不能单独判 RISC（有的 CISC 也定长），要连「访存限制 + 寄存器数 + 格式数」一起看。

与库内定义对齐：`CISC` = 多、变长、可访存、靠微程序；`RISC` = 少、定长、寄存器到寄存器、可硬布线 + 流水线。判据表只是这两句的展开。

## 5. 指令语义（两套体系 + 辨析）

挂点：合同① ISA 的语义面 · 根张力「复用与代价」· 不变量 #1 第 2 次实例化（`shl`/`lea` 替乘加）、#3 第 2 次实例化（微指令展开）

### 5.1 表 A：x86 子集

| 指令 | 语义（一条 C 表达式） | 408 考点/陷阱 | 边界 |
|---|---|---|---|
| `mov dst, src` | `dst = src` | 不改标志；内存到内存非法 | 段/控制寄存器有专用 mov |
| `lea reg, [addr]` | `reg = EA` | **只算地址，不访存**；可做加乘 | 不读 `[addr]` 的内容 |
| `push src` | `esp -= 4; [esp] = src` | 改 `esp`，不改标志 | 64 位减 8 |
| `pop dst` | `dst = [esp]; esp += 4` | 与 push 对称 | 64 位加 8 |
| `xchg a, b` | 交换 | 内存操作数隐含锁 | 两个内存操作数非法 |
| `movzx dst, src` | 零扩展 | 无符号小类型 → 大类型 | 源不能是立即数 |
| `movsx dst, src` | 符号扩展 | 有符号小类型 → 大类型 | 源不能是立即数 |
| `add/sub dst, src` | `dst ±= src` | 生成 ZF/SF/CF/OF/AF/PF | 浮点用 `addss`/`subsd` |
| `inc/dec dst` | `dst ± 1` | **CF 不变** | 这是最常见的标志位陷阱 |
| `neg dst` | `dst = -dst` | 操作数非 0 时 CF=1 | 对 0 不变 |
| `imul src`（1 操作数） | `edx:eax = eax * src` | 有符号，结果 64 位 | 高位在 edx |
| `imul dst, src` | `dst *= src` | 截断时 CF=OF=1 | 有符号 |
| `imul dst, src, imm` | `dst = src * imm` | 截断时 CF=OF=1 | 有符号 |
| `mul src` | `edx:eax = eax * src` | 无符号；高位结果与 imul 不同 | 与 imul 的差别不只在标志 |
| `idiv/div src` | `eax = 商, edx = 余数` | 被除数是 `edx:eax`；先 `cdq`/清 `edx` | 除 0、商溢出 → 异常 |
| `cdq/cqo` | `edx = sign(eax)` / `rdx = sign(rax)` | 有符号除法前必做 | 无符号用 `xor edx, edx` |
| `and/or/xor` | 位运算 | 逻辑运算清 CF/OF | `not` 不影响标志 |
| `not dst` | 按位取反 | 不改标志 | 与 `neg` 不同 |
| `test a, b` | `a & b`，只设标志 | **不写回** | 常写 `test eax, eax` |
| `shl/shr` | 逻辑左/右移 | CF = 移出位；计数掩码到 5 位 | 浮点不能用 |
| `sar` | 算术右移 | 符号位补高位 | 只对整数 |
| `cmp a, b` | `a - b`，只设标志 | **左操作数是被减数** | 不写回 |
| `call target` | `push 下一条; jmp target` | 返回地址 = 下一条 | 近/远调用压不同宽度 |
| `ret` | `pop EIP` | 与 call 配对 | `ret n` 额外加 esp |
| `ret n` | `pop EIP; esp += n` | **被调用者清栈** | stdcall |
| `leave` | `mov esp, ebp; pop ebp` | 等价两条指令 | 需要 ebp 帧 |
| `cld/std` | `DF = 0/1` | 串操作方向 | 影响 `movs/stos` |
| `rep movs*` | 重复串复制 | `ecx` 次数，`esi/edi` 指针，DF 定向 | 方向由 DF 决定 |
| `loop` | `ecx--; if (ecx != 0) goto` | 改 ecx | 编译器少用 |
| `cmovcc` | 条件传送 | 无分支；两路都求值 | 不能消除所有分支 |
| `setcc` | 条件置字节 | 结果为 0/1 | 只写 8 位 |
| `nop` | 空操作 | 对齐、占位 | 不改状态 |

必须点明的陷阱级语义：

- `lea` 算地址不访存：`lea eax, [ebx+ecx*4]` 只做 `eax = ebx + ecx*4`，不读内存；编译器常用它替代乘加。
- `xor eax, eax` 与 `mov eax, 0` 的结果都是 0，但前者把 ZF 置 1、CF/OF 清 0，后者不改标志。
- `cmp a, b` = `a - b` 不写回；`jl` 判的是 `a < b`（有符号），不是 `b < a`。
- `imul` 单操作数走 `edx:eax`；`div/idiv` 前必须扩展被除数，否则 `edx` 的垃圾会变成高位。
- `shl` 只适用整数；浮点乘 2 要改阶码，直接左移会把尾数位移进阶码（2017/44(4)）。
- `push` 改 `esp`；`call` 压的是**下一条**指令地址；`ret n` 由被调用者清栈。

边界：以上默认 32 位 x86（cdecl）；64 位下寄存器宽度、传参和 `push` 步长都变（见 §9）。`movsd` 在 SSE 里是浮点标量移动，在串操作里是 4 字节串移动，同名不同物，看操作数类型。

### 5.2 表 B：RISC 风格指令认型

| 指令 | 语义 | opcode（标准 RISC-V） | 格式要点 |
|---|---|---|---|
| `add` | `rd = rs1 + rs2` | `0110011` | R 型，`funct3=000` |
| `addi` | `rd = rs1 + imm` | `0010011` | I 型，12 位补码立即数 |
| `slli` | `rd = rs1 << shamt` | `0010011` | I 型，`shamt` 在 `IR[24:20]` |
| `lw` | `rd = M[rs1 + imm]` | `0000011` | I 型，`funct3=010` |
| `sw` | `M[rs1 + imm] = rs2` | `0100011` | S 型，立即数拆两段 |
| `beq/bne` | `if (rs1 ==/!= rs2) pc += imm` | `1100011` | B 型，13 位补码偏移 |
| `jal` | `rd = pc+4; pc += imm` | `1101111` | J 型，20 位补码偏移 |
| `jalr` | `rd = pc+4; pc = rs1 + imm` | `1100111` | I 型，用于返回/间接调用 |
| `lui` | `rd = imm << 12` | `0110111` | U 型，构造高 20 位 |

边界：**题面自带字段表时一律以题面为准**。2024/43 的 `slli` 把 `funct3` 写成 `010`，标准 RISC-V 是 `001`；它不是标准 RISC-V，只是借了字段位置的「RISC 风格 ISA」。认型先看 `opcode`，再看 `funct3`，最后才套语义。

### 5.3 辨析：伪指令 / 汇编指令 / 机器指令 / 微指令

| 层次 | 谁产生 | 谁解释 | 存在哪 | 与相邻层的关系 |
|---|---|---|---|---|
| 伪指令 | 程序员/汇编器 | 汇编器 | 汇编源程序 | 展开成一条或几条汇编指令，CPU 不认识 |
| 汇编指令 | 汇编器 | 汇编器 | 汇编源文件 | 通常 1:1 对应机器指令（伪指令除外） |
| 机器指令 | 汇编器 | CPU | 目标文件/内存 | 一条指令的二进制编码 |
| 微指令 | 控制器设计者 | 微程序控制器 | 控制存储器 | 一条微指令产生一组控制信号；多条微指令解释一条机器指令 |

一句话：**伪指令由汇编器展开，汇编指令由汇编器翻译，机器指令由 CPU 执行，微指令由控制器执行**。

### 5.4 编译链

```
预处理 → 编译 → 汇编 → 链接
 .c      .i      .s      .o     可执行文件
```

- 预处理：展开宏、头文件、条件编译。
- 编译：高级语言 → 汇编语言（2016/12 问「将高级语言源程序转换为机器目标代码文件的程序」，答**编译程序**）。
- 汇编：汇编语言 → 机器指令/可重定位目标文件；**汇编器才认识助记符，CPU 只认识机器码**。
- 链接：合并目标文件与库，重定位符号，生成可执行文件（2022/20 问「转换为可执行目标文件的主要过程」，答**预处理、编译、汇编、链接**）。

边界：编译程序输出的是汇编代码，不是最终可执行文件；把「编译」当成「一步到机器码」是 2016/12 的典型错项。链接器不翻译指令，只拼装与重定位。

## 6. 比较、标志与分支

挂点：硬件层「ALU 执行」工位 · 合同① ISA ↔ ch2 的接口 · 根张力「复用与代价」· 不变量 #1 第 3 次实例化（标志位 = 加法的副产品，供条件跳转复用）

| 标志 | 含义 | 生成规则（加法/减法） |
|---|---|---|
| ZF | 结果为零 | 结果所有位为 0 |
| SF | 结果为负 | 结果最高位 |
| CF | 无符号进位/借位 | 加法看最高位进位；减法看借位（无符号 `a < b` 时 CF=1） |
| OF | 有符号溢出 | 最高位进位与次高位进位异或；或「同号相加得异号」 |
| AF | 半字节进位 | 第 3 位向第 4 位的进位，BCD 用 |
| PF | 低字节偶校验 | 结果低 8 位中 1 的个数为偶数 |

两个真题算法写死：

- **2024/43(2)**：`8765 4321H + 9876 5432H`。
  - 和 = `1 1FDB 9753H`，取低 32 位 → `F = 1FDB 9753H`。
  - 两操作数符号位都是 1，结果符号位是 0 → 同号相加得异号 → `OF = 1`。
  - 最高位有进位 → `CF = 1`。
  - 若把操作数当无符号整数，判断溢出看 **CF**（不是 OF）。
- **2017/44(3)**：`f1(0)` 中 `n=0`、`i=0`，`cmp i, (n-1)` 即 `0 − 0FFFFFFFFH`。
  - 无符号看：`0 < 0FFFFFFFFH`，要借位 → `CF = 1`。
  - 有符号看：`0 − (−1) = +1`，不溢出 → `OF = 0`；结果非零 → `ZF = 0`。
  - 这条 `cmp` 的来源是 `for (unsigned i = 0; i <= n-1; i++)`：`n=0` 时 `n-1` 回绕成 `0FFFFFFFFH`，循环反而进入。

`jcc` 三分组：

| 组 | 指令 | 条件 |
|---|---|---|
| 单标志 | `je/jz` | ZF=1 |
| | `jne/jnz` | ZF=0 |
| | `js/jns` | SF=1 / SF=0 |
| | `jo/jno` | OF=1 / OF=0 |
| | `jp/jnp` | PF=1 / PF=0 |
| 无符号 | `jb/jnae/jc` | CF=1 |
| | `jae/jnb/jnc` | CF=0 |
| | `jbe/jna` | CF=1 或 ZF=1 |
| | `ja/jnbe` | CF=0 且 ZF=0 |
| 有符号 | `jl/jnge` | SF≠OF |
| | `jge/jnl` | SF=OF |
| | `jle/jng` | ZF=1 或 SF≠OF |
| | `jg/jnle` | ZF=0 且 SF=OF |

`cmp` 后接有符号还是无符号，只看助记符：`g/l` 一族是有符号，`a/b` 一族是无符号；混用就是把 OF 当 CF 用。

机器码 → 助记符认型（2 字节 rel8 一族）：

| 机器码 | 助记符 | 机器码 | 助记符 |
|---|---|---|---|
| `74` | `je` | `75` | `jne` |
| `7C` | `jl` | `7D` | `jge` |
| `7E` | `jle` | `7F` | `jg` |
| `72` | `jb` | `73` | `jae` |
| `76` | `jbe` | `77` | `ja` |
| `EB` | `jmp rel8` | `E9` | `jmp rel32`（5 字节） |
| `0F 8x` | `jcc rel32`（6 字节） | `E8` | `call rel32`（5 字节） |

`cmovcc` / `setcc`：无分支写法，两路都求值。`setcc r/m8` 把条件码写成 0/1；`cmovcc r32, r/m32` 条件成立才传送。代价对比：条件跳转可能控制冒险（预测失败要清流水线）；`cmov` 避免控制冒险，但制造数据依赖，且两路都要算。

边界：标志位只在「上一条改标志的指令」后有效；`mov`/`lea`/`jmp`/`push`/`pop` 不改标志。读题时向前找最后一条改标志的指令，不要默认上一条算术指令就是它。

## 7. 循环

挂点：合同① ISA 的控制面 · 根张力「通用性」· 不变量 #6（时空互换）第 1 次实例化（回边把重复代码压成时间）

三形态骨架（Intel 语法，32 位）：

```asm
; do-while：体在前，回边在后
.L2:
    mov eax, [ebp-4]        ; i
    add eax, 1
    mov [ebp-4], eax
    cmp dword ptr [ebp-4], 10
    jl  .L2                 ; 向上跳 = 回边

; while：顶部测试 + 底部回边
    jmp .Lcheck
.Lbody:
    mov eax, [ebp-4]
    add [ebp-8], eax        ; s += i
    add dword ptr [ebp-4], 1
.Lcheck:
    cmp dword ptr [ebp-4], 10
    jl  .Lbody              ; 向上跳

; for：init → test → body → step → 回 test
    mov dword ptr [ebp-4], 0
    jmp .Ltest
.Lbody2:
    ; body
    add dword ptr [ebp-4], 1
.Ltest:
    cmp dword ptr [ebp-4], 24
    jl  .Lbody2             ; 向上跳
```

识别法写死：**全函数唯一向上跳的 `jcc` = 回边 = 循环；向下跳 = 分支**。`jmp` 向上也可能是回边（`do-while` 的无条件回跳），但条件回边才是循环的标志。

2023/44 的证据：第 1–2 条 `mov [ebp-8], 0; jmp 00401084h` 是「先给 i 赋 0，再跳到测试处」，典型的 `for`/`while` 顶部测试形态；第 7 条 `jge 004010bch` 是向下跳的出口分支。

归纳变量（strength reduction）：`i*4` 被优化成指针 `+=4` 后，汇编里看不到乘法，要按步长反推；`i*256` 是同一模式的另一形态（2023/44 的 `ecx`）。识别线索：循环体内对某个寄存器反复 `add reg, 常量`，而这个寄存器只用于访存 EA。

嵌套循环：内层回边地址更大、跳距更短；二维数组下标还原顺序是先 `j` 后 `i`（内层变化快）。

`loop` 与教材写法等价：

```asm
loop .L      ; ecx -= 1; if (ecx != 0) goto .L
; 等价于
dec ecx
jnz .L
```

408 教材题常用 `loop`，编译器不用（`loop` 慢且只支持 ecx）。

边界：`i < n` 与 `i <= n-1` 在有符号/无符号下不等价：`n=0` 时无符号 `n-1` 回绕成 `0FFFFFFFFH`，`i <= n-1` 恒真（2017/44 的 CF 例）。还原 C 时先确定变量是有符号还是无符号，再选 `jl` 还是 `jb`。

## 8. 跳转与目标地址

挂点：合同① ISA · 根张力「通用性」· 不变量 #3 第 3 次实例化（跳转表 = 控制地址变成数据）

公式：

$$\text{目标}=\text{下一条指令地址}+\text{符号扩展}(\text{位移})$$

三个算例：

- `EB 09` 在 `0040 1079H`：下一条 `0040 107BH`，`+9` → `0040 1084H`。
- `7D 32` 在 `0040 1088H`：下一条 `0040 108AH`，`+32H` → `0040 10BCH`。
- `E8 D6 FF FF FF` 在 `0040 1025H`（2019/45）：下一条 `0040 102AH`，位移 `FFFFFFD6H = −2AH`，目标 `0040 102AH − 2AH = 0040 1000H`，正好是 `f1` 的入口。

`jmp 00401084h`（2023/44 第 2 条）是**前跳**：跳过循环体，先到测试处；它不是回边，别把它当循环。

位移宽度与指令字节数的对应：

| 形态 | 字节数 | 位移宽度 | 例 |
|---|---|---|---|
| `EB rel8` | 2 | 8 位 | `EB 09` |
| `E9 rel32` | 5 | 32 位 | 近跳（rel32） |
| `0F 8x rel32` | 6 | 32 位 | 近条件跳转的 32 位形式 |
| `E8 rel32` | 5 | 32 位 | `call` |

绝对/间接跳转与 `switch` 跳转表：`jmp dword ptr [表基址 + idx*4]`，特征是一条 `jmp` 加一张连续地址表；表项也可以是「相对偏移」，此时目标 = 表项 + 基址。与「比较链」的形态对比：`case` 少且稀疏时编译器生成一串 `cmp/je`；`case` 密集时生成跳转表。

408 固定问法：「采用什么寻址方式」→ 相对寻址；「给出计算过程」必须写出「下一条指令地址 + 位移」，不能只写结果。

边界：相对位移的基准是「下一条」还是「当前条」由 ISA 定义；x86 是下一条，有些教材/ISA 用当前条。题面给了操作码和地址，就按题面的指令长度推下一条。间接跳转的目标在寄存器/内存里，不能直接用「下一条 + 位移」算。

## 9. 过程的实现方法

挂点：合同① ISA ↔ OS 的调用约定 · 根张力「通用性」· 不变量 #4（透明性：调用者不知道被调用者用了多少栈）第 1 次实例化

`call`/`ret` 的机器语义：

```asm
call target   ; push 下一条指令地址; jmp target
ret           ; pop 返回地址 → EIP
```

返回地址为什么必须是下一条：`call` 执行完，CPU 已经取过 `call` 本身，下一条才是调用者要继续的地方；压当前条会死循环。

三约定表：

| 约定 | 参数位置 | 返回值 | 谁清栈 | 易失寄存器 |
|---|---|---|---|---|
| cdecl（32 位） | 从右到左压栈 | `eax` | **调用者**（`add esp, 4n`） | `eax/ecx/edx` |
| stdcall（32 位 Windows） | 从右到左压栈 | `eax` | **被调用者**（`ret n`） | `eax/ecx/edx` |
| System V AMD64 | `rdi, rsi, rdx, rcx, r8, r9`，其余压栈 | `rax` | 调用者清栈上的参数 | `rax/rcx/rdx/rsi/rdi/r8–r11` |

序言/尾声模板与定位规则：

```asm
push ebp
mov  ebp, esp
sub  esp, N          ; 开局部变量
...
mov  esp, ebp        ; 或 leave
pop  ebp
ret
```

| 位置 | 32 位 cdecl | 64 位 System V |
|---|---|---|
| 第 1 个参数 | `[ebp+8]` | `rdi` |
| 第 2 个参数 | `[ebp+12]` | `rsi` |
| 第 7 个参数 | `[ebp+32]` | `[rbp+16]` |
| 返回地址 | `[ebp+4]` | `[rbp+8]` |
| 旧 ebp | `[ebp]` | `[rbp]` |
| 第 1 个局部变量 | `[ebp-4]` | `[rbp-8]` 起（8 字节槽） |

返回值 `eax/rax`；大于寄存器可容纳的返回值（32 位 >8 字节 / 64 位 >16 字节）用隐藏指针（调用者传一块空间，被调用者写入）。

叶子函数可以省栈帧（不 `push ebp`，直接用 `esp` 偏移）；尾调用可以复用栈帧（`jmp` 而不是 `call`）；递归 = 栈帧链，每层独立 `[ebp]` 链；函数指针 = `call 寄存器/内存`（接 §8 间接跳转）。

408 口径：题面给自定义指令系统时按题面约定（2024/43 无 `push/pop`，参数传递由题面说明），不套真机 ABI。

边界：`[ebp+8]` 只是 cdecl 的约定；stdcall 参数位置相同但清栈者不同；64 位下前 6 个参数不在栈上，`[rbp+16]` 不是「第二个参数」。优化后的代码可能没有 `ebp` 帧，局部变量用 `rsp` 偏移。

## 10. 栈与过程的配合流程

挂点：硬件层「栈/存储」工位 · 合同① ISA ↔ 合同③ 中断协议 · 根张力「异步与差错边界」· 不变量 #2（分层+按需保存：现场即状态快照）第 1 次实例化

调用时序表：

| 谁做   | 动作                      | esp 变化          | 栈顶新增             |
| ---- | ----------------------- | --------------- | ---------------- |
| 调用者  | 压参数（从右到左）               | `-4n`           | 参数区（低地址是第 1 个参数） |
| 调用者  | `call f`                | `-4`            | 返回地址             |
| 被调用者 | `push ebp`              | `-4`            | 旧 ebp            |
| 被调用者 | `mov ebp, esp`          | 0               | ebp 指向旧 ebp      |
| 被调用者 | `sub esp, N`            | `-N`            | 局部变量区            |
| 被调用者 | 体内 `push` 保存寄存器         | 每次 `-4`         | 保存值              |
| 被调用者 | `mov esp, ebp; pop ebp` | 先复原到 ebp，再 `+4` | 回到返回地址           |
| 被调用者 | `ret`                   | `+4`            | 弹出返回地址           |
| 调用者  | `add esp, 4n`           | `+4n`           | 参数区释放            |

栈帧图（高地址在上）：

```
        ┌──────────────┐
ebp+12  │  参数 2       │
ebp+8   │  参数 1       │
ebp+4   │  返回地址     │
ebp     │  旧 ebp       │ ← ebp
ebp-4   │  局部变量 1   │
ebp-8   │  局部变量 2   │
        │  ...          │
        └──────────────┘ ← esp
```

两层嵌套调用：`f` 调 `g` 时，`g` 的帧在 `f` 的 `esp` 之下，形成两条 `[ebp]` 链；返回时逐层弹出，调用者的 `ebp` 不被被调用者改写（被调用者保存/恢复）。

`esp` 增减表：

| 指令 | esp 变化 |
|---|---|
| `push` | −4（64 位 −8） |
| `call` | −4（64 位 −8） |
| `pop` | +4（64 位 +8） |
| `ret` | +4（64 位 +8） |
| `ret n` | +4+n |
| `sub esp, N` | −N |
| `add esp, 4n` | +4n |
| `leave` | 先 `esp=ebp`，再 `pop ebp`；净变化 = 旧 ebp + 4 − 旧 esp |

栈向**低地址**增长；栈溢出 = 递归深度 × 帧大小超过栈上限。

与中断/系统调用的对照：

| 维度 | 子程序调用 | 中断/异常 |
|---|---|---|
| 触发源 | 程序内 `call`，主动 | 外部设备异步 / 指令执行异常，被动 |
| 保存内容 | 只压返回地址 | 硬件压 PC、PSW（可能还有错误码） |
| 谁压栈 | `call` 指令（CPU 执行） | 中断响应硬件 |
| 返回指令 | `ret` | `iret` |
| 服务关系 | 主程序的一部分，返回后继续 | 独立处理程序，返回被中断处 |
| 嵌套 | 栈自然支持 | 靠优先级/屏蔽字控制 |

边界：中断保存的现场比 `call` 多（至少 PC+PSW），所以 `iret` 不是 `ret`；系统调用可能用 `syscall/int` 进入内核，保存/恢复由硬件与内核共同完成，不能套 cdecl 的参数规则。

## 11. 跨章接口

挂点：三个合同全上 · 根张力「速率差」+「复用与代价」· 不变量 #2 第 2 次实例化（缺页/预取）、#4 第 2 次实例化（Cache 对汇编不可见）

ISA 四章叫法表：

| 同一件事 | ch4 指令系统 | ch5 CPU | ch2 运算 | ch3 存储 |
|---|---|---|---|---|
| 指令字段/编码 | 指令格式、操作码、寻址方式 | 取指/译码的数据通路与控制信号 | — | 取指访存 |
| 操作数语义 | 寄存器/立即数/内存操作数 | 数据通路选通 | 补码、标志位、溢出 | 对齐、大小端 |
| 控制 | 指令的操作 | 微程序 vs 硬布线、`Ext`/`ALUBsrc`/`ALUctr` | 条件码 | — |
| 访存 | load/store | 指令周期、流水线 | 地址计算 | I-Cache、页表、TLB、缺页 |

2024/43 的控制信号读法（按题 43(b) 数据通路图）：

| 指令 | `Ext` | `ALUBsrc` | `ALUctr` | 理由 |
|---|---|---|---|---|
| `add` | 无关 | `0` | `000`（加） | ALU 第二输入取 `B = rs2`；MUX 的 0 路是 B |
| `slli` | `0` 或 `1` 均可 | `1` | `010`（逻辑左移） | 移位量只用 `IR[24:20]` 的低 5 位；零/符号扩展只改高位 |
| `lw` | `1`（符号扩展） | `1` | `000`（加） | `imm` 是 12 位补码；EA = `rs1 + imm` |

- `Ext` 0/1 = 零扩展/符号扩展；`lw` 的 `imm` 是补码 → 必须 `1`。
- `slli` 的 `Ext` 两可：`shamt` 在 12 位字段的低 5 位，扩展只影响 bit 11–5，不参与移位量。
- `ALUBsrc` 的字面值取决于数据通路图：MUX 0 路接 `B`，1 路接扩展器输出；`add` 选 0，`slli`/`lw` 选 1。**图变了，值就变，方法不变**。

取指缺页（2023/44(4)）+ I-Cache：

- 缺页判据 = 该虚拟地址所在页是否在内存，与「第几次执行该指令」无关。
- 第一次执行第 19 条时，取指访问 `0040 10AEH` 所在页；前面的指令都在同一页，取指时已把该页调入 → **不会因取指缺页**。
- 但第 19 条的数据地址 `0042 2000H` 可能在另一页，数据访问仍可能缺页；题目问的是「取指令过程中」，要分开答。

流水线冒险在机器级代码上的可见形态（自造 4 行）：

```asm
I1: lw   eax, 0(ebx)      ; load
I2: add  ecx, eax         ; 用 I1 的结果 → load-use 冒险
I3: add  eax, 4           ; 写 eax，与 I1/I2 有数据依赖
I4: jne  .L               ; 控制冒险
```

- 连续 `add` 依赖同一寄存器 = 数据冒险（转发/停顿）。
- `jcc` = 控制冒险（分支预测/延迟槽）。
- `lw` 后紧跟使用该寄存器的指令 = load-use 冒险（即使有转发也要停一拍）。

边界：Cache 对汇编程序员透明，汇编里看不到 `Cache` 指令；但性能可观测（同一段代码改变访存顺序会变快/变慢）。缺页是「合同② 违约」：暂停主线、委托页表/磁盘、回来续上；它不是指令语义的一部分。

## 12. 五步还原法 + 真题演算

挂点：合同① ISA 的读题面 · 根张力「通用性」· 不变量 #5 第 4 次实例化（把题面表示翻译回语义）

五步：

| 步 | 看什么 | 产出 | 典型失败 |
|---|---|---|---|
| 1 判题面类型 | 四列对照 / 字段表 / 概念选择 | 决定用地址算术还是字段拆解 | 把概念题当计算题 |
| 2 算地址/拆字段 | 机器码长度、IR 位段 | 下一条地址、寄存器号、立即数 | 忘了「下一条」、符号扩展错 |
| 3 标变量 | `[ebp-k]` 局部、`[ebp+k]` 参数、寄存器归纳变量 | 变量表 | 把参数当局部 |
| 4 画控制流 | 回边=循环，前跳=分支，短路与/短路或两条边 | 控制流图 | 把 `jmp` 前跳当循环 |
| 5 写 C + 边界值回验 | 0、1、n−1、负数 | C 代码 | 不代边界值，符号/无符号弄反 |

三段真题演算：

**2023/44**

1. 第 19 条 11 字节 → `0040 10AEH + 0BH = 0040 10B9H`。
2. `jmp`/`jge` 都是相对寻址；`0040 107BH + 9 = 0040 1084H`，`0040 108AH + 32H = 0040 10BCH`。
3. 源操作数 `0Ah` 是立即寻址；目标操作数是基址+变址×比例+偏移；`ecx = i×64×4 = i×256`；disp 字节 `00 20 42 00` 低字节在前 → 小端。

**2017/44**

1. CISC：指令长度 1/2/3/7 字节不等；`cmp dword ptr [ebp-0Ch], ecx` 直接访存；格式不规整。
2. 长度 `0040 107FH − 0040 1020H + 1 = 60H = 96` 字节。
3. `i=0, n=0` 时 `0 − 0FFFFFFFFH` 借位 → `CF=1`；`OF=0`。
4. `shl` 不能实现浮点 `power*2`：浮点的阶码/尾数布局与整数不同，左移会把尾数位移进阶码。

**2024/43**

1. 32 个通用寄存器（`rs1/rs2/rd` 各 5 位）；`shamt` 5 位覆盖 0–31。
2. `add` 的 `ALUBsrc=0`；`F=1FDB 9753H`，`OF=1`，`CF=1`；无符号溢出看 CF。
3. `slli` 的 `Ext` 可 0 可 1：只用低 5 位 `shamt`，高位扩展不参与。
4. `lw` 的 `Ext=1`、`ALUctr=000`。
5. `A040 A103H`：`IR[6:0]=0000011` → 只可能是 `lw`；`IR[14:12]=010` 也吻合；`imm=IR[31:20]=A04H`，作 12 位补码 = `−5FCH`；`rs1=IR[19:15]=1` → 地址 `FFFF A2D0H − 5FCH = FFFF 9CD4H`。

2019/45 只写题面口径：递归调用的 `call` 是相对寻址，`int` 加减的机器级实现走 `add/sub` 与标志位；`imul` 的高 32 位不是低 32 位的符号扩展时 `OF=1`，要转异常应在后面加 `jo` 之类的条件转移。不逐问演算（题面长，且主战场在 ch2）。

边界：真题地址/机器码以题面为准，本文数字只作复核；题面若改了指令长度或字段位置，所有算式重算，不能套记忆中的结果。

## 13. 不变量登记 + 待解问题走线 + 穿越 drill

挂点：六不变量与三个合同的登记面 · 根张力「复用与代价」+「速率差」· 不变量 #1–#6 各至少一次实例化

六不变量 × 本考点实例表：

| 不变量 | 本考点的实例 | 边界 |
|---|---|---|
| #1 运算归约为加法+移位 | EA 计算是加法；`shl` 代乘；`lea` 代加乘；标志位是加法的副产品 | 浮点乘 2 不是左移（2017/44(4)）；除法/乘法不总能归约 |
| #2 分层+按需搬运 | 取指缺页；I-Cache；页表/TLB | 页已在内存时不发生缺页；命中率高时层次不可见 |
| #3 控制即数据 | 指令存在内存；微程序；跳转表 | 硬布线控制器没有微指令；跳转表只在 case 密集时 |
| #4 透明性 | Cache 对汇编不可见；调用约定隐藏栈帧 | 性能可观测；调试器/攻击者能看见栈帧 |
| #5 表示先于电路 | 指令编码、操作码扩展、大小端、对齐、条件码 | 表示选择有代价（字段宽度、对齐填充）；非对齐可能异常 |
| #6 时空互换 | 回边把重复代码压成时间；流水线重叠；跳转表 vs 比较链 | 分支预测失败会抵消流水线收益；表太大反而慢 |

考纲第四章 5 个待解问题逐题走线：

1. **什么是指令？什么是指令系统？为什么引入？** ISA 是软硬件合同：软件只见指令语义，硬件可自由实现；ch4 定义合同，ch5 用控制器/数据通路履约。
2. **指令由哪些部分组成？** 操作码 + 地址码/字段（寄存器号、立即数、寻址方式位）；ch4 给格式，ch5 给取指/译码通路。
3. **寻址方式多或少的影响？** 多 → 灵活、代码短，但格式复杂、译码慢、执行阶段多、CPI 高；ch4 列方式，ch5 数执行阶段。
4. **一个操作数占多个单元，怎么给地址？** 指令给首地址，长度/类型由指令或类型隐含；多字节的字节序由大小端决定，边界由对齐决定；ch4 给地址，ch3 给存储布局。
5. **装入/存储型指令有什么特点？** 只有它们访存，运算在寄存器间，格式因此规整；ch4 定义 load/store，ch5 用流水线调度掩盖访存延迟。

穿越 drill（20 分钟，`a[i][j] = 10` → 磁盘）讲述脚本骨架：

1. C 语义：`a[i][j]=10` 的地址 = `base + i×行字节数 + j×4`（ch4）。
2. 编译器：寄存器分配、归纳变量、生成 `mov [ecx+edx*4+disp], 10`（ch4）。
3. 取指：PC → 虚拟地址 → TLB/页表 → 物理地址 → I-Cache → 主存；缺页则暂停（ch3/ch5）。
4. 译码：opcode、寻址方式、算 EA（ch4）。
5. 取数：dCache 命中/缺失；缺失向下逐级搬运（ch3）。
6. 执行：ALU 做加法，生成标志位（ch2）。
7. 写回：写 Cache/写缓冲，写策略决定何时落盘（ch3）。
8. 下一条：流水线重叠，数据/控制/结构冒险（ch5）。
9. 中断检查点：每条指令末尾采样中断（ch5）。
10. 脏页落盘：DMA、总线仲裁、磁盘（ch6/ch7）。

卡壳记录表（讲述时只记，不解释）：

| 时点 | 卡在哪 | 缺的是哪条边 |
|---|---|---|
| 取指 | 虚拟地址怎么变物理地址 | ch3 页表/TLB 那条边 |
| 译码 | 字段怎么变成控制信号 | ch4 格式 ↔ ch5 数据通路 |
| 执行 | 标志位谁生成、谁用 | ch2 ALU ↔ ch4 条件跳转 |
| 写回 | 什么时候真正写内存 | ch3 写策略/Cache |
| 下一条 | 为什么流水线不会算错 | ch5 冒险/转发 |
| 落盘 | 谁发起 DMA | ch7 DMA ↔ ch6 总线 |

卡壳 = 缺边，只补那条边，不重读整章；首句若是章节号即判负。

判据自检（抄 `计组融贯性诊断` 的口径，落到本笔记）：

- C1 穿越讲述卡壳数目标 0；卡壳记录表逐轮变短。
- C3 五个待解问题每题跨 ≥2 章（上表每条都点了两章以上）。
- C4 随机抽本节任一表格，30 秒内说出挂点/张力/不变量第几次实例化。

边界：不变量登记是「认出模式」，不是「多背一张表」；如果一条实例说不出边界，它只是标签，不算登记。

## 14. 易错清单 + 自测

挂点：全节判据的复用面 · 合同① ISA · 根张力「复用与代价」· 不变量 #5 第 5 次实例化（表示与读法）

| 陷阱 | 正解 |
|---|---|
| `word` 是当前机器字长 | `word` = 16 位，历史定义；`dword`=32，`qword`=64 |
| `dword` 是 64 位 | `dword`=32 位；64 位是 `qword` |
| `cmp a, b` 是 `b-a` | 是 `a-b`，左操作数是被减数 |
| `test` 会写回结果 | 只设标志，不写回 |
| `lea` 会读内存 | 只算 EA，不访存 |
| `div` 直接除 | 被除数是 `edx:eax`，先 `cdq`/清 `edx` |
| `call` 压当前指令地址 | 压下一条指令地址 |
| `jg` 用于无符号比较 | `jg/jl` 有符号；无符号用 `ja/jb` |
| 相对跳转用当前地址加位移 | 用下一条地址加位移（x86） |
| 看到 `00 20 42 00` 读成大端 | 低字节在前 → 小端 `0042 2000H` |
| `ret` 和 `ret n` 一样 | `ret n` 额外清 n 字节参数，被调用者清栈 |
| `shl` 可实现浮点乘 2 | 浮点乘 2 改阶码；`shl` 只适用于整数 |
| `xor eax, eax` 与 `mov eax, 0` 完全一样 | 结果一样，标志位不同：`xor` 改 ZF/CF/OF |
| `push` 只写内存不改 esp | `push` 先 `esp-=4` 再写 |
| `rep movsb` 方向固定 | 方向由 DF 决定，`cld` 递增、`std` 递减 |
| `loop` 不改 ecx | `loop` 先 `ecx--` 再判 |
| `[ebp+8]` 在任何约定下都是第一个参数 | 只是 cdecl/stdcall 的 32 位约定；64 位前 6 个参数在寄存器 |
| `jmp` 一定是相对寻址 | 可以是相对、直接、间接；看机器码/操作数 |
| `leave` 是一条独立语义 | 等价 `mov esp, ebp; pop ebp` |
| 栈向高地址增长 | 栈向低地址增长，`push` 减 esp |

自测 10 题（先盖住答案）：

| 题 | 答案 |
|---|---|
| 32 位定长、5 位寄存器号、只有 `lw` 访存，判 CISC 还是 RISC？ | RISC |
| 第 19 条在 `0040 10AEH`、11 字节，第 20 条地址？ | `0040 10B9H` |
| `EB 09` 在 `0040 1079H`，目标地址？ | `0040 1084H` |
| `cmp a, b` 后 `jl` 成立，C 里是 `a<b` 还是 `b<a`？ | `a < b`（有符号） |
| `0 − 0FFFFFFFFH` 的 CF？ | `CF=1`（借位） |
| `[ebp+8]`、`[ebp+4]`、`[ebp-4]` 各是什么？ | 第 1 个参数、返回地址、第 1 个局部变量 |
| cdecl 与 stdcall 谁清栈？ | 调用者 / 被调用者（`ret n`） |
| `lea eax, [ebx+ecx*4]` 做了什么？ | `eax = ebx + ecx*4`，不访存 |
| `78 56 34 12` 按小端是什么数？ | `1234 5678H` |
| 判 RISC 的四条证据？ | 定长、load/store 访存、多寄存器（5 位字段）、格式少/硬布线 |

边界：易错表是「读题时的检查项」，不是定义；遇到题面自定义的 ISA，先按题面校正，再套表。
