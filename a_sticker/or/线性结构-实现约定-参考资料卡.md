## 0 一句话

三件结构各有一套「默认实现 + 可选项」：默认值不是最优解，是**让边界条件只有一个**——链表的空判定只挂在头指针上，栈的空用越界表示，队列的空与满靠留一个不可用空块分开。

## 1 口述原文（照录）

### 1.1 链表基本规范

- 工作区域，改变结构的时候一定要得到被操作的节点的前序节点。
- 所有节点的指针被修改前，都要保证内已经失效，容被缓存或转移。

可选部分：

- 头结点：让头指针不会悬空，统一逻辑
- 无头节点：删除插入可能要特殊操作。
- 尾指针：删除要判断会不会影响。
- 循环指针：默认无头节点？
- 空的判定：只有首元或者头指针为空

### 1.2 栈

- 栈空是用越界来表示的（统一了逻辑）

### 1.3 链栈

- 一般没有头节点，头指针 == 栈顶
- 头指针规范（规范就是可选中选择一种没什么特殊的实现）指向最顶上的非空位置
- 所以满 == top == n-1

### 1.4 共享栈

- 共享栈是两头一起向中间长，满的时候两者刚好没有重叠。

### 1.5 队列

- 顺序存默认采用循环队列

### 1.6 循环队列

- 默认可选项：留一个不可用空块
- 头指针指向不可用空块
- 默认有尾指针：注意被删除波及
- 尾指针行为类似栈 top 指针指向最后一个元素，空指向不可用空块
- 空：两个指针指向同一个空块
- 满：rear 下一个是 front

### 1.7 链队列

- 默认没有头结点
- 默认循环链表
- 队尾一般在链表头部（head，不是 front）

## 4 待澄清与裁决（2026-11-27 owner 裁决）

1. **`满 == top == n-1` 挂在「链栈」下**——裁决：属于**顺序栈**（`top` 指向最顶非空元素 ⇒ 满即 `top == n-1`）。链栈只保留「无头结点、头指针 == 栈顶」，并在 `Chain Stack` 里注明链式结构没有容量上限。
2. **「都要保证内已经失效，容被缓存或转移」**（原句有脱字）——裁决：**覆盖前先缓存/转移旧目标**，即 `next` 先存再改。写进 `Linked List` §基本规范 第 2 条。
3. **「循环指针：默认无头节点？」**——仍按**未定**处理：`Circular Linked List` 只写「循环只改哪里算结尾，空判定仍走两条路」，默认值留空。
4. **`Shared Stack` 的满条件**原文只说「两者刚好没有重叠」，未给判据式子；写入时照录，不补公式。
