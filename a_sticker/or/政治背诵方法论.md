# 政治背诵方法论

> **原材料（or/）**：从「考研政治 · 分析题修订体系」反向拆出的输入侧方法论——不解决怎么答，解决答案材料要背成什么形状才能被调用。
> **口径**：格名与下钻代号沿用原体系，代号定义见 §4.1；原体系被改掉的地方全在 §0，先读它。
> **证据级别**：`官方·`＝会议文件、报告、宪法条文；`文献·`＝同行评议论文与元分析（附作者·年份）；`二手·`＝教辅口径（官方未公开，最多写「多家教辅口径相同」）；`存疑·`＝无法核实，不得作判据。**未标级别的正文一律按 `二手·` 读**；要求 `官方·` 或 `文献·` 的地方必须标，标了就要能指回原文或文献。
> **不复述条文**：本文只给机器，不给条文。唯一例外是 §1.1 那组制度名对照，只给名称与指向，不给条文原话；其余凡需具体表述，以官方文本为准。

## 0. 阅读须知：对原体系的六条修正

怎么用：先读本节 → 再背 §3 的出口判据与 §4 的首动作表 → 最后只对「排他」「结构」两档做处置（§2.1）。

材料范围不在本文：背什么由当年考试大纲与该年时政小册子界定；本文只给形状，不给范围。

| # | 原说法 | 核对结果 | 改用 |
|---|---|---|---|

| 2 | 全填＝套话＝反模板机制下掉档 | 踩点给分；多答不错不扣分，多答错照扣；雷同不判雷同 | 删掉「反模板」，改走 §8 |
| 3 | 3–4 点即收笔 | 一题常含两小问 | 一问 2–3 点，一题 4–5 点 |
| 4 | 层级类表述只按「最高 / 次高 / 再次」一条轴记 | 同一层级还要按领域分家，单轴会把并存的两条判成互斥 | 两轴坐标；它是检索工具，不是官方定义（§1） |

四条红线（后文不再重复）：

1. **口诀不上卷**：口诀是记忆装置，卷面写条文原话。
2. **条文不改字**：一字之差换对象，换字前先回原文。
3. **引文必标级别**：没标级别的结论不进背诵，也不进判据。
4. **不装工具**：默写用纸、自查用一张纸的清单（§5）；本文件不写闪卡语法，也不指定插件。

## 1. 一条原理：背的是格，不是段

- 段落是排版单位，格位是得分单位。一段话能挂到格名上的才进背诵；挂不上的（过渡、背景、口号式收尾）只读不背。
- 格位至少由两个坐标限定：**纵向层级**（高 / 中 / 低）与**横向领域**（政治 / 经济 / 文化 / 社会 / 生态…）。**这两个坐标是本文自造的检索工具，不是官方定义**——它只负责把材料分栏，判对错仍回原文。只按一个坐标收材料，会把并存的两条判成互斥，这是「地位」类题最常见的错位。
- 同一对象常对应几条「听起来同义」的表述，而它们其实指向不同对象。这类表述必须分栏存放，判断依据永远回原文，不靠回忆。
- 一字之差就是换对象。所以「理解」的产物不是段落大意，而是四元组：对象 / 格位（两坐标）/ 表述 / 排他点。四元组不是抽象要求：对象＋格位进清单的「对象」栏，表述＋排他点进「词对」栏（§5）。

### 1.1 最短样例：三个制度名

本文唯一一处给具体名称的地方。三者问法几乎相同，名称只差二到四字，层级却不同——正是「一字之差换对象」的标准形状。**对应关系为 `二手·`**：表里只给指向，条文表述一律回官方文本核对，本文不代填。

| 术语 | 指的是 | 层级别混成 |
|---|---|---|
| 根本制度 | 社会主义制度 | 根本政治制度 |
| 根本政治制度 | 人民代表大会制度 | 根本制度；基本政治制度 |
| 基本政治制度 | 三项并列表述（<三项>，按官方文本清点） | 根本政治制度 |

用法：三个词各写一行进 §5 的「词对」栏，只写「指什么 + 别混成什么 + 判据一句」；答题时先判问的是哪一层，再落词。

## 2. 三档负担（消化层的唯一分类）

| 档 | 判据 | 例（只给类型，不给条文） | 处置 |
|---|---|---|---|
| 可推导 | 从对象本身能推出表述，换个说法不改对错 | 由定义直接展开的原理要点 | 理解 + 一句复述，不背字 |
| 排他 | 换一个字就换对象或换层级 | 名称相近、层级相近的两条表述 | 背到能默写，配错法对照 |
| 结构 | 是一组格名或顺序，内容现场填 | 🅵 五格格序、一组环节名、一组关系词对 | 背格名序列，句子不背 |

一句判据：**能推出来的一律不背；推不出且一字之差定对错的，背到能默写。**

三档只在**消化层**成立（§3）：它是「哪些材料值得处置」的筛子，不是「背到什么程度」的进度条——「排他档背到能默写」是 §3 背诵层的出口判据，不属本节。

### 2.1 三档 → 处置（哪档做什么，一次说清）

| 档 | 分析题 | 客观题 |
|---|---|---|
| 可推导 | 不处置，只留一句复述 | 不处置 |
| 排他 | 进清单的「词对」栏（§5） | 进 §6 的「词对」线索 |
| 结构 | 只记格名序列，进「骨架」栏 | 进 §6 的「时间轴」线索 |
| 三档之外 | 从材料反推格名，回填「首动作」栏 | — |

结构档单独强调：格名是检索键，内容现场从材料填。结构档背错比背错一句话贵十倍——格名错了，整段答案的方向就错了。

## 3. 三层流水线（每层有出口判据）

| 层 | 动作 | 出口判据（过不了不许往下） |
|---|---|---|
| 理解 | 拆四元组：对象 / 格位两坐标 / 表述 / 排他点 | 说得出「为什么是这一格，不是隔壁格」 |
| 消化 | 分三档（§2）+ 按 §2.1 把该栏填进清单 | 合上材料**默出**格名序列（自由回忆，不是再认）；给一段材料能反着套到格上 |
| 背诵 | 只留排他项、层级坐标、易混表述对照 | 见到设问动词立刻定骨架；易混表述不串；层级不错位 |

验收证据：

- 测试效应（retrieval practice / testing effect）有稳定证据，效应量中等（`文献·` Rowland 2014, *Psychological Bulletin*；Adesope 等 2017, *Review of Educational Research*）。本文不引用任何单一数字当门槛：效应中等意味着「多回忆有效」，不意味着「一背就成」。
- **两种验收对应两种任务**：分析题考自由回忆，出口是「默得出来」；客观题考再认＋辨析，出口是「认得出来、分得清」。重读产生的熟悉感对后者够用、对前者不够——不是「再认是错觉」，而是同一份材料按题目形态走两条验收线（§6）。
- 间隔与重复由节律保证（§9 第 6–7 天只复习错项），不依赖任何软件。
- 退回是常态：错一次就退一层（§7），不是「再背十遍」。重复强化的是错的格位，越背越牢。

## 4. 反推表：模块 → 首动作 → 材料侧留什么

**模块先于动词**：动词决定走哪个格，模块决定格子在哪个体系里。

| 模块（题号） | 首动作 | 骨架 | 材料侧必背 | 直接划掉 |
|---|---|---|---|---|
| 马原（34） | 定位**原理名** | 原理名 + 原理句 → 展开 → 材料句 → 方法论/启示 | 高频原理的准确名称与术语群 | 论证推导、教材式铺陈 |
| 毛中特/习（35） | 定政策对象 | 🅰 是什么 → 为什么 → 怎么办，逐段下钻 | 地位词、层级坐标、措施格名 | 展开措施、宣传句 |
| 史纲（36） | 定历史阶段 | 背景 → 过程要点 → 历史意义 → 经验启示 | 事件名、阶段名、会议名 | 细节过程 |
| 思修（37） | 定概念 | 概念 → 重要性 → 实践要求 → 辩证关系 | 概念定义、关系词对 | 举例 |
| 当代（38） | 定时政议题 | 中国立场 → 依据 → 主张/意义 | 官方表述的关键短语 | 论述展开 |

当代题那一列**每年重取**：来源固定为当年时政小册子 / 报告原文 / 白皮书（`官方·`），不在本文件锁定，也不沿用往年——时政不重取，这份方法论第二年就过期。

### 4.1 代号（🅰🅱🅲🅳🅵 是什么）

沿用原体系的段位代号。代号只指**段**，不指内容；内容一律现场从材料填。

| 代号 | 指哪一段 | 何时用 |
|---|---|---|
| 🅰 | 35 题主骨架：是什么 → 为什么 → 怎么办 | 定政策对象的题 |
| 🅱 | 为什么段走「性质 → 地位 → 作用 → 意义」 | 问地位、意义 |
| 🅳 | 为什么段走「理论 / 历史 / 实践依据」 | 问依据、为什么能 |
| 🅵 | 怎么办段走格序（指导思想 → 原则 → 目标 → 任务 → 保障） | 问怎么干 |
| 🅲 | 怎么办段走主体清单（党 / 政府 / 人民 / 社会组织） | 问谁来干 |

### 4.2 35 题内部下钻

下钻只在 35 题内部展开，别外推到其他模块：

| 答案侧 | 材料侧必背 | 直接划掉 |
|---|---|---|
| 是什么 | 性质、内涵的**唯一**表述（「……是……」） | 展开说明、顺带的意义 |
| 为什么 · 🅱 | 性质 → 地位 → 作用 → 意义的层级坐标与排他词 | 论证句、举例 |
| 为什么 · 🅳 | 理论 / 历史 / 实践三条依据的类别归属 | 具体论证过程、年代 |
| 怎么办 · 🅵 | 格序：指导思想 → 原则 → 目标 → 任务 → 保障（原体系标「六格」而列五格，按五格背） | 展开措施 |
| 怎么办 · 🅲 | 主体清单：党 / 政府 / 人民 / 社会组织 | 措施细节 |
| 专项 · 制度 | 主体—内容—形式—保障 四个格名（可换 决策—执行—监督、结构—功能） | 逐条解释 |
| 专项 · 民主 | 一组环节名 + 官方定位语（原文照抄，不用教辅口号） | 环节内涵 |
| 专项 · 关系 | 六种关系词对 + 「反对××主义错误倾向」这一句 | 例子 |
| 自查层 | 易混表述对照、应然 / 实然对照 | 不进答案 |

这张表的用处是砍材料：逐段对照，落在「划掉」列的直接不背，背诵量通常剩不到一半。**减的是背诵量，不是答题字数**——而字数的来源是材料句：一格 2–3 条主点，每条配一句材料指认（§8 的篇幅就这么填满的）。砍材料不等于少答题，也不等于少写字。

## 5. 自查清单（替代卡片）

一张 A4、一题一行、四栏。写不下的那栏就是没读懂的格位。

| 栏 | 填什么 | 判据 |
|---|---|---|
| 模块 · 首动作 | 题号 → 模块 → 首动作（§4） | 见到设问动词 5 秒内说出首动作 |
| 骨架 | 该模块的格名序列（§4 骨架列） | 合上材料默得出，顺序不错 |
| 词对 | A 指什么 / B 指什么 / 判据一句（§1.1、§2.1） | 换一个字不改对象，才算过关 |
| 出口 | 该层出口判据（§3） | 过不了就退一层，不退步只重抄 |

三条规矩：

- 只写格名与词对，不写句子——写了句子说明还在理解层。
- 一页写满即止，不换第二页：一页装不下的材料，多半是该砍的材料（§4）。
- 每周重抄一次清单，抄不出的那一栏就是错的格位，按 §7 归因。

## 6. 客观题：三条线索

客观题不考格位，考名称、结论、年份之间的硬绑定。分数与题型按 `二手·`（约 50 分，16 单选 + 17 多选），以当年真题为准。

- **时间轴**：事件 → 年份 → 阶段（史纲主链优先）。同一事件只有一行，重了就是没分阶段。
- **三列**：会议 / 文件 → 核心结论 → 年份，三列缺一列就是赌。
- **词对**：A 修饰谁 / B 修饰谁 / 判据一句（与 §1.1 同格式，可复用清单的「词对」栏）。

两条纪律：

- 多选题的判据是「每一组词对都说得出区别」。说不出区别的选项就是在赌——先把该组词对写进清单，再谈选不选；具体给分规则属 `二手·` 口径，本文件不推断。
- 客观题错题按 §7 归到「术语错」，修法是补该行词对，不是重读整章。

## 7. 复盘契约（错题接回背诵）

| 错因 | 症状 | 修法 |
|---|---|---|
| 定位错 | 原理名/政策名唤错；地位题答成作用题 | 重画该对象的两坐标；马原补原理名清单 |
| 术语错 | 一字之差，或把口诀当条文写；客观题认得出却选错 | 补「词对」栏：正确答案 + 错误答案 + 一句判据 |
| 材料错 | 通篇原理、没有材料句，或只抄材料 | 每条要点强制配一句材料指认 |
| 骨架错 | 模块认错、设问动词没圈对，答了不需要的段 | 回 §4 首动作表，重背「模块 → 骨架」 |
| 时间错 | 想写全才落笔，写完三题就没时间 | 按题硬停（§8），先写骨架再补点；下一套卷子只练截断 |

归因只能落在这五类之一。落不进去 = 没读懂材料，处理是重做 §1 的四元组，不是加重复次数。

## 8. 取舍纪律与篇幅

- 阅卷口径是「踩点给分」；「多答不错不扣分」是多家教辅口径的一致说法（`二手·`，官方细则未公开）。关键限定：**多答「错」照扣**——原理名错、术语不规范、政治性表述出错，都会把前面挣的点吐回去。所以「多写」不等于「写不确定的东西」。
- 原体系「全填＝八百字套话＝反模板机制下掉档」查无依据，删除。
- 真正的扣分动作只有四类：原理名错（`二手·`：经验上属单点最大失分项，具体分值不采信）、术语不规范、不结合材料、答非所问。
- 纪律不是「少写」，而是**每条都要有落点**：一格 2–3 条主点，每条 2–3 句；一问 2–3 点，一题两问共 4–5 点。这些是**可调的工作参数，不是评分规则**。
- 篇幅与时间：10 分题 300–500 字、20–25 分钟，原理与材料约 6:4（`二手·`：新东方在线、中国教育在线口径）。字数按答题卡留白定，**宁多不错**；写不下是没取舍。
- 时间账（自算，不引机构）：180 分钟里客观题约 50 分钟，余 130 分钟 ÷ 5 题 ≈ 26 分钟一题——20–25 分钟/题是这条账上限内的取值。

## 9. 一周落地（拿 [[政治地位题目]] 当样板田）

1. 第 1 天：五模块首动作（§4 主表）。默写，不看表。
2. 第 2 天：35 题下钻判据——为什么段 🅱 或 🅳、怎么办段 🅵 或 🅲 的二选一。
3. 第 3 天：结构档全量——🅵 五格格序、🅲 三问、制度四格、一组环节名、六种关系词对、两种错误倾向。只背格名。
4. 第 4 天：样板田——先把 §1.1 那三行词对写进清单，再拿 [[政治地位题目]] 的条目逐条拆格、填「骨架」「出口」两栏（约 30 行）；该笔记本身是 `二手·` 材料，只练拆格动作，不当条文依据。
5. 第 5 天：客观题三线索（§6）——时间轴取史纲主链，三列取当年时政册，词对取清单里已有的行。
6. 第 6 天：闭卷默写（分析题）＋限时客观题；错因按 §7 归因，只补错的那一类。
7. 第 7 天：只复习错行；进度按成功提取次数计，能默写即停，不刷覆盖。
