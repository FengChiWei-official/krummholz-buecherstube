## 0. 一句话

塞音有两个各自可测的时段：**闭塞段**（声带振不振 = 清浊）与**除阻之后**（声门开多久 = VOT/送气）。汉语只用后一段，拉丁语只用前一段，英语把后一段当成前一段用——三个语言在同一张二维图上占了三块不同的地方。

## 1. 两条轴的物理定义

| | 清浊 | 送气 |
|---|---|---|
| 定义 | 闭塞段（塞擦音还包括擦音段）声带是否周期振动 | 除阻后声门开放、气流泄出的时段长度 |
| 声学锚点 | 闭塞期低频周期性（voice bar、脉冲、HNR） | VOT、爆破后噪声段、后接元音的 F0 扰动 |
| 测量 | Praat：脉冲轨 + 波形上的规律低频 | Praat：爆破点 → 浊音起点的时差（见 Praat 卡 4.2） |
| 能否独立 | 能（拉丁语：浊而不送气） | 能（汉语：清而分送气） |

VOT 参考值 `[已核]`：

| 类型 | VOT | 例 |
|---|---|---|
| 不送气清 | 0–30 ms | 汉语 b、英语 `spy` |
| 送气清 | 50–100 ms | 汉语 p、英语 `pie` |
| 浊（负 VOT，闭塞期已振动） | −100 – 0 ms | 西班牙语 b、吴语 b |
| 英语词首"浊"塞音 | 0–10 ms（短滞后，不振） | `buy` |

## 2. 二维平面：三个语言各占哪一块

| | VOT 短 / 负（不送气） | VOT 长（送气） |
|---|---|---|
| **清**（闭塞期不振） | 汉语 b d g；**英语词首 b d g**；拉丁 p t k | 汉语 p t k；英语词首 p t k；拉丁 ph th ch（借词） |
| **浊**（闭塞期振动） | 拉丁 b d g；英语元音间 b d g；吴语 b d g（气声） | 印地语 bʱ dʱ ɡʱ |

这张表就是全卡：

1. **汉语的 b ＝ 英语的 b ＝ 拉丁的 p**，同一格。三语的"清浊"其实指三件事。
2. 英语的 p/b 对立落在 **VOT** 上，所以词首并没有真浊音可对比——`buy` 的 b 不振。
3. 浊 + 送气（气声）少数语言才有；浊 + 长 VOT 在气动上要"先振动再猛泄气"，罕见。

气动原因（解释力最强的一条）：闭塞期间口腔是封闭的，可供振动的气只有口腔那点容积，压力约 50 ms 就顶满，振动随即停。所以浊塞音普遍靠**负 VOT**（除阻前就开始振动）；英语走了另一条路——词首不振，改用 VOT 区分。**清浊与送气在物理上是同一根 VOT 轴的两端，语言只是各取一端当音位。**

## 3. 符号对照

### 3.1 塞音

| 部位 | 清 | 浊 | 浊送气 |
|---|---|---|---|
| 双唇 | p | b | bʱ |
| 齿 / 齿龈 | t̪ / t | d̪ / d | dʱ |
| 卷舌 | ʈ | ɖ | ɖʱ |
| 硬腭 | c | ɟ | ɟʱ |
| 软腭 | k | ɡ | ɡʱ |
| 小舌 | q | ɢ | ɢʱ |
| 声门 | ʔ | — | — |

### 3.2 塞擦音

| 部位 | 清 | 浊 | 清送气 |
|---|---|---|---|
| 唇齿 | pf | — | — |
| 齿龈 | ts | dz | tsʰ |
| 龈后 | tʃ | dʒ | tʃʰ |
| 卷舌 | ʈʂ | ɖʐ | ʈʂʰ |
| 龈腭 | tɕ | dʑ | tɕʰ |
| 软腭 | kx | — | — |

送气符号写在整个塞擦音之后（`tʃʰ`），但 VOT 的**起点在塞音的除阻处**，长的部分其实是擦音段——这正是上一版把"送气擦音"搞错的地方。

### 3.3 汉语拼音 → IPA（最容易错的一张）

| 拼音 | IPA | 类型 |
|---|---|---|
| b d g | p t k | 不送气清塞音 |
| p t k | pʰ tʰ kʰ | 送气清塞音 |
| z zh j | ts ʈʂ tɕ | 不送气清塞擦音 |
| c ch q | tsʰ ʈʂʰ tɕʰ | 送气清塞擦音 |
| — | b d ɡ | 普通话没有（吴语有，且是气声浊） |

`z` 不是 [z]，`zh` 不是 [ʒ]，`j` 不是 [dʒ]——三个都是塞擦音。

### 3.4 英语拼写 → IPA

| 拼写 | 词首 | 词中 | 词尾 |
|---|---|---|---|
| p | pʰ（pie） | p（spy） | p̚（lip） |
| b | **p**（buy） | b（habit） | b̥（cab） |
| t | tʰ（tie） | ɾ（writer）/ ʔ（button） | t̚（bit） |
| d | **t**（die） | ɾ（rider） | d̥（bad） |
| k | kʰ（key） | k（sky） | k̚（back） |
| g | **k**（go） | ɡ（bagger） | ɡ̊（bag） |
| ch / j | tʃ / dʒ | | |
| tr / dr | tʃɹ / dʒɹ（常塞擦化） | | |

### 3.5 拉丁拼写 → IPA

| 拼写 | IPA | 备注 |
|---|---|---|
| p t c | p t k | 一律不送气；`c` 永远是 [k] |
| b d g | b d ɡ | 真浊；`g` 永远是 [ɡ] |
| ph th ch | pʰ tʰ kʰ | 仅希腊借词 |
| qu | kʷ | 单音，不是 [kw] |
| gu | ɡʷ | 同上 |
| x | ks | 两个音，不是塞擦音 |
| z | z | 仅希腊借词 |
| — | 无塞擦音 | [ts tʃ dʒ] 都是罗曼语阶段才长出来的 |

## 4. 语流中的习惯

### 4.1 普通话 — 对立全在送气

| 现象 | 例子 | 机制 |
|---|---|---|
| 送气是唯一对立 | 爸 / 怕、姑 / 哭、资 / 疵 | 闭塞期不振，`b d g` 只是"不送气"的记号 |
| 送气可压缩、不中和 | 「太太」第二个 tʰ 变短 | VOT 缩短仍属送气范畴，不会变成不送气 |
| 不送气清音在浊环境被动浊化 | 好的 [xɑu̯də]、大概 [daɡai] | 声带被邻音带振，但不构成对立 |
| 没有塞音韵尾 | 只有 -n / -ŋ；入声只在吴、粤、闽 | 所以没有"词尾不除阻"和"词尾清化"这两个问题 |
| 塞擦音三套、无浊塞擦音 | z/c、zh/ch、j/q | 送气落在塞音除阻 + 擦音段 |
| 对照：吴语 | 帮 [p] / 胖 [pʰ] / 旁 [b̤] | 三向对立，浊音是气声浊 |

### 4.2 英语 — 对立名义上在清浊，实际在 VOT

| 现象 | 例子 | 机制 |
|---|---|---|
| 词首 b d g 不振 | `buy` [paɪ]、`die` [taɪ]、`go` [koʊ] | 对立由 VOT 承担，真浊音只在元音间 |
| /s/ 之后不送气 | spy、sty、sky | 汉语没有 sC 丛，这是汉语母语者的第一道坎 |
| 元音间 /t d/ 中和 | writer = rider = [ˈɹaɪɾɚ] | 闪音把清浊对立整个抹掉 |
| 词尾塞音不除阻 | lip / bit / back 读 [p̚ t̚ k̚] | 对立改由**元音时长**承担 |
| 前清音缩短元音 | price vs prize、bat vs bad | pre-fortis clipping：词尾对立的主要线索在元音上 |
| -ed 三选一 | walked [t] / played [d] / wanted [ɪd] | 同化，和 -s 的 [s]/[z]/[ɪz] 同理 |
| 逆同化 | ten bikes [tem]、that boy [ðæp]、good girl [ɡʊɡ] | 部位同化 |
| tr / dr 塞擦化 | tree [tʃɹiː] | 英语的塞擦音不少是这么来的 |

### 4.3 拉丁语 — 对立全在清浊，且没有塞擦音

| 现象 | 例子 | 机制 |
|---|---|---|
| p t k 不送气 | 希腊语用 π τ κ 转写（Πομπήιος、Καῖσαρ） | φ θ χ 留给希腊借词的 ph th ch |
| ph th ch 只在外来词 | philosophia、theatrum、chorus | 受教育者送气；Catullus 84 嘲笑 Arrius 乱加 h |
| b d g 真浊 | 词首也要振动 | 英语母语者最难过的一关（英语词首 b 不振） |
| 无塞擦音 | `c` 永远 [k]、`g` 永远 [ɡ] | [tʃ]/[dʒ] 是意大利语等后起的变化 |
| 长辅音是音位 | ager（田）vs agger（土堆）、anus vs annus | 时长是第三个维度，汉语、英语都没有 |
| 前缀同化 | adferre → afferre；in- → im-/il-/ir-；ob- → of-；sub- → suf-/sup-/sus- | 纯音系规则，与拼写无关 |
| 跨词连读 | sed et → se.det | 词末辅音与后词首元音重新音节化 |
| qu / gu | [kʷ] / [ɡʷ] | 单音，不是 [kw]/[ɡw] |

## 5. 互学的错配点

- **汉语 → 英语**：词首 p/b 基本能对上（汉语送气 ↔ 英语送气，汉语不送气 ↔ 英语短滞后）。真正的坎在词尾（bat/bad 靠元音时长）、/s/ + 塞音（spy）、元音间闪音。
- **英语 → 汉语**：词首也能对上，比想象中容易；难在送气强度（汉语更强）与轻声里的送气保持。
- **两者 → 拉丁**：汉语母语者的 p/t/k 直接可用（就是拼音 b/d/g），但 b/d/g 是全新音（要真振动）；英语母语者两样都要改——p/t/k 去送气，b/d/g 加振动。所以英语腔的拉丁语最重。

## 6. 常见错误

1. 把"不送气"当"浊"（汉语 b 不振）。
2. 把"送气"当"清"（两条轴可以独立）。
3. 把拼音 `z`/`zh`/`j` 当擦音（都是塞擦音）。
4. 把英语词首 `b` 当浊音（是清不送气 [p]）。
5. 用清浊解释汉语的词尾（汉语根本没有塞音韵尾）。
6. 把拉丁 `c` 读成 [tʃ]（意大利语习惯）。
7. 把拉丁 `qu` 读成 [kw]（是单音 [kʷ]）。
8. 以为塞擦音的送气落在擦音段之后（VOT 起点在塞音除阻）。
