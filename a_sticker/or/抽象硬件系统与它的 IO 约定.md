# 抽象的计算机系统与它的 I/O 约定

## 一、作为观念存在的抽象计算机系统

**最小内核：四条。**

1. **可寻址存储**：地址空间 A，每个地址映射一个定长位串。存储无类型、无结构——它只是一张「地址 → 位串」的表。
2. **有限寄存器组**：一小撮带名字的位串（PC、IR、通用寄存器、标志位）。这是机器「当前状态」的全部。
3. **时钟/节拍**：把物理时间离散化，状态只在节拍边界变化。节拍频率 = 机器的能力尺度；「速率差」这个概念就在这里诞生。
4. **固定的转移函数**：`next_state = f(state)`，其中 f 由「PC 指向的位串」与「寄存器内容」共同决定。这就是存储程序——**指令不在硬件里，指令是存储里的位串**。

**唯一动态对象**：取指 → 译码 → 执行，循环。整个抽象机器只有这一个动作，重复执行。

**最反直觉的一条**：机器里没有「类型」，也没有「指令 vs 数据」。两者同存一个存储、一个地址空间，机器靠**时间**（何时被取指）与**位置**（PC 指向谁）区分。这既是考纲的待解问题，也是不变量 3（控制即数据）的根。

**边界**：抽象机器是一个封闭的状态转移系统。不与外界交换时，它只是自转的有限状态机——于是「存储有限」必须被「地址空间无限」的假象遮住，这是虚拟存储要回答的问题。

**分层不是设计口味，是被迫的**：机器节拍在 ns 级，世界（人、磁盘、网络）在 ms 级，速率差约六个量级；而机器对外只会做一件事——「按约定读写一个地址」。于是全部外部世界必须被投影成「某个地址上的位串」。这是 I/O 抽象的全部内容。

## 二、硬件视角下的输入输出

**定义**：对硬件而言，I/O 不是「设备」，而是**状态转移函数中被外部决定的那一部分**。

- 输出 = 机器把位串写进一个外部可读的位置（端口 / 内存映射地址 / 一次总线事务）。
- 输入 = 机器从一个「值由外部决定」的位置读位串——读到的值不是机器算出来的。
- 对 CPU 而言，I/O 与访存**是同一个动作**：都是「读/写一个地址」。差别只有两点：(a) 地址译码落到哪个空间（端口空间 / 存储空间）；(b) **数据何时有效**——主存总是准备好，设备不一定。

**难点不在传送，在协商。** 三个结构性困难，各对应一个根张力：

1. **不同源（异步）**：设备时序不受机器时钟控制 → 握手（就绪/应答）、中断（外部事件注入顺序执行流的唯一机制）、仲裁（多方竞争唯一的总线）。
2. **不同速（速率差）**：设备慢约六个量级 → 机器把「空转等待」改造成「去做别的」（中断、DMA、缓冲）——不变量 2 的又一次实例化。
3. **可能出错（差错边界）**：外部位串可能损坏 → 校验位/校验和；而「发现错误怎么办」与「数据没准备好怎么办」共用同一套流程：**暂停主线、委托慢的一方、回来续上**。

**中断的抽象地位**：机器原生控制流只有「顺序执行 + 跳转」；外部事件在任意时刻到来，而机器只在离散点检查——**指令边界**。所以中断 = 把连续的外部事件流投影到机器的离散检查点上。它与异常共用机制，因为两者都是「当前指令流无法继续」的同一种违约。

**DMA 的抽象地位**：搬运不需要智能，只需要「地址 + 长度 + 方向」。于是把这段循环从指令流里**外包**给一个专门的状态机（DMA 控制器），代价是它必须成为总线主设备 → 需要仲裁 → 回到「快慢两方如何对话」。CPU 从「执行搬运指令」降级为「配置 + 被通知」——控制即数据的又一次实例化。

## 三、它和谁做了信息解释约定

机器自身**不解释位串**：它只按约定重写与搬运。解释权由约定双方共同持有。

| 约定 | 双方 | 约定内容 | 违约后果 |
|---|---|---|---|
| **ISA**（指令系统） | 编译器/OS ↔ 微架构 | 位串 → 操作；寄存器与地址语义；异常语义 | 非法指令 / 未定义行为（软件只见硬件承诺，内部实现随意）|
| **设备接口 / 总线协议** | 设备控制器 ↔ 设备驱动 | 哪个地址是端口；状态位含义（就绪/忙/错误）；握手时序；中断向量语义 | 读不到数据 / 死等 / 误判完成 |
| **系统调用**（系统软件界面） | 用户程序 ↔ OS | 哪些操作必须委托给 OS；调用约定 | 权限异常 |

再往上一层是**人机界面**：位串 → 意义的最终持有者是人（图像、文本、声音）。四层底图里，每两层之间就是这样一条约定。

**三条约定的共同形状**：一方持有「含义」，另一方保证「搬运与重写」。ISA 里，「这条位串是加法」由编译器与硬件共同持有，硬件不关心里面的数代表什么；I/O 里，「这个字节是坐标还是字符」由驱动与设备控制器共同持有，总线不关心。

**最抽象的一句**：抽象计算机系统是一台「按节拍对位串做重写、且只通过地址与世界交换位串」的机器。它的智能在约定里，不在电路里；对外只承诺两件事——**按 ISA 重写位串，按协议搬运位串**。
