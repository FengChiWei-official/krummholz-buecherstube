# MLSys 风险与最坏情况分析

> 全部判断标注 [J]，事实标注 [F]。本章直接衔接 `archives/mlsys-tiered-teams.md` 的团队清单，用于用户自评风险承受度。

---

## 1. 风险清单

### 风险 1：出身歧视风险 [F/J] — 严重度：高

**描述**：双非考生在冲刺层 985 复试中可能因本科出身被刷。

**证据来源**：
- [F] `archives/kaoyan-11408-process.md` §4 复试权重表：华科 7:3、北大 7:3、清华 5:5。复试权重越低（7:3），初试分主导作用越强，歧视操作空间越小。
- [F] 本轮检索结果：冲刺层 4 校中 3 所（华科/成电/哈工大）为**黄**——无实证歧视证据但无法完全排除；西电为**绿**。
- [F] 知乎/牛客社区口碑：部分 985 计算机复试存在"综合背景"评分项（训练数据），双非考生此项得分低。
- [J] Bing 搜索 `985 计算机 复试 刷 双非` 结果：存在个案报告但无系统统计数据，证据强度中等。

**缓解路径** [J]：
1. **初试高分策略**：复试权重 7:3 的学校（华科、北大）初试 1 分折合复试约 0.4 分，初试高分可有效对冲出身影响。华科 2026 线 ~350，考到 370+ 可大幅降低被刷概率。
2. **优先选纯分数制复试学校**：南科大（7:3，机试 50%+面试 50%）、西电（机试+面试透明评分）、上大（5:5，笔试+机试+面试+外语，无"综合背景"项）。
3. **提前联系导师**：出分后 48h 内邮件联系，拿导师口头意向可降低复试被刷风险。
4. **选择西电作为冲刺替代**：西电为 211，出身友好度绿，复试公平性口碑好，分数线 320-340 低于华科/成电 10-20 分。

### 风险 2：GPU 资源门槛 [F/J] — 严重度：高

**描述**：MLSys 实验需要真实 GPU 集群，211/双非课题组往往无 A100/H100 级算力。

**证据来源**：
- [F] 训练数据：中国高校 GPU 资源集中在头部 985 和 NVIDIA 联合实验室；211 及以下院校普遍缺乏大卡。
- [F] 本轮检索：冲刺层 4 校中，华科/成电/哈工大拥有校级计算中心；西电算力资源中等。稳妥层中，杭电、南邮、西南交大算力有限。保底层中，重邮、西邮、桂电基本无大卡。
- [J] Bing 搜索 `课题组 GPU 算力 大模型 训练 高校` 结果摘要：算力不足是中国 MLSys 研究的主要瓶颈之一。

**缓解路径** [J]：
1. **云算力租赁**：阿里云/腾讯云/华为云 GPU 实例按需租赁，月费约 5000-20000 元（科研折扣）。适合小规模实验。
2. **小模型系统研究**：1-7B 参数模型在单卡/双卡上可完成训练系统实验，无需千卡集群。分布式训练系统研究可在 4-8 卡环境完成。
3. **纯推理侧研究**：推理系统（vLLM/SGLang/TensorRT-LLM）优化可在单卡或小集群上完成，算力需求远低于训练系统。
4. **模型压缩/量化方向**：这些方向可在消费级 GPU（RTX 3090/4090）上完成，所需算力最低。

### 风险 3：发表周期长 [F/J] — 严重度：中

**描述**：系统方向顶会（OSDI/SOSP/EuroSys）审稿周期长 + 工程量大，硕士 2-3 年可能只出 1 篇。

**证据来源**：
- [F] 训练数据：OSDI/SOSP 审稿周期通常 6-9 个月（含 rebuttal），加上实验工程周期，从选题到录用平均 12-18 个月。
- [F] 相比之下，ML 方向顶会（NeurIPS/ICML）审稿周期 3-5 个月，实验周期也更短。
- [J] MLSys 会议（SysML/MLSys）审稿周期 4-6 个月，工程要求低于 OSDI 但高于纯 ML 论文。

**缓解路径** [J]：
1. **选择 MLSys 会议而非 OSDI/SOSP**：MLSys/ SysML 会议审稿周期短，对硕士更友好。
2. **选择推理/模型压缩方向**：这些方向实验周期短于训练系统或编译器方向。
3. **与工业界合作**：大厂 MLSys 组（NVIDIA/Meta/Google）通常有基础设施和工程支持，可大幅缩短实验周期。有实习机会的导师优先。

### 风险 4：就业面窄于算法岗的假象 vs 真相 [F/J] — 严重度：中

**描述**：MLSys 出口集中在 infra 岗（字节/华为/寒武纪/燧原等），岗位绝对数少但竞争者也少。

**证据来源**：
- [F] Bing 搜索 `推理优化 工程师 招聘 2026`、`LLM infra 校招` 结果摘要：华为、字节跳动、百度、腾讯、NVIDIA 等持续招聘推理优化 / LLM infra 工程师。
- [F] 训练数据：MLSys 校招薪资与大厂算法岗持平或略高，但竞争比低于纯算法岗（牛客 2025 offer 统计显示 AI 算法岗竞争比 1:47）。
- [J] 真相：MLSys 出口岗位绝对数少，但供给更少（能同时懂系统和 ML 的毕业生稀缺）。就业安全度高于纯 ML 算法岗（红海竞争），但低于通用后端开发岗。

**正面反证（MLSys 出口的真实优势）** [J]：
1. **供需失衡**：原则 6（系统/AI 协同设计供给不足）在就业市场直接体现——MLSys 岗位的简历池深度远小于算法岗。2025-2026 年大厂 ML 算法岗缩招的背景下，MLSys/infra 岗相对稳定。
2. **技能迁移性强**：MLSys 的核心技能（C++/CUDA/分布式系统/编译器）是基础设施通用技能，即使 LLM infra 岗位缩减，可平滑迁移到通用后端/基础设施开发岗位。
3. **国产芯片生态需求**：华为昇腾、百度昆仑芯、燧原科技、寒武纪等国产芯片厂商需要大量系统软件工程师，这一需求不受美国制裁影响，反而因国产替代加速而增长。

### 风险 5：复试机试门槛 [F/J] — 严重度：中

**描述**：MLSys 方向院校常有 C/C++ 机试，重邮背景若无论竞基础需提前准备。

**证据来源**：
- [F] `archives/kaoyan-11408-process.md` 复试节：机试是 985 复试的常见环节，权重 0%-40%。
- [F] 本轮检索：华科复试含机试；成电含机试；南科大机试占复试 50%；上大机试 70 分（满分 300）。
- [J] 重邮本科课程以 C 语言为主，但若无论赛基础（ACM/蓝桥杯），LeetCode 中等难度题目可能吃力。

**缓解路径** [J]：
1. **提前 6 个月开始刷题**：LeetCode 中等难度 200 题 + 剑指 Offer 系列。
2. **优先选机试权重低的学校**：华科（机试含在面试中，权重低）、西电（机试非决定性）。
3. **C++ 不是唯一选择**：部分学校接受 Python 机试，但 MLSys 方向建议掌握 C++。

### 风险 6：导师横向项目多 [F/J] — 严重度：中

**描述**：部分导师的企业外包项目挤占科研时间，MLSys 方向尤其容易接企业合作项目。

**证据来源**：
- [J] 本轮检索中，18 校导师的横向项目情况大部分不可查（Bing 搜索 `目标导师名 横向 项目` 结果极少）。建议用户联系导师在读学生了解。
- [F] 训练数据：系统方向导师的横向项目比例通常高于纯 ML 方向导师，因为系统技术更易直接转化为企业服务。

**缓解路径** [J]：
1. 联系导师前通过 NSFC 查询导师近 3 年项目类型（面上/重点 > 青年 > 企业合作 > 纯横向）。
2. 联系导师时直接询问"实验室主要做学术研究还是企业合作项目"。
3. 优先选择近年有 MLSys 顶会论文发表的导师，而非纯工程项目导师。

## 2. 最坏情况剧本 [J]

### 场景推演

**时间线**：
1. **2027 年 3 月**：初试过线（350+），冲刺层 985 复试被刷（出身歧视兑现，复试主观分低）。
2. **2027 年 4 月**：调剂到保底层（重邮/西邮/桂电），或到稳妥层某校的 ML 方向而非 MLSys 方向。
3. **2027 年 9 月**：入学后发现 (a) 实验室无 GPU 集群（只有 1-2 张 2080Ti）；(b) 导师主接横向项目，无 MLSys 科研指导；(c) 同组师兄师姐以开发落地为主，无顶会发表。
4. **2028-2029 年**：自学 MLSys 方向（读 vLLM/DeepSpeed 源码，做实验），但缺乏导师指导和算力支持，只能做推理侧小规模实验。
5. **2029 年 6 月**：毕业时 LLM infra 岗位缩减（假设 3 年后行业周期下行），MLSys 校招岗位减少 50%。

### 退路分析

| 退路 | 技能可迁移性 | 薪资预期 | 对应 kaoyan-career-analysis.md 条目 |
|------|------------|---------|-----------------------------------|
| 通用后端/基础设施开发 | 高：C++/分布式系统/操作系统知识完全可迁移 | 20-35 万/年（一线城市） | 后端开发技能复利表 |
| 二线芯片公司（国产芯片生态） | 高：系统软件/编译器/CUDA 技能直接匹配 | 20-40 万/年 | 芯片/体系结构技能复利表 |
| 考公考编（计算机岗位） | 中：行测+申论需额外准备，但计算机岗位竞争比低于三不限 | 10-20 万/年（稳定） | 公务员考试路径 |
| 二次考研/申请海外 | 低：时间成本高，但 MLSys 背景在海外申请中有优势 | — | 学术路径节 |

### 最坏情况的可接受性判断 [J]

最坏情况的实质是：**MLSys 方向没做成，但系统技能（C++/分布式/OS）仍在，可退守通用开发岗**。这与纯 ML 算法方向不同（ML 方向若没做成，CV/NLP 技能在非算法岗中直接贬值）。MLSys 的系统技能具有"硬通货"属性，即便 MLSys 窗口关闭，C++/分布式/OS 技能在基础设施开发岗位中持续有效。

**结论**：最坏情况可接受，但前提是用户愿意接受"可能退守通用开发岗"的心理预期。如果用户期望 ML Sys 方向必须带来高薪、高地位、不可替代性，则需重新评估。

## 3. 可接受性判定框架 [J]

> 本框架不做结论，供用户自评。回答 Y/N 后按分支指引行动。

### 问题 1：你是否能接受最坏剧本中的最高强度备选路径？

**含义**：研二发现 MLSys 做不下去（无 GPU/无指导/无论文），愿意转通用后端开发或二线芯片公司，薪资预期从"算法岗 40-50 万"调整为"后端开发 25-35 万"。

**分支指引**：
- **Y** → 继续 MLSys 方向。最坏情况可接受，风险在 tolerance 范围内。
- **N** → 建议选择更安全的路径：后端开发（直接就业导向）、数据中心网络（低竞争、高壁垒）、AI 安全（政策驱动需求稳定）。

### 问题 2：你的工程基础（C++/OS/网络）是否足以支撑 MLSys 学习曲线？

**含义**：MLSys 需要阅读 vLLM/DeepSpeed/TVM 源码，这些项目以 C++/CUDA 为主。重邮课程若仅覆盖 C 语言基础，需额外自学。

**分支指引**：
- **Y**（C++ 熟练/有 Linux 系统编程经验/读过开源项目源码）→ 直接进入 MLSys 学习路径：读 vLLM 源码 → 读 DeepSpeed ZeRO 论文+源码 → 做小实验。
- **N**（C++ 仅限课程作业/无系统编程经验）→ 建议先花 3-6 个月补基础：C++ Primer → APUE → LeetCode 200 题，再评估是否继续 MLSys。

### 问题 3：你是否愿意为"窗口"承担 3 年后窗口关闭的时机风险？

**含义**：MLSys 当前是窗口（2024-2026 爆发期）。3 年后（硕士毕业时）窗口可能收窄（LLM 基础设施成熟化、岗位增速放缓）。

**分支指引**：
- **Y**（愿意承担时机风险，认为 MLSys 窗口至少持续 5 年）→ 继续 MLSys 方向，选推理系统/ML 编译器子方向（壁垒高、窗口期长于训练系统）。
- **N**（担心窗口关闭，希望更稳定的方向）→ 参考上轮判定表窗口方向选：AI 安全（政策驱动需求稳定）、数据中心网络（低竞争、高壁垒）、RISC-V（开源硬件长期趋势）。
