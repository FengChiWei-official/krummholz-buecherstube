## 1. 假说 H 的陈述与可证伪形式

### 1.1 陈述

`[J]` **H**：当底层对象（样本点 / 像素 / 词元 / 状态）的自由度高到无法直接建模时，学科进展来自引入一个**中间层构件**（有效自由度），把高自由度对象**粗粒化为构件**，再在构件层上定义算法，并通过组合构件重建宏观行为。抽象层级的选择本身是驱动力，而非仅数据与算力。

### 1.2 可证伪形式的三个谓词

| 谓词 | 内容 | 形式 |
|------|------|------|
| **P1** | 每次范式跃迁可识别出一个**新构件**被引入（此前算法直接在底层对象上操作） | 跃迁表（§4.1）逐条可查 |
| **P2** | 构件化分**内容侧**（对数据/表示做划分）与**结构侧**（对计算图做划分）两类，被同一机制驱动 | §4.2 侧别标注 |
| **P3** | 构件层一旦确立，其后改进以**尺度/规模**为主而非新构件 → 跃迁稀疏、改进密集 | **未做定量检验**（§7.3） |

`[F]` H 的理论锚点在物理侧有正式表述：Anderson 1972「More Is Different」主张**每一复杂度层级都涌现新的有效规律**，不能由下层直接外推（`10.1126/science.177.4047.393`）。

### 1.3 与用户原表述的差异（AI 为主线后的改写）

- `[J]` 原表述"介观 ML 在内容上抽象、AI 在结构上抽象"——本文认为**这个二分要弱化**：结构侧的每次成功（卷积核、专家、注意力头）都伴随内容侧的重划分（特征、token、patch）。两者是**同一机制的两个投影**，而非两种学科。
- `[J]` "介观尺度 ML 是抽象"这一判断**维持**，且已验证为 CQUPT 粒计算纲领的直系（§2）。

## 3. 镜二：超导的"介观有效理论"范式

`[J]` 超导史给出的是**层间迁移的标准剧本**：多体微观哈密顿量不可解 → 造介观构件/序参量 → 在介观层写有效理论 → 由重整化群把层与层之间的"同一性"讲清楚。

| 层级 | 物理（超导） | 对应 AI |
|------|--------------|---------|
| 微观 | 电子–声子多体哈密顿量（不可直接解） | 原始样本 / 像素 / 词元（高维、离散、无结构） |
| 介观构件 | 库珀对、准粒子、序参量 | 卷积核与层次特征、词/图像 token 向量、粒球、expert、思维步 |
| 介观有效理论 | Ginzburg–Landau、BCS 平均场 | CNN 特征层次、Attention、MoE 路由、RAG chunk、CoT |
| 宏观/普适 | 配分函数、临界指数、RG 固定点 | scaling laws、涌现能力、"能力面" |

`[F]` 关键引用：BCS 微观理论（`10.1103/physrev.108.1175`，1957）；**层间不可外推**的纲领（Anderson 1972，`10.1126/science.177.4047.393`）；把"尺度变换"变成技术的重整化群（Wilson 1975，`10.1103/revmodphys.47.773`）。

`[F]` **两向通道已存在，且被正式发表**：
- 变分重整化群与深层网络之间的**精确映射**（`10.48550/arxiv.1410.3831`，2014，即"深度网络=粗粒化流"的直接主张）；
- 早年提议（`10.48550/arxiv.1301.3124`，2013）、后续追问"深度学习是不是 RG 流"（`10.1109/access.2020.3000901`，2020）、以及**反过来用深度学习去解函数重整化群**（`10.1103/physrevlett.129.136402`，2022）。

`[J]` 这条镜子的价值不在"物理预言了 AI"，而在**它给出了 H 的可操作模板**：一旦承认"层"，就会出现两类可研究问题——**造什么构件**（库珀对 vs 粒球）与**怎样跨层**（RG vs scaling law）。

## 6. 由 H 预测的 3 个可创新点

### C1 抽象层级 / 粒度搜索：把"在哪一层粒化 + 用什么粒化算子"变成可搜索空间

- `[J]` 现状：token 边界（BPE）、patch 大小、chunk 长度基本是**手工超参**；架构搜索只搜"同一粒度内的接线"。
- `[J]` 预测：把**粒化算子族**（切分 / 合并 / 球化 / 关系化）连同粒度一起纳入可微/可搜索设计，会释放与"换架构"同量级的收益。
- 锚：粒球分类器（`10.1016/j.ins.2019.01.010`）、粒度选择的决策化（`10.1109/tkde.2025.3566038`）、"深层网络即粗粒化流"（`10.48550/arxiv.1410.3831`）。

### C2 粒度预算 / 表示有效粒度的诊断学：预测"下一次跃迁必须发生在哪一层"

- `[J]` 现状：scaling law 只描述"参数量/数据量 → 损失"；没有描述"表示的有效粒度 → 可达性能"的量。
- `[J]` 预测：定义表示的有效粒度（率–失真意义下的粗粒化分辨率）并测其边际收益，可在跑大实验前判断"该层的粒化红利是否耗尽"，从而**指出下一个构件该在哪造**。
- 锚：scaling laws（`10.48550/arxiv.2001.08361`）、Chinchilla 的配比定律（`10.48550/arxiv.2203.15556`）、用 DL 反解函数重整化群（`10.1103/physrevlett.129.136402`）。

### C3 内容粒化的统一算子族：tokenization / chunking / memory / RAG / CoT 视为同一家族

- `[J]` 现状：这五件事分散在不同子领域，各有各的启发式；但都是"在内容上选边界"。
- `[J]` 预测：以"任务条件熵最小化（粒内同质、粒间可分）"为统一准则**学习粒边界**，可让检索单元、记忆合并、推理步切分共享一套算法。
- 锚：RAG 综述（`10.48550/arxiv.2312.10997`）、多模态 LLM 综述（`10.48550/arxiv.2306.13549`）、CoT 的中间步（`10.48550/arxiv.2201.11903`）。

`[J]` 三者的共同前提（也是本文最可下手的工程点）：**粒度目前是超参，而 H 说它应该是被优化的对象。**

## 7. 否证、反例与不确定项

### 7.1 对 H 的反例（证伪尝试）`[F]/[J]`

| 反例 | 事实 | 对 H 的伤害 |
|------|------|-------------|
| Adam（`10.48550/arxiv.1412.6980`，84 625 引） | 纯优化改进，无任何新构件，影响面巨大 | 进步**不必**来自新构件 → 削弱"唯一来源"读法 |
