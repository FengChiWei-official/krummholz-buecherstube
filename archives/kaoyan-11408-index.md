10. **冷校主流方向实测**：完成于 2026-09-18（使用用户自备 OpenAlex API key，1032 次调用 / $0.25），产出 `kaoyan-cold-groups.md`：以**会场 DOI 前缀**定义方向、以 `raw_affiliation_strings` 校验机构归属，给出 13 所冷校 × 5 主流方向（CV / LLM-NLP / Agent / 世界模型 / 具身机器人）的实测产出与组清单。三项须注意：(a) **OpenAlex 存在机构错挂**——「浙江大学计算机学院」被挂到浙江科技大学（支持率 8%），该类错误会把名校误判成冷校，任何冷校榜都必须做原始机构串校验；(b) NeurIPS/ICLR/ICML/CoRL/RSS/SIGIR/AAMAS 在 OpenAlex 无 DOI 可锚定，方向规模被低估；(c) 7 所产出可观的冷校（苏州/安徽/福州/广东工业/云南/南信大/齐鲁工业）在知识库中**没有分数线与名额记录**，须按该文 §6.1 亲读清单补齐后才能做上岸评估。
11. **名校相对容易位实测**：完成于 2026-09-19（复用缓存 + 318 次调用 / $0.025），产出 `kaoyan-warm-groups.md`：把知识库 43 所名校的分数线/名额与 OpenAlex A/B 产出对齐，给出三层结论——学校级（价差 = 产出分位 − 线分位；名额密度 = 专硕名额 ÷ A/B 产出）、方向级（校内相对冷门方向）、组级（**非头部但有 ≥8 篇产出的组**）。首选结论：**哈工大本部（CV/具身）**在产出（2264）、名额（95）、线（**330**，校区口径修正后）三项同时占优；次优山东大学（CV，线 320）、西北工业大学（CV 593 篇且非头部组体量大）。须注意：(a) 「非头部组」是竞争强度的**代理**指标，OpenAlex 无报考人数/录取名单，不能等同于「报的人少」；(b) 价差榜不含名额，清华计算机系以专硕 ~20 个名额伪装成高性价比；(c) 附录 11 所高产出名校（西电/国防科大/南京理工/华东师范/大连理工/深大/南科大等）知识库仍无分数线，须补录。
12. **校区可分离性（v2 修正）**：知识库 [[kaoyan-scores]] 按**校区行**记分数线（清华 3 行 / 北大 2 行 / 哈工大 2 行），OpenAlex 只有学校级实体，v1 版曾把三校的校区行串成混合值。实测结论：**北大深研院可用署名串切分**（`kaoyan-warm-groups.md` §1.2：CV 8 会场 175 篇、A/B 229 篇 = 北大全校的 9.9%；线 345 + 60 名额 vs 信科 355 + 65 → 名额密度 262 vs 31；但 ACL 系仅 5 篇，方向极偏视频编码/多媒体/3D）；**哈工大深圳、清华深研院不可分离**（哈工大 CVPR 全量 311 篇中 "Shenzhen" 署名串为 0；清华深圳国际研究生院实体 `I4405263052` works_count = 0）。切分时须防两类污染：哈工大深圳旧英文名含 `Shenzhen Graduate School` 子串；`Peng Cheng Laboratory, Shenzhen` / PKU 深圳医院署名不属深研院。
13. **华南师范大学个案**（`kaoyan-warm-groups.md` §7）：知识库原无华师记录，本轮补录。**报考侧最松**——2025 复试线 260（= 当年工学国家线）、2026 学硕计划 71 人（计算机 48 + 人工智能 23，较 2025 的 44 扩招 61%）、复试差额 1:1.5、2025 计算机技术实际录取初试 295–361。**产出侧偏弱**——A/B 128 篇（CV 62 / ACL 系 34 / AAAI 23 / 具身 9），广州同城仅高于暨大（64），低于广工（250）、深大（629）、华工（783）。**两个结构性问题**：(a) 会场率低——9 位主要 PI 中，潘家辉（96 篇总产出/4% 落 A/B 会场）、郝天永（93/5%）、蒋运承（79/4%）的主战场在本文会场清单之外，须问清学生实际发表会场；(b) **署名结构异常**——卢宇武一作率 57%（CV 会场论文 12/13 篇本人一作，学生多居中间位），与同校郝天永 0% 一作/63 篇末位（学生一作-导师通讯）形成对照，符合 [[kaoyan-sources]] §4.3「导师抢一作 = 避雷」判据，但结论标 [J] 须现场核实。可报组排序：李双印（会场率 28%/一作率 7%）> 陈保良（55%/27%）> 黄振华（20%/4%）> 卢宇武（36% 但需核实）> 郝天永 TAM Lab（名头最硬但 A/B 会场率 5%）。
14. **中科大教师全景**（`kaoyan-ustc-faculty.md`）：全量拉取 USTC 计算机领域 2023-2026 作品（9498 篇、13384 个作者 ID），按 **OpenAlex author ID 而非姓名**聚合（实测「Li Li」在同校有 12 个 ID、「Hao Wang」16 个、「Kai Zhang」27 个，按姓名聚合会合错人），得到 **161 位 PI（单 ID ≥18 篇）**：数据挖掘/推荐 42、CV/多媒体 35、网络/系统 28、安全/隐私 24、NLP/语音 14、量子（物理学院）9。两个可操作结论：(a) **署名健康度极高**——161 位 PI 的一作率普遍 0–4%，「导师抢一作」在 USTC 基本不存在（对照华南师大卢宇武 57%）；(b) 风险在**组太大排不上**——陈恩红 220 篇/146 位独立一作、俞能海 156/104、李厚强 137/87，建议选 18–39 篇档的中小组（116 位，其中傅雪阳 71%、张天柱 90%、毛震东 71%、吴枫 71% 的 A/B 会场率）。另须注意 USTC 的 CS 力量分散在计算机学院/人工智能与数据科学学院/网络空间安全学院/信息科学技术学院，报考须按学院分别查。
