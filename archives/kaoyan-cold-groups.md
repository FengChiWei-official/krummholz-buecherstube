# 冷门学校 · 主流方向 · 课题组实测（2027 考季）

> 目标：回答两个问题——**(1) 学生会出成绩的主流方向有哪些；(2) 学校偏冷（分数低/名额多/名气小）的组有哪些。**
> 方法：**会场即方向**（CSRankings 口径），不靠关键词猜；「冷」用全国产出排名 + 知识库分数线/名额定位。
> 事实 `[F]` / 判断 `[J]` 分区。全部数字来自 OpenAlex 实测（时间窗 2023-2026，机构限定 CN）。

## 0. 口径（前置，执行中未更改）

| 项 | 定义 |
|----|------|
| **方向** | 用**会场 DOI 前缀**锚定，不用关键词。例：CV = `10.1109/cvpr` `10.1109/iccv` `10.1109/wacv` `10.1109/tpami` `10.1007/s11263` `10.1109/tip` `10.1109/tmm` `10.1109/tcsvt`；LLM/NLP = `10.18653`（ACL 系）+ `10.1162/tacl`；具身 = `10.1109/icra` `10.1109/iros` `10.1109/lra` `10.1109/tro` |
| **Agent / 世界模型** | 无专属 DOI 段（AAMAS/SIGIR 在 OpenAlex 无覆盖），只能用**会场 ∩ 标题摘要词**：Agent = (AAAI∪ACL∪ACM) ∩ `agent`；世界模型 = (CVPR∪ICCV∪AAAI∪ACM) ∩ `world model` |
| **出成绩** | 落在上述 A/B 会场的论文数（不是总发文量——总发文量被水刊和数据错误污染） |
| **学生能出成绩（代理指标）** | **非头部一作领衔占比**：一作不是该校该方向最高产 3 人的论文比例。高 = 多学生各自领衔，低 = 少数 PI 包办 |
| **冷** | 三条件之一：复试线低 / 统考名额多 / 名气小（学术体量小）。知识库有分数的直接用，无记录的标 ⚠️ |
| **机构归属校验** | 逐校比对 `raw_affiliation_strings`；支持率 <90% 的学校剔除（见 §6） |

2. **苏州大学是冷校 NLP 断层第一**：ACL 系 129 篇（全国第 13 名量级），但 CVPR 仅 4 篇——**方向极偏，选它等于选 NLP**。

5. **桂电 20 篇、西邮 34 篇**：两校在五个方向的 A/B 产出都很低（CVPR 合计 1 篇）。它们的强项不在这里（桂电在存储/边缘、西邮在云计算调度）。**为「好上岸」选它们合理，但别指望这些方向。**
6. **安徽大学 / 福州大学 / 广东工业 / 南信大**在三个以上方向都有两位数产出，是「冷校里的多面手」。

## 6. 数据质量与限制（必读）`[F]`

1. **机构错挂（最重要）**：OpenAlex 把 `College of Computer Science and Technology, Zhejiang University` 的机构串判给 **浙江科技大学**，导致该校 CV 方向虚高到 201 篇（原始串支持率仅 **8%**）。**已剔除**。同样问题使 **深圳技术大学** 支持率仅 **19%**（与深圳理工大学、港中深混串），**已剔除**。其余 13 校支持率 91–100%，保留。→ **任何基于 OpenAlex 机构过滤的冷校榜，都必须做这一步校验，否则会把名校误判为冷校。**
2. **group_by 口径**：机构/作者的聚合计数是「作者-机构对」，合作论文会被多校各计一次（例：TACL 全国 69 篇 → 分组和 168）。因此**分组和 ≠ 去重篇数**，只在排序意义上使用。
3. **会议覆盖缺口**：NeurIPS/ICLR/ICML/CoRL/RSS/SIGIR/AAMAS 无 DOI 前缀可锚定，CVPR/ICCV/ICRA/IROS 在 OpenAlex 的记录也明显少于真实（CVPR CN 仅 4208）。**绝对数是下界，方向间不可直接比大小。**
4. **「学生能出成绩」是代理指标**：用「非头部一作领衔占比」近似，未直接验证一作是否为硕士生（可能含本科生/青年教师）。高比例只说明**产出分散、非 PI 包办**。
5. **会议论文的 primary_location.source 为空**：OpenAlex 中 `type=conference-paper` 记录多数没有 source 实体，故**不能用 source.id 做会场过滤**，只能用 `doi_starts_with`。
6. **开放评审（每年 9-10 月）**：本节所有数据为 2026-09-18 快照，2026 年论文仍在入库（下半年的会尚未收全），故 2026 数字偏低。
7. **报考侧数据缺失**：7 所冷校（苏州/安徽/福州/广东工业/云南/南信大/齐鲁工业）在知识库中**没有任何复试线/名额记录**，必须按下表亲读补齐。
