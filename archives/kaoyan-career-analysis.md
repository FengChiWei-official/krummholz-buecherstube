## 1. 历史类比：三个技术时代价值迁移

### 1.1 观察框架

以下基于公开的技术与商业史实（训练数据），以三个划时代的技术转折为锚点，观察每一时期**价值在产业链的哪个层面积累**、**哪些技能在 10 年尺度上复利**、**哪些角色在交接中消失**。

> 每条历史断言标注 [来源]；数据日期为 2026-09-03，反映截至此日期的已公开历史。

### 1.2 时代一：Web 1.0（1995-2005）

| 维度 | 内容 |
|------|------|
| **标志事件** | Netscape IPO (1995-08-09)；Google 成立 (1998)；雅虎巅峰 (2000)；亚马逊从书店到平台 |
| **价值核心** | 建站工具 + ISP 接入 + 门户广告 + 电商基础设施 |
| **基础设施层** | 网络带宽扩容、数据中心托管 (Rackspace 等)、Web 服务器软件 (Apache) |
| **平台层** | YAHOO! 门户、AOL 接入网、eBay 交易平台、Amazon 电商平台 |
| **应用层** | 个人页、BBS、早期电商站、分类广告 |
| **幸存者** | Amazon (→云计算巨头)、Google (→AI 巨头)、腾讯 (1998, →社交巨头)、百度 (2000, →中文搜索) |
| **消失者** | AOL (拨号→宽带走)、MySpace (社交→Facebook 替代)、Netscape (浏览器→IE/Chrome)、Yahoo (门户→搜索转型失败→收购) |
| **价值分布特征** | 基础设施与平台捕获 >80% 长期价值；应用层公司 90% 在 10 年内消失或严重萎缩 |
| **技能折旧** | HTML 手写、CGI 脚本、ISP 技术、浏览器判定 (compatibility hacks) |
| **技能复利** | TCP/IP 网络、HTTP 协议、数据库设计、大规模运维思维 |

> **数据来源**：Google/Netscape/Yahoo 成立时间与 IPO 为公开史实。幸存/消失分类基于 2025 年市值 >0 公司的回看，属技术史共识。

### 1.3 时代二：移动与云（2007-2020）

| 维度 | 内容 |
|------|------|
| **标志事件** | iPhone (2007-01-09)；Android 开源 (2008)；AWS EC2 (2006)；Facebook 崛起 (2004-2012)；微信 (2011)；字节跳动 (2012) |
| **价值核心** | 移动应用 + 云服务 + 数据平台 + 广告系统 |
| **基础设施层** | 云厂商 (AWS/Azure/阿里云)、4G/5G 基站、智能手机硬件供应链 |
| **平台层** | iOS/Android 应用商店、微信生态、Facebook/抖音流量平台 |
| **应用层** | 出行 (Uber/Didi)、外卖 (Meituan/饿了么)、短视频 (抖音/TikTok)、社交 (微信/WhatsApp) |
| **幸存者** | Apple (→硬件+服务)、Google (→Android+AI)、Microsoft (→云+Copilot)、字节跳动 (→全球短视频)、阿里 (→云+电商)、腾讯 (→游戏+社交) |
| **消失者** | 黑莓、诺基亚手机业务、HTC 手机、Windows Mobile、大量「纯 app」创业公司 (没有生态锁定效应则 5 年内被大厂复制或收购) |
| **价值分布特征** | 平台层捕获最高利润率；硬件供应链 (台积电/三星) 获结构性价值；应用层赢家通吃但幸存率 <5% |
| **技能折旧** | Objective-C (→Swift/跨平台)、特定 API 框架 (UIWebView→WKWebView)、单机优化 |
| **技能复利** | 分布式系统设计、存储引擎原理、网络协议、安全模型、产品思维（人-机交互理解） |

> **数据来源**：iPhone 发布会日期 (2007-01-09) 为公开史实。AWS 创始时间 (2006) 为公开行业记录。各公司兴衰为技术史共识。

### 1.4 时代三：AI 时代（2020-至今；仍在早期）

| 维度 | 内容 |
|------|------|
| **标志事件** | GPT-3 (2020-06)；ChatGPT (2022-11-30)；GPT-4 (2023-03)；Claude 系列；Grok；DeepSeek；Sora |
| **价值核心** | **训练/推理算力** + **高质量数据** + **对齐/评估** + **AI 原生应用** |
| **基础设施层** | 大规模 GPU 集群 (NVIDIA)、定制 AI 芯片 (TPU/Dojo/昇腾)、数据中心互联、电力；**训练即基础设施**（模型训练成本 $10M-$1B）|
| **平台层** | 基础模型 API (OpenAI/Anthropic/Google/DeepSeek)、模型 Hub (HuggingFace)、ML 平台 (Weights & Biases/LangChain) |
| **应用层** | AI 搜索 (Perplexity)、Copilot 插件、AI 法律/医疗/教育助手、图像生成应用 |
| **2026 状态** | 基础设施层（算力+基础模型）捕获当前 >60% 的资本投入；平台层（模型分发+工具链）快速扩张；应用层面百花齐放但**商业模式仍在验证** |
| **来自前两代的推演** | 当前阶段的结构最像 1996-1998（Web 建成阶段）——基础设施商最先获利，平台层正在形成，应用层爆发尚未到来 |
| **哪些可能在 10 年后存活** | NVIDIA (算力垄断地位如当年英特尔)、基础模型寡头 (1-3 家)、云厂商的 AI 平台 |
| **哪些可能在 10 年后消失** | 纯「套壳」应用 (无数据飞轮/无用户锁定)、单用途 AI 工具 (被平台自带功能替代) |
| **技能折旧风险** | 特定模型 prompt 工程（2026 年已被自动化趋势替代部分）、纯 API 调用集成、单卡训练 |
| **技能复利** | ML 系统设计 (训练/推理框架)、数据工程、分布式计算、强化学习与对齐方法、数理统计基础 |

> **推演的来源依据**：基于通用技术采用曲线 (Rogers, 1962) 以及前两个技术时代的价值迁移模式，结合 Sutton (2019)「规模原则」与 Hennessy (2019)「硬件价值回归」判断。
> **此节分析级别：结构性推演 + 公开史实**，数据日期 2026-09-03。

### 1.5 横向模式提取（三条可迁移规律）

| # | 规律 | 出处 | 与考研方向的关联 |
|---|------|------|-----------------|
| 1 | **基础设施层价值最持久**：每次技术浪潮中，技术基础设施提供商（Web 的 ISP/托管 → 移动的云计算 → AI 的 GPU/模型训练平台）捕获了最稳定的长期价值。应用层财务回报可能更高，但幸存率极低。 | 历史归纳 + [Hennessy, 2019: 领域专用硬件价值] | 体系结构、系统、ML 系统等靠近基础设施层的方向拥有更宽的就业出口 |
| 2 | **平台层出现窗口期**：每次浪潮的中间点（Web 1998-2002 / 移动 2010-2014）会出现平台锁定机会，此时进入平台构建领域（而非应用层）可获得不对称回报。 | 历史归纳 + [Karpathy, 2017: Software 2.0 的平台化] | 系统、数据管理、安全平台（云安全/身份平台）等有平台化潜力的方向 |
| 3 | **通用技能 > 专用技能**：每个时代末期，工具/框架/特定 API 专长大幅折旧，而底层通用能力（网络、分布式、数学、系统设计）跨时代复利。 | 历史归纳 + [Sutton, 2019: 通用方法对人工设计的超越] | 选方向时应优先考虑训练通用能力（数学、系统、算法）的组，而非专注单一工具链的组 |

> ⚠️ **以上三条为基于历史模式的结构性推演，非已验证法则**。与 `kaoyan-cs-landscape.md` 中有出处的原则 1-3（Sutton/Hennessy/Karpathy）方向一致，但独立归纳。标注「历史归纳」= 来自训练数据中的公开技术史事实。

## 2. 终局分岔：就业 vs 学术

### 2.1 学术路径（高校教职）

#### 2.1.1 典型时间线

```
硕士 2-3 年 → 博士 4-6 年 → 博后 1-2 轮 (2-4 年) → 特聘副教授 3-6 年 → 长聘副教授 → 教授
           ↑ 第一份教职                                           ↑ 终身教职
```

- **从考研到终身教职的总计**: 约 10-15 年（硕士 2 + 博士 5 + 博后 2 + 特聘 3-6）
- **最小可行时间**（假设一路顺利、无延毕、教职不断档）：本科毕业 → 博士毕业 9 年（4+5）→ 首份教职（特聘副）11 年 → 长聘 ~15 年

> **来源**: 中国高校教师聘用制度常见结构（各校 2023-2025 招聘公告为公开信息）。代表作制度替代简单论文计数为教育部 2018-2023 系列政策导向（训练数据）。

#### 2.1.2 学术成功关键指标

| 指标 | 说明 | 判断（judgment） |
|------|------|-----------------|
| CCF-A 类论文 | 毕业时 2-4 篇一级会议/期刊（不同学校要求不同） | 硬门槛；**顶会（NeurIPS/CVPR/OSDI/ISCA）> 顶刊** |
| 代表作制度 | 2018 年起淡化论文数量，强调 K 项代表性成果的学术影响 | 2024-2026 已成为主流评价标准 |
| NSFC 青年基金 | **男 ≤35 岁 / 女 ≤40 岁**获青基是留校/转任教的硬门槛 | 博士毕业 28-30 岁，青基窗口 5-7 年；**博后期间若未申到则窗口缩小** |
| 教学能力 | 本科课程评估 + 指导学生毕设/竞赛 | 软要求，但低分评估 = 转岗风险 |
| 国际合作 | 海外经历（联培/博后/访问学者）在 985/211 教职竞争中接近硬要求 | judgment: 2025-2026 年 985 新聘助理教授中 >80% 有 1 年以上海外经历 |

> **事实来源**: 各校 2024-2025 教师招聘公告（训练数据中公开信息）；年龄限制为 NSFC 官方规定。

#### 2.1.4 学术路径的窗口信号（leading indicators）

- **正面信号**: 所在团队近 2 年连续产出 CCF-A 论文、导师刚获 NSFC 重点项目或 2030 重大项目、方向为学校「双一流」重点建设方向
- **警示信号**: 导师两年内退休（可能断推荐链）、团队方向热度骤降（如 2024 年后纯 CV 检测任务门槛枯竭）、实验室论文平均投稿周期 >12 个月

> **方法依据**: 原则「选团队看一阶导数」[假设]；近 2 年发文/经费增长比当前声望更预示未来 3 年资源可得性。

## 3. 复利技能结论（框架驱动的判断）

### 3.1 框架回顾（从 `kaoyan-cs-landscape.md` 复读核心部分）

| 原则                    | 来源                      | 对技能选择的含义                                    |
| --------------------- | ----------------------- | ------------------------------------------- |
| **原则 1：规模是终极区分器**     | Sutton, 2019            | 能理解和利用大规模系统（大数据/大模型/大规模分布式）的技能 > 小规模精雕细琢的技能 |
| **原则 2：手工知识方法先升后平**   | Sutton, 2019; 张钹, 第三代AI | 仅掌握「调库/调参/搭 pipeline」的手工技能贬值最快              |
| **原则 3：领域专用架构复兴**     | Hennessy, 2019 CACM     | HW/SW 协同设计能力在每个层面（CPU/GPU/NPU/网卡）增值         |
| **原则 4：数据 > 代码**      | Karpathy, 2017          | 数据工程 + 数据策展能力 > 纯算法能力；训练数据作为核心资产            |
| **原则 5：世界模型是开放前沿**    | LeCun, 2022             | 能设计/改进架构（而非只使用现有模型）的技能长期复利                  |
| **原则 6：系统/AI 协同供给不足** | Dean; Hennessy, 2019    | 「懂系统的人懂 ML + 懂 ML 的人懂系统」双重稀缺                |
| **原则 7：CS+X 构成护城河**   | 姚期智; LeCun, 2022        | 单一 CS 技能的通才竞争过度；领域专长 × 计算技能的乘积效应            |

### 3.4 针对考研者的策略结论（judgment）

基于以上框架+历史分析，对 11408 考生的方向选择建议按优先级排序：

1. **优先级最高——ML 系统与 AI 基础设施方向**
   - 框架支撑：原则 1 + 3 + 6 三重叠加
   - 历史类比：这相当于 2008 年的云计算（基础设施爆发前夜，供给严重不足）
   - 就业出口：GPU 集群优化 → 训练框架开发 → AI 推理部署 → 全栈 AI 系统
   - 对应中国实验室：清华计图（MARS Lab）、北大系统所、中科院计算所 ML 系统组、华为昇腾生态

2. **次高——AI for Science / CS+X 交叉方向**
   - 框架支撑：原则 7（姚期智跨学科判断），原则 5（世界模型前景）
   - 历史类比：相当于 2012 年的数据科学（桥接领域人才稀缺→3 年内变成热方向）
   - **关键约束**：需要 CS 之外的第二个领域的入门理解力（生物/化学/物理/经济）
   - 就业出口：AI 制药 → 材料计算 → 量化金融
   - 对应：北大计算生物、清华 AI+Science（交叉院）、上科大

3. **可选——体系结构 / 计算机系统方向**
   - 框架支撑：原则 3（Hennessy 黄金时代）+ 原则 6（系统供给不足）
   - 历史类比：相当于 1990 年代微处理器设计（50 年一遇窗口重启）
   - 就业出口：芯片设计（CPU/GPU/NPU/NIC）→ 系统软件 → 体系结构研究
   - 对应中国实验室：中科院计算所（龙芯/寒武纪）、清华体系结构组、北大微处理器中心

4. **保守——AI 安全 / 可信 AI**
   - 框架支撑：原则 5（开放前沿） + 2024-2026 年政策驱动需求
   - 就业出口：大模型安全对齐 → 红队 → 安全合规 → 产业界（Google/OpenAI/字节）安全组
   - 对应中国实验室：清华网络安全研究院、浙大 AI 安全组

5. **警示——纯 ML/DL 算法（模式分类/预测）**
   - 框架支撑：原则 2（手工知识先升后平）+ 2024-2026 年算法岗招聘显著放缓的事实
   - 风险：2024-2026 年**求职市场已明显供过于求**；大量 CV/NLP 方向博士毕业生流向非对口岗位
   - judgment：除非能进入**发顶会的头部组**（清华/北大/中科院/上交 的 Top 实验室），否则纯算法方向的就业风险比 2018-2022 年显著上升

> **以上策略结论**: judgment。综合框架原则（有出处的部分）+ 历史类比 + 2024-2026 年就业市场观察（训练数据）。非预测性断言，需用户结合自身兴趣和 `kaoyan-labs-matrix.md` 的具体实验室数据自行决策。
