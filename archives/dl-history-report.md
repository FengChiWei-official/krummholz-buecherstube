# 深度学习简史：以学者的来时路、关注点、背景知识为动力

> **方法：辩证历史科学。** 不用"天才灵感"解释演进，而用三层可查的动力结构：**(1) 学者的来时路**——师承、机构、上一份工作决定的**可接触问题集**；**(2) 关注点**——他当时要解决的**具体**工程/理论难题（而非事后包装的宏大叙事）；**(3) 依赖的背景知识**——前序哪些构件、数学工具与硬件是**前提**。再叠加物质条件（算力、数据、评测、经费、组织形式）解释**议题为何在此刻转向**。
>
> 事实 `[F]` / 判断 `[J]` / 推断 `[INFERENCE]` 分区。本文引用的 **56 个 arXiv ID 经 arXiv 官方 API 全量核验，0 缺失**（2026-09-19）；机构与师承以 OpenAlex 作者档案 + 网页多源交叉，**作者消歧有噪声**（详见 §6.1）。

## 0. 结论摘要

- `[J]` **深度学习的驱动力是"矛盾—构件—议题"的三拍循环**，而非单点发明：旧范式的**具体失败**（深度退化、似然不可解、定长瓶颈、注意力 O(n²)）产生一个**新构件**（恒等捷径、判别器、注意力、稀疏/状态空间），构件一旦确立，**议题整体迁移**（从"能不能训"→"能不能扩"→"能不能省"→"能不能推理"）。
- `[J]` **物质条件决定议题的时点**：ILSVRC 提供了可比性，GPU/CUDA 提供了可行性，产业实验室（Google Brain/Mind、OpenAI、FAIR/MSRA）提供了人力与算力管道。同一套算法在 2000 年无法成为"议题"。
- `[J]` **"来时路"高度集中**：多伦多（Hinton）、蒙特利尔（Bengio）、牛津（Zisserman）、Google 系、MSRA→FAIR。这不是巧合，是**学术再生产**：问题集、评测习惯、工程文化沿师承与机构扩散。
- `[J]` 与 [[mesoscale-ml-report]] 的假说 H 对读：本史给出的**每次跃迁都伴随一次内容侧或结构侧的重新粒化**；而**同层内的规模/优化改进**（Adam、Chinchilla）同样决定性——H 的强读法不成立，弱读法成立。

## 1. 前史：为 2012 准备的四个构件（1943–2011）

| 构件 | 学者来时路 | 关注点 | 背景知识 |
|------|-----------|--------|---------|
| **反向传播**（1986）`10.1038/323533a0` | Rumelhart / Hinton / Williams，联结主义传统（PDP 小组） | 多层网络的信用分配 | 链式法则、感知机（1969 的 XOR 批评） |
| **卷积网络 LeNet**（1998）`10.1109/5.726791` | Yann LeCun，贝尔实验室 → 纽约大学 | 手写数字识别，权重共享降参数量 | 反向传播、视觉皮层局部感受野（Hubel–Wiesel） |
| **LSTM**（1997）`10.1162/neco.1997.9.8.1735` | Hochreiter（Diplom, Munich）与 Schmidhuber | 梯度消失 → 门控记忆 | RNN、BPTT、常数误差流（constant error carousel） |
| **深度信念网 / 逐层预训练**（2006）`10.1162/neco.2006.18.7.1527` | Hinton（多伦多）、Osindero、Teh | 深网难训 → 无监督逐层初始化 | RBM、对比散度、统计物理出身 |

`[J]` 辩证位：此阶段**算法已齐备但议题不存在**——因为没有**能判定胜负的公共评测**，也没有**能承载深度的硬件**。深度学习在 1990s–2000s 的"失败"不是理论失败，是**再生产条件不足**。

`[F]` **ImageNet / ILSVRC**（`10.48550/arxiv.1409.0575`）由李飞飞等在普林斯顿/斯坦福构建：把"视觉识别"从各自为政的小数据集变成**单一可比榜单**。`[J]` 这就是 2012 年爆发的前置物质条件。

## 2. 第一拍（2012–2017）：把"深"变成可行

### N1 · AlexNet（2012）`10.1145/3065386`
- **学者的来时路** `[F]` Alex Krizhevsky（乌克兰出生、加拿大长大，Hinton 学生，**CIFAR-10/100 数据集**作者）与 Ilya Sutskever（多伦多数学荣誉学位 2005 → Hinton 门下 MS/PhD，论文研究循环网络；此前在斯坦福 Andrew Ng 组做研究学生）。三人成立 **DNNresearch**，2013 年 3 月被 Google 收购。
- **关注点** `[F]` 把 ILSVRC 的分类错误率压下去；工程上必须用 **2 块 GTX 580** 拆模型才放得进显存——**关注点是"能跑起来"，不是"更优雅"**。
- **依赖的背景知识** `[F]` 反向传播(1986)、卷积结构(1998)、ReLU、**Dropout**(2012 同组，`10.48550/arxiv.1207.0580`)、ImageNet 数据、CUDA 通用 GPU 计算。
- **辩证位** `[J]` 算法无新意，**新的是把大数据 + GPU + 深网同时摆上一台机器**；评测榜单把"经验"变成"可比的胜负"。

### N2 · VGG（2014）`10.48550/arxiv.1409.1556`
- **学者的来时路** `[F]` Karen Simonyan 与 Andrew Zisserman，**牛津 VGG**（Zisserman 的多视图几何/视觉识别传统）→ 后被 Google DeepMind 吸收。
- **关注点** `[F]` 只堆 **3×3 卷积**能走多深：均匀构型、极简规则。
- **背景知识** `[F]` AlexNet、ILSVRC、迁移特征（VGG 特征被大量复用）。
- **辩证位** `[J]` 把"深度"变成**唯一可调变量**，为后续深度竞赛设定了坐标系。

### N3 · GoogLeNet / Inception（2014）`10.48550/arxiv.1409.4842`
- **学者的来时路** `[F]` Christian Szegedy 等，**Google**（Szegedy 数学博士，Bonn/GMD 背景，OpenAlex 记录其 Google 任职 2013–2022）。
- **关注点** `[F]` 在**固定算力预算**内同时加深加宽：Inception 模块 + 1×1 卷积降维。
- **背景知识** `[F]` AlexNet、LeNet、NiN 的 1×1 卷积思想。
- **辩证位** `[J]` **算力约束直接塑造结构**——Inception 是可预算化的模块化，而非美学选择。

### N4 · GAN（2014）`10.48550/arxiv.1406.2661`
- **学者的来时路** `[F]` Ian Goodfellow，蒙特利尔（Bengio 组）读博期间，此前 Stanford（OpenAlex 记其 Université de Montréal 2011–2014、Google 2013–2024、OpenAI 2016–2017）。
- **关注点** `[F]` 绕过"似然函数不可解/配分函数不可算"，用**判别器**提供一个替代信号。
- **背景知识** `[F]` minimax 博弈、反向传播、RBM/DBM 的生成传统、Dropout 时代的训练经验。
- **辩证位** `[J]` 生成建模的目标从"能分类"变为"能造"；**矛盾=不可解似然**，**构件=对抗信号**。

### N5 · word2vec 与子词（2013 / 2015）`10.48550/arxiv.1301.3781`、`10.48550/arxiv.1508.07909`
- **学者的来时路** `[F]` Tomáš Mikolov（Brno 理工博士 2008–2013，MSRA/Google）；BPE 子词来自爱丁堡（Sennrich/Haddow/Birch）。
- **关注点** `[F]` 让词表示**可算且高效**（skip-gram/CBOW），并解决**开放词表**。
- **背景知识** `[F]` 神经语言模型（Bengio 2003）、分布假设、LSTM、统计 NLP 传统。
- **辩证位** `[J]` **内容侧粒化**的两次动作：离散符号→连续向量；整词→子词。

### N6 · seq2seq 与注意力（2014）`10.48550/arxiv.1409.3215`、`10.48550/arxiv.1409.0473`
- **学者的来时路** `[F]` Sutskever/Vinyals/Le（Google）；Bahdanau/Cho/Bengio（蒙特利尔）。
- **关注点** `[F]` 变长序列映射；**定长隐向量的瓶颈**（长句性能骤降）→ 可微对齐。
- **背景知识** `[F]` LSTM(1997)、word2vec(2013)、统计机器翻译。
- **辩证位** `[J]` 瓶颈 → 注意力；**这一个构件就是 Transformer 的直接前身**。

### N7 · 可训练性的管道件（2014–2016）`10.48550/arxiv.1412.6980`、`10.48550/arxiv.1502.03167`、`10.48550/arxiv.1607.06450`
- **学者的来时路** `[F]` Adam：Kingma & Ba（阿姆斯特丹/多伦多—DeepMind 系）；BatchNorm：Ioffe & Szegedy（Google）；LayerNorm：Ba/Kiros/Hinton（多伦多）。
- **关注点** `[F]` 更深网络为何训不动：内部协变量偏移、逐层尺度、步长自适应。
- **背景知识** `[F]` SGD/momentum、初始化难题、Dropout、RBM 时代经验。
- **辩证位** `[J]` 这些是**前提件而非亮点**：没有它们，ResNet 的深度在实践中无法稳定堆叠。

### N8 · ResNet（2015）`10.48550/arxiv.1512.03385`
- **学者的来时路** `[F]` 何恺明：清华本科 → 香港中文大学 MPhil（OpenAlex 记 2009–2011）→ **MSRA**（2012–2016）→ **FAIR**（2016–2022）；后续转入 MIT `[INFERENCE]`（OpenAlex 记录被消歧噪声污染，未采信）。
- **关注点** `[F]` **深度退化**——"更深的网络反而更差"（非过拟合）。
- **背景知识** `[F]` VGG/GoogLeNet 的深度竞赛、BatchNorm(2015)、ILSVRC 评测。
- **辩证位** `[J]` 解法不是加大容量，而是**改归纳偏置**（恒等捷径让"多余层"可退化为恒等）——典型的"换构件而非换规模"。

### N9 · AlphaGo / AlphaGo Zero（2016 / 2017）`10.1038/nature16961`、`10.1038/nature24270`
- **学者的来时路** `[F]` DeepMind（2010 成立，2014 被 Google 收购），Hassabis、Silver 等；Sutskever 亦为合著者（Google Brain 时期）。
- **关注点** `[F]` 用 CNN + 树搜索 + 强化学习**取代人工特征与启发式**；Zero 版进一步**去掉人类棋谱**。
- **背景知识** `[F]` CNN、Q 学习/策略梯度、MCTS、GPU 集群。
- **辩证位** `[J]` **数据来源的辩证反转**：从"依赖标注数据"转为"自我对弈自造数据"。

## 3. 第二拍（2017–2022）：把"并行与规模"变成议题

### N10 · 稀疏门控 MoE（2017）`10.48550/arxiv.1701.06538`
- **学者的来时路** `[F]` Noam Shazeer 等（Google Brain；Shazeer 亦是 Transformer 合著者）。
- **关注点** `[F]` 参数规模上去了但每样本只激活少数专家 → 用**条件计算**切断"算力随参数量线性增长"。
- **依赖的背景知识** `[F]` 集成学习、LSTM、GPU/TPU 上的稀疏算子实现。
- **辩证位** `[J]` **容量与计算量解耦**——这是后来一切 MoE 的原型。

### N11 · Transformer（2017）`10.48550/arxiv.1706.03762`
- **学者的来时路** `[F]` Ashish Vaswani（USC 博士 2007–2017 → Google；OpenAlex 记 Google 2016–2025），合著者来自 Google Brain / Google Translate。
- **关注点** `[F]` 去掉循环与卷积，用自注意力**并行化**训练；同时提升翻译质量与吞吐。
- **依赖的背景知识** `[F]` attention(2014)、seq2seq、BPE 子词、LayerNorm、残差连接、TPU（2016 起 Google 内部部署）与翻译数据/服务规模。
- **辩证位** `[J]` 主动**放弃时序局部性**这一强归纳偏置，换取并行与规模 → 一切后续规模化的先决条件。

### N12 · 预训练范式统一（2018–2019）`10.48550/arxiv.1810.04805`、`10.48550/arxiv.1910.10683`
- **学者的来时路** `[F]` BERT：Jacob Devlin 等（Google）；T5：Raffel 等（Google）；GPT-2：Alec Radford 等（OpenAI，**无 arXiv 记录**）。
- **关注点** `[F]` BERT——双向上下文 + 掩码语言模型，预训练-微调；T5——**系统对比目标函数**，把一切任务统一为"文本→文本"；GPT-2——零样本迁移。
- **依赖的背景知识** `[F]` Transformer、BPE、word2vec 式预训练、WebText 级语料。
- **辩证位** `[J]` **任务边界瓦解**：内容侧粒化统一到 token 级，任务退化为条件。

### N13 · 稀疏注意力（2019）`10.48550/arxiv.1904.10509`
- **学者的来时路** `[F]` Rewon Child、Scott Gray 等（OpenAI）。
- **关注点** `[F]` 注意力 O(n²) 在长序列上不可承受 → 结构化稀疏模式。
- **依赖的背景知识** `[F]` Transformer、稀疏矩阵、GPU 内存层级。
- **辩证位** `[J]` 第一次把**计算复杂度本身**当成议题，而非实现细节。

### N14 · GPT-3 与 Scaling Laws（2020）`10.48550/arxiv.2005.14165`、`10.48550/arxiv.2001.08361`
- **学者的来时路** `[F]` Tom Brown 等（OpenAI）；Jared Kaplan 等（OpenAI，物理背景）。
- **关注点** `[F]` 把"规模"从资源变成**方法**：幂律可预测性 + 上下文内学习（ICL）。
- **依赖的背景知识** `[F]` Transformer、稀疏注意力、大规模分布式训练、BPE。
- **辩证位** `[J]` 议题从"能不能训"变为"能不能扩"；同时埋下"涌现"争议（§4.5）。

### N15 · ViT 与 MAE（2020 / 2021）`10.48550/arxiv.2010.11929`、`10.48550/arxiv.2111.06377`
- **学者的来时路** `[F]` Dosovitskiy 等（Google Brain）；何恺明等（FAIR）。
- **关注点** `[F]` ViT——图像是否仍需要卷积的局部性先验；MAE——掩码重建能否用于视觉自监督。
- **依赖的背景知识** `[F]` Transformer 的规模化成功、BERT 的掩码目标、超大规模数据（JFT-300M）。
- **辩证位** `[J]` **内容侧粒化最纯粹的案例**：图像被切成 16×16 patch 当 token。

### N16 · CLIP（2021）`10.48550/arxiv.2103.00020`
- **学者的来时路** `[F]` Alec Radford 等（OpenAI）。
- **关注点** `[F]` 用自然语言替代固定类别标签作监督 → 零样本分类。
- **依赖的背景知识** `[F]` 对比学习（SimCLR 系）、Transformer、4 亿图文对。
- **辩证位** `[J]` **监督信号被粒化**：从"标签"到"语言"。

### N17 · 扩散模型（2015 → 2019 → 2020）`10.48550/arxiv.1503.03585`、`10.48550/arxiv.1907.05600`、`10.48550/arxiv.2006.11239`
- **学者的来时路** `[F]` Sohl-Dickstein（Berkeley/Stanford 的物理—ML 交叉背景）；Yang Song（Stanford，Ermon 组）；Jonathan Ho（Berkeley，Abbeel 组，此前 Stanford）。
- **关注点** `[F]` 用非平衡热力学/去噪目标，替代对抗训练的不稳定。
- **依赖的背景知识** `[F]` 变分推断、score matching、U-Net、热力学类比。
- **辩证位** `[J]` GAN 的矛盾（不稳定、模式崩溃）→ 回归稳定目标 → 生成质量与规模兼得。

### N18 · MoE 复兴（2021–2024）`10.48550/arxiv.2101.03961`、`10.48550/arxiv.2401.04088`、`10.48550/arxiv.2412.19437`
- **学者的来时路** `[F]` Fedus/Zoph/Shazeer（Google，Switch Transformer）；Mistral（Mixtral）；DeepSeek（DeepSeek-V3）。
- **关注点** `[F]` 在**推理成本受限**下继续扩参数。
- **依赖的背景知识** `[F]` 稀疏 MoE(2017)、分布式训练、推理服务成本结构。
- **辩证位** `[J]` **效率成为议题**（见 §4.6、§5 链 4）。

### N19 · CoT 与 RLHF（2022）`10.48550/arxiv.2201.11903`、`10.48550/arxiv.2203.02155`
- **学者的来时路** `[F]` Jason Wei 等（Google Brain）；Long Ouyang 等（OpenAI）。
- **关注点** `[F]` CoT——让推理**显式化**（中间步成为 token）；RLHF——把人类偏好变成训练信号。
- **依赖的背景知识** `[F]` 规模化 LLM、ICL、强化学习（PPO）、人类标注的组织能力。
- **辩证位** `[J]` **"思维"被粒化**；对齐从规则系统变为统计偏好拟合。

### N20 · 推理模型与 Agent（2023–2025）`10.48550/arxiv.2501.12948`、`10.48550/arxiv.2305.20050`、`10.48550/arxiv.2308.11432`、`10.48550/arxiv.2309.07864`
- **学者的来时路** `[F]` DeepSeek（中国产业实验室）；Lightman 等（OpenAI）；Wang 等 / Xi 等（高校为主）。
- **关注点** `[F]` 用**可验证奖励 + 长思维链**训练推理；把 LLM 变成会调用工具、持有多步状态的可执行体。
- **依赖的背景知识** `[F]` CoT、RLHF、过程奖励模型（PRM）、工具 API 生态。
- **辩证位** `[J]` 从"预测下一个 token"转向"按步骤求可验证结果"——**推理本身成为可优化对象**。

## 4. 各领域前沿（2023–2026，每段 ≥1 条可解析引用）

### 4.1 CV `10.48550/arxiv.2304.02643`、`10.48550/arxiv.2304.07193`
SAM 把"分割"变成**提示式通用任务**（点/框/文本提示即出掩码）；DINOv2 证明**无监督特征**可与弱监督比肩。趋势：从"任务专用模型"转向"通用骨干 + 提示/适配"。
`[F]` 注意：OpenAlex 把该文的标题错挂为 "Micrograph segmentations for DDEVD"，真实标题为 "Segment Anything"——**必须用 arXiv 复核**。

### 4.2 NLP·LLM `10.48550/arxiv.2303.18223`、`10.48550/arxiv.2303.08774`、`10.48550/arxiv.2312.10997`
LLM 综述给出规模化范式全图；GPT-4 技术报告**不公开方法细节**，本身标志"能力报告"文体的转折；RAG 综述把外部知识粒化为可检索 chunk。

### 4.3 生成模型 `10.48550/arxiv.2307.01952`、`10.48550/arxiv.2209.00796`、`10.48550/arxiv.2210.02747`
SDXL（潜空间扩散的工程化）、扩散综述（方法谱系）、Flow Matching（用向量场/ODE 视角统一扩散与流）。

### 4.4 多模态 `10.48550/arxiv.2306.13549`
多模态 LLM 综述：视觉编码器 + 投影层 + LLM 的"三段式"成为主流；模态边界被拉平到同一 token 层。

### 4.5 强化学习与推理 `10.48550/arxiv.2501.12948`、`10.48550/arxiv.2305.20050`、`10.48550/arxiv.2206.07682`、`10.48550/arxiv.2304.15004`
R1 用 RL 激发长链推理；"Let's Verify Step by Step" 用**过程监督**验证推理步；"涌现能力"（2022）与其"海市蜃楼"反驳（2023）构成一场**关于"宏观层是否存在新定律"的公开辩证**。

### 4.6 系统与效率 `10.48550/arxiv.2205.14135`、`10.48550/arxiv.2312.00752`、`10.48550/arxiv.2412.19437`
FlashAttention（IO 感知的精确注意力）、Mamba（选择性状态空间，线性时间）、DeepSeek-V3（MLA + 无辅助损失的负载均衡 MoE 工程）。

### 4.7 具身与世界模型 `10.48550/arxiv.2307.15818`、`10.48550/arxiv.2406.09246`、`10.48550/arxiv.2402.15391`
RT-2 把 VLM 直接当 VLA 控制器；OpenVLA 开源复现；Genie 从视频生成**可交互环境**。趋势：**动作与环境被粒化为可学习构件**。

## 5. 辩证分析：物质条件 → 议题转向（4 条因果链）

**链 1｜算力物质条件 → "深"从理论可能变为工程可行** `[F]`
证据：AlexNet 必须**两块 GTX 580** 拆分才放得下（`10.1145/3065386`）；ImageNet 提供了够大的训练集（`10.48550/arxiv.1409.0575`）。`[J]` 议题因此从"该不该用神经网络"转为"能堆多深"（`10.48550/arxiv.1409.1556`、`10.48550/arxiv.1512.03385`）。

**链 2｜公共评测 → 竞争性议题的生产** `[F]`
ILSVRC 把视觉识别变成**单一可比榜单**（`10.48550/arxiv.1409.0575`），使"谁更好"可判定。`[J]` 2012–2015 的结构竞赛（AlexNet→VGG→GoogLeNet→ResNet）是被**度量装置**催生的，而非纯粹智力竞赛。

**链 3｜产业实验室与组织形式 → 议题从"训得动"转为"扩得起"** `[F]`
DNNresearch 2013 年被 Google 收购，把学术明星转为产业军团（Sutskever 后续主导 seq2seq 与 AlphaGo 工作，再共同创办 OpenAI）。`[J]` Google Brain/DeepMind/OpenAI/FAIR/MSRA 集中了算力与数据——Transformer 的 8 位作者同属 Google 系（`10.48550/arxiv.1706.03762`）；OpenAI 随后用 Scaling Laws 与 GPT-3 把"规模"确立为方法（`10.48550/arxiv.2001.08361`、`10.48550/arxiv.2005.14165`）。

**链 4｜推理成本与上下文长度 → 效率议程** `[F]`
注意力 O(n²) 与长上下文成本，使"复杂度/内存"从实现细节升为研究主题：稀疏注意力(2019)（`10.48550/arxiv.1904.10509`）→ FlashAttention(2022)（`10.48550/arxiv.2205.14135`）→ Mamba(2023)（`10.48550/arxiv.2312.00752`）→ MoE 工程化（`10.48550/arxiv.2412.19437`）。
