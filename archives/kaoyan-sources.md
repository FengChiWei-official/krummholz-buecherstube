# 考研11408 信源地图与人机分工

## 说明

本文件记录考研11408决策调研中涉及的所有信源的**可达性、信息类型、AI可提取程度、必须用户亲自读的部分**。所有可达性测试执行于 2026-09-03，以 curl HEAD/GET 为主，辅以适当 User-Agent 模拟浏览器。

**原则**：AI做机器可提取的；剩余交给用户并附入口+阅读重点+可信度折扣。

## 五、技术注意事项

### 5.1 反爬与访问策略

| 站点 | 反爬措施 | 应对策略 |
|------|---------|---------|
| 研招网 | acw_tc cookie, XSRF token | 可用 curl + cookie jar 维持会话 |
| CCF 官网 | 403 对深层路径 | 尝试缓存/Bing 缓存 |
| NSFC | 403 对大部分路径 | 尝试 Bing `site:` 查询，或通过高校科技处页面间接获取 |
| 知乎 | BLB 反爬 | 需要浏览器 UA + 合理的请求间隔 |
| 小红书 | openresty 反爬 + JS 渲染 | 浏览器驱动 |
| 一亩三分地 | Cloudflare | 用户自己访问 |
| 牛客 | SPA JS 渲染 | 浏览器驱动或 API 抓包 |

### 5.2 编码注意事项

- 小木虫使用 **GBK** 编码
- 研招网使用 **UTF-8**
- Bing 中文搜索需要 URL encode 关键词 + `setlang=zh-cn` header

### 5.3 数据时效标注

所有从上述站点提取的硬数据，必须标注**提取日期**（2026-09-03）。各站数据更新频率：
- 研招网：年度更新（考研季 9-10 月最新）
- 新东方：滞后约 1 年
- 大学官网：复试季更新（3-4 月）
- OpenAlex：持续更新，论文元数据约滞后 3-6 个月
- arXiv 统计：月度更新
- NSFC：年度更新（3 月指南，8 月立项公布）
- 论坛内容：实时，但需标注帖子日期
