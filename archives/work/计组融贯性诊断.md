# 计组融贯性诊断

学完 408 计组考纲一个月后，能回忆的是各章相对重要的知识点，无法串联。诊断：不是记忆问题，是编码结构问题，而编码结构被考纲的组织方式决定。

## 诊断

1. **考纲是空间分类学，机器是时间过程。** 七章按部件组织（部件=章）。全机唯一的动态对象——冯·诺依曼循环（取指-译码-执行，指令与数据同存）——只在第一章作为两个名词出现（存储程序方式、程序和指令的执行过程），此后六章再未回来充当组织框架。编码索引 = 章节位置，一个月后按索引检索，返回的自然是每章若干热点。串联需要时间序结构，而考纲从未提供任何可检索的时间序对象。
2. **记住的是各章的答案，考纲从不给出各章的问题。** 每个子系统是对一个量化张力的被迫回答：Cache ← CPU 比主存快约两个量级；补码 ← ALU 只想会加法；中断/DMA ← 外设慢约六个量级；流水线 ← 单周期实现浪费硬件。答案离开问题无法连边，而问题恰恰跨章重复：快慢两方如何对话，在 Cache、虚拟存储、总线仲裁、中断、DMA 五处得到同构回答。考纲把这些问题拆散为各章「参考问题」，于是学习者从未有机会发现它们是同一个问题。
3. **检索结构是编码结构的诚实回放。** 「能回忆相对重要的知识点」说明编码时的 retrieval cue =（章节，考频权重），即 checklist 模式；checklist 不生成跨章边。整理后的考纲笔记本身即证据：每章内部结构良好，章间零结构，忠实复刻了症状。

## 三角度评估

- **洋葱（层次+边界+API）**：对三分之一。真正嵌套的只有翻译栈（高级→汇编→机器）与 ISA——全学科唯一的真 API：ch4 是 API 的定义，ch5 是 API 的一种实现，ch2 是 API 的数据语义，ch3 是 API 之下最大的性能合同。但 CPU–内存边界不是 API 边界：存储层次不是洋葱层（不是封装与委托），而是同一权衡（快↔贵↔小）的逐级重复；把洋葱套满全图会强加错误结构。
- **目的论**：最强，与材料同构。计组里没有「本来就有的东西」，每件都是被迫回答，且所有张力收敛到四个根张力：速率差（→层次/异步/搬运）、复用与代价（→编码让一种电路干所有活）、通用性（→控制变成数据）、异步与差错边界（→校验/中断/仲裁）。目的论同时给出「是什么」与「为什么在这个位置」。
- **代数（运行模式抽象，具体=抽象的组合与实现）**：目的论的压缩机制，且是该学科自身的压缩方式：补码=选好编码，加法器就会减法；流水线=空间并行改时间复用；微程序控制器=一个小冯·诺依曼机控制一个大冯·诺依曼机；Cache 与虚拟存储=同一剧本演两遍（小的快的替大的慢的演戏，靠局部性+按需搬运）。不变量=可多次实例化的模式。

## 推荐结构：一个主轴，两个补充

**主轴（目的论的实例化）= 一条指令的一生。** 不是概念图，是叙事。从 `a = b + c`（带一个 `if` 跳转更佳，会经过控制相关）出发：

编译器：寄存器分配、机器级表示（ch4）→ 取指：PC→虚拟地址→TLB/页表→物理地址→iCache→主存，缺失向下逐级按需搬运（ch3/ch5 指令周期）→ 译码：操作码/地址码、寻址方式算 EA（ch4）→ 取操作数：dCache 同一套流程（ch3）→ 执行：补码加法、标志位在 ALU 生成（ch2，供 ch4 条件跳转用）→ 写回：写策略（ch3）→ 下一条：流水线重叠、数据冒险转发/停顿、控制冒险分支预测（ch5）→ 每条指令末尾的中断检查点（ch5 异常/中断）→ 长时间后 dirty page 落盘：DMA、总线仲裁、磁盘（ch6/ch7）。

七章 = 这条线上的七个工位，每章恰好回答主线提出的一个问题（ch3：为什么取数慢却感觉不到；ch6/ch7：快慢两方怎么握手）。给每章在主线上挂一行：它回答什么问题。

**边界（洋葱的正确用法）— 三个真合同：** ① ISA：软硬件 API，违约=非法指令；② 存储层次合同：透明性，CPU 不知道 Cache 存在，该层全部内容=维护假象的成本；③ 总线/中断协议：异步双方握手规则。每个边界问两问：谁对谁透明？违约走什么流程？（缺失与中断都是「违约」的统一处理：暂停主线、委托慢的一方、回来续上。）

**不变量（代数的正确用法）— 六个跨章不变量，每学一物登记「第几次实例化」：**

1. 一切运算归约为加法+移位（补码减法、乘除迭代、移码让阶码比较变成加法、标志位生成）
2. 快慢两方互联的统一解 = 分层+缓存+按需异步搬运（Cache、虚拟存储、中断、DMA、总线仲裁——五次实例化）
3. 控制即数据（指令存在存储器、微程序、流水线冒险调度：机器调度机器）
4. 透明性 = 每层维护一个假象，维护成本=该层全部内容（Cache 假装主存快、虚存假装地址无限、流水线假装 CPI=1）
5. 表示先于电路（补码/移码/IEEE 754、指令编码与操作码扩展、对齐/大小端）
6. 时空互换（流水线=空间并行→时间复用、交叉存储=时间并行、block 大小=命中率 vs 失配代价）

## 操作协议

1. 一张纸画主线，七章挂工位（产出：一张图，每章一行）。
2. 讲述测试：合上书，从 `a=b+c` 讲到磁盘上的字节，20 分钟。卡壳处=真正缺的边；只补那条边，不重读整章。这直接攻击症状：强迫按时间序而非章节检索。
3. 不变量登记：每个新知识点问「这是哪个不变量的第几次实例化」（学 DMA 时认出它是模式 2 的第四次出现，即完成一次跨章连边）。
4. 考纲里现成的「待解问题」就是 integrative 试卷：它们大多是边问题（指令/数据区分=同一总线不同时刻；CPU 响应中断的条件=两个自治系统的握手；向量中断/中断向量/向量地址=一条边上的三个词）。答它们必须走线，答不了章。

## 与库的接口

本库（原子卡+链接）本身就是答案的形状：按关系组织而非按目录组织。计组主线图的最终形态应是一张 `Links of 一条指令的一生` 类笔记——意义级动作，须 owner 批准。

## 复习任务规划（T-9 周；2026-10-24 裁决后）

> **本规划是粗糙臆测，不是契约**（owner，2026-10-24：「那只是粗糙的臆测，要用实践去不断的修改」）。它的唯一作用：让第一轮实践有形状。四段、粒度闸门、挂点检查、C1–C4、9 周，全部可被实践推翻——**冲突时改规划，不改实践**。判据是「融贯出现时能被看见」的方式，不是考核指标。

初试 12 月第 4 个周末（据报名窗口 2026-10 推得 2026-12-26/27），距今约 9 周。

**裁决（owner，2026-10-24）**：组织轴不再是「一条指令的一生」——单一模板第一僵化、第二信息量过大，把握不了。改为**整体层优先**：先把握计算机的核心系统与软硬件交互界面；不变量与「目标-本质」（根张力）绑定。`一条指令的一生` 降为穿越校验 drill，不再承担组织职责。

**粒度闸门（治「太多」）**：整体层只收四类节点——**层、合同、根张力、不变量**。算法与参数细节（Cache 映射方式、替换算法、中断向量表、地址位数…）一律挡在闸门外，归章内下钻。

**三层结构：**

1. **底图（已有）**：`[[How does PC system work]]` 四层——硬件层 / 操作系统层 / 用户界面 / 用户层。
2. **硬件层展开（核心系统）**：按四个根张力生成部件，不按章列举——速率差 → 存储层次与异步搬运；复用与代价 → 编码与运算部件；通用性 → 控制（指令 / 微程序）；异步与差错边界 → 总线与 I/O 握手。
3. **三个真合同标在边界上**（洋葱的正确用法，§三角度）：① ISA：硬件 ↔ OS 的 API，违约 = 非法指令；② 存储层次合同：透明性，该层全部内容 = 维护假象的成本；③ 总线 / 中断协议：异步双方的握手规则。每合同两问：**谁对谁透明？违约走什么流程？**（缺失与中断同属「违约」处理：暂停主线、委托慢的一方、回来续上。）

**不变量 ↔ 根张力（草稿，待你定稿）**：根张力是「目标-本质」，不变量是它在电路 / 协议上的压缩式答案。

| 不变量 | 根张力 | 本质 |
|---|---|---|
| 1 一切运算归约为加法 + 移位 | 复用与代价 | 一种电路干所有活 |
| 2 分层 + 缓存 + 按需异步搬运 | 速率差 | 快慢两方如何对话（5 次实例化）|
| 3 控制即数据 | 通用性 | 一套硬件跑任意程序 |
| 4 透明性 = 维护假象 | 速率差 + 复用与代价 | 层次合同的成本面 |
| 5 表示先于电路 | 复用与代价 | 选好编码，电路就少 |
| 6 时空互换 | 速率差 + 复用与代价 | 用空间买时间，或反之 |

**缺口（请你裁）**：四个根张力中，第 4 个（异步与差错边界）在六个不变量里**没有对应项**——它的答案形态是协议（握手 / 校验 / 中断），由合同 ③ 承载。即张力 1–3 由不变量承载、张力 4 由合同 ③ 承载；「四张力 ↔ 六不变量 + 一合同」是否齐备，属你的判断。

**四段：**

| 段 | 时点 | 动作 | 闸门 |
|---|---|---|---|
| 0 整体层 | 本周 | 底图四层 → 硬件层展开 → 三合同标边 → 四张力标注（≤10 张卡）| 每张卡必须答得出「它回答哪个根张力」 |
| 1 绑定 | 同周 | 上表定稿（最后一列你写）| 每个不变量有根张力；张力 4 归合同 ③ |

| 3 穿越校验 | 每周 2 轮 | 讲述测试 20 min（`a=b+c` → 磁盘，时间序）+ 待解问题抽 3 题 | 卡壳数逐轮降 → 0；首句是章节号即判负 |

**判据**：C1 穿越校验卡壳数 → 0；C2 六不变量各认出 ≥2 次实例、不变量 2 认全 5 次（Cache / 虚存 / 中断 / DMA / 总线仲裁）；C3 待解问题每题跨 ≥2 章走线；C4 随机抽 Node 30 秒内说出它挂在整体层哪个部件 / 合同 + 回答哪个张力。

**节律**：校验放每次复习开头（先讲后学）；不变量登记不另立时段——捕获时顺手问「这是哪个张力的第几次实例化」；每周问箱（S9）优先抽计组 Node，跨章边固化成 Links 卡（终态 `Links of 一条指令的一生`，须你批准）。

**库的现状（本次核对）**：计组概念 Node 为零——`Cache` / `总线` / `流水线` / `ISA` / `补码` / `中断` / `DMA` 全无，Raw Index 有网络与数据结构、无计组；计组侧只有本诊断与 `[[计算机组成考纲]]`。故整体层只能靠**写卡**产出，画图不产生库结构。

## 人机协议（2026-10-24 二次裁决：苏格拉底式）

**裁决（owner，2026-10-24）**：「我现在肯定没有融贯的能量」——模式改为：**你提问 → AI 回答以辅助思考 → 你独立下结论 → AI 反驳/指导 → 结论入卡**。AI 的回答是暂定命题，不是结论；结论永远由你说出。

**三条硬机制**（防止退化成 AI 讲课）：

1. **答必带边界**：AI 每个回答必须附一条「它在什么情况下不成立」。没有边界的回答不许出口——这把叙述改造成待检验的命题。
2. **结论由你说，一句话**：AI 不代写结论。一句话才可被下一轮攻击；说不成句 = 还没想清。
3. **每轮以 elenchus 收尾**：AI 必须给出最强反例或矛盾，不给「对」。找不到反例 → 该结论登记为**暂立**，入卡。

**一轮的节奏**：你问 → AI 答（带边界）→ 你下结论 → AI 反驳 → 你修订并登记。**每轮至少产出一条你自己的结论**；没产出 = 这一轮只是聊天。

**卡壳（aporia）是信号，不是失败**：卡壳 = 缺边。AI 不许填，只许缩小范围——给 2–3 条候选边，你选。

**结论卡**：每条结论一张卡（你的话）+ 挂点（整体层哪个部件 / 合同）+ 张力 + 不变量第几次实例化。融贯只有这一条生长路径：结论累积 → 边累积 → 体系。段 0（整体层）与段 2（章内下钻）的推进方式就是苏格拉底轮。

**与旧亮线的关系**：旧亮线（AI 不叙述）在**校验环节**仍然有效——讲述测试必须你讲，AI 只记卡壳。新协议放开的是**提问环节**。故成本比改为：**提问环节 1:1，校验环节 20:1**（你 20 分钟、AI 1 分钟）。同一理由不变：校验是检索训练，提问是编码辅助。

**校验环节 AI 职责照旧**：当听众（计时、只记卡壳位置）、挂点质问、出题与判定（走线 / 跨章）、盲抽定位、候选链接（S2 给 3 个 + why，你选）。

**AI 始终不做**：不写卡片正文；不画整体图；不给最终结论；不把散文落进 `library/`（AI 散文只进 `a_sticker/or/`）。
