# 计组融贯 — 切入口与外部资源

> AI 调研备忘（2026-10-24）。用途：为「整体层 + 感性了解」找一个切入口；附学习科学的实证依据。资源链接在文内，可直达。

## 一、结论先行：第一切入口

**Gustavo Duarte《Software Illustrated》系列中的 6 篇，按「开机 → 内核 → 第一个进程 → 一次中断」顺序读一遍**（合计约 1–2 小时，无代码负担，纯叙事 + 图）。

四条理由：① 它就是你提的那条链；② 它是叙事（感性），不是分类学；③ 它把你的「距离」结论直接**量化**；④ 概念与 408 考纲一一对应（复位矢量、实模式/保护模式、GDT/IDT、分页、特权环、IRQ→向量→IDT）。

| # | 篇 | 给什么 |
|---|---|---|
| 1 | [Motherboard chipsets and memory map](https://manybutfinite.com/post/motherboard-chipsets-memory-map) | 整体层底图：CPU/北桥/南桥、地址空间怎么分 |
| 2 | [How Computers Boot Up](https://manybutfinite.com/post/how-computers-boot-up/) | 复位 → POST → MBR → bootloader（你提的「按默契运行特殊位置的指令」）|
| 3 | [The Kernel Boot Process](https://manybutfinite.com/post/kernel-boot-process/) | 内核自举：实模式→保护模式、GDT/IDT、建页表、开分页 |
| 4 | [When Does Your OS Run?](https://manybutfinite.com/post/when-does-your-os-run/) | **中断**：IRQ → 向量(0–255) → IDT → ring 0 处理程序——即「OS 何时在运行」|
| 5 | [CPU Rings, Privilege, and Protection](https://manybutfinite.com/post/cpu-rings-privilege-and-protection/) | 特权环/门描述符/栈切换 = OS 层存在的条件 |
| 6 | [What Your Computer Does While You Wait](https://manybutfinite.com/post/what-your-computer-does-while-you-wait/) | 「距离」的数字版（见下）|

第 6 篇的量化（原文办公室比喻）：L1 命中 ≈ 从桌上拿纸（3 s）、L2 ≈ 从旁边架子取书（14 s）、主存 ≈ 走 4 分钟去买糖、磁盘寻道 ≈ 离开大楼漫游**一年三个月**；主存延迟 ≈ 250 周期；一个时钟周期内光只走约 10 cm。同系列还有 [Anatomy of a Program in Memory](https://manybutfinite.com/post/anatomy-of-a-program-in-memory/)（进程地址空间 = 「运行一个进程」的那一半）、[Intel CPU Caches](https://manybutfinite.com/post/intel-cpu-caches/)、[How the Kernel Manages Your Memory](https://manybutfinite.com/post/how-the-kernel-manages-your-memory/)。

**边界**：2008 年 x86/BIOS 时代（Linux 2.6）。UEFI、NVMe 的细节已变，概念不变。**别拿它背实现细节，拿它建图像**；它也不覆盖 ch2（数据表示与运算）——那部分考纲自己解决。

## 二、第二层（要「实在」时）：xv6 —— 小到能读完的操作系统

MIT xv6（RISC-V，ANSI C）：Ch1 接口 / Ch2 OS 组织 / Ch3 页表 / Ch4 陷阱与系统调用 / Ch5 中断与设备驱动 / Ch6 锁 / Ch7 调度 / Ch8 文件系统。

为什么是它：**整台 OS 可以读完**；「运行一个进程 + 触发一次中断」在 Ch3–Ch5 有真代码可对照；RISC-V 干净，没有 x86 的历史包袱。

## 三、结构对照（正典命名）：CSAPP 第 1 章

*[A Tour of Computer Systems](https://csapp.cs.cmu.edu/public/ch1-preview.pdf)*（免费预览 PDF）：hello 程序的一生——位 + 上下文 → 编译系统四阶段 → 硬件组织（总线/IO/主存/CPU，PC/寄存器堆/ALU，load/store/operate/jump）→ 运行 hello（键盘 → DMA 载入 → 执行 → 显示）→ Cache（处理器-内存差）→ 内存层次（L0–L6，「每层是下一层的 cache」）→ OS 抽象（进程/虚存/文件）。

关键：原文明确写 *"a processor **appears to** operate according to a very simple instruction execution model, defined by its instruction set architecture"*，并区分 ISA 与微架构——**这正是你独立推出来的那条结论的正典表述**。

## 四、学习科学的实证（你这套做法有名字，也有证据）

| 你的做法 | 文献 | 结论 |
|---|---|---|
| 讲述测试 / 苏格拉底轮 | [Chi et al. 1994, *Eliciting self-explanations improves understanding*](https://doi.org/10.1016/0364-0213(94)90016-7) | 被要求自解说的学习者理解更深；**高产自解说者建立了正确的心理模型**，低产者多没有 |
| 卡壳是信号；别按当下流畅度判断 | [Bjork, *desirable difficulties*](https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/07/RBjork_inpress.pdf) | 让学习当下更难的操纵（间隔、交错、生成）提升延迟后的保持与迁移；**当下流畅 ≠ 长期学会** |
| 跨章走线（不按章）| [Richland, Bjork, Finley & Linn 2005](https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/07/Richland_RBjork_Finley_Linn_2005.pdf) | 分块练习利于单点回忆；**交错练习利于跨域整合与迁移** |
| 粒度闸门（「太多一定把握不了」）| Sweller 认知负荷（元素交互性）| 元素高度交互时工作记忆立刻过载；须减外在负荷、按「部分—整体」推进 |
| 图 + 讲述一起用 | 多媒体学习「连贯形成」（Mayer；信号 + 显式映射）| 只给信号收益有限；**信号 + 显式对应提示**才显著提升整合 |
| 整体层 + 章内细节两层 | [du Boulay 1986 *notional machine*](https://doi.org/10.2190/3lfx-9rrf-67t8-uvk9)；[Sorva 2013 综述](https://doi.org/10.1145/2483710.2483713) | 学习失败大多是 **notional machine 不完整**；它应被当作明确的学习目标；**允许多个不同抽象层级的 notional machine 并存** |

**最后一行单独看**：你这个问题有正式名字——**notional machine（观念机器）不完整**。Sorva 综述的结论「多个不同抽象层级的 notional machine 并存是正常且必要的」，正好支持你否掉单一模板、改走「整体层 + 章内下钻」两层。另外，Chi 那条说明：**心理模型是被自解说建起来的，不是被读来的**——这与诊断 §3 独立同构。

1. **它讲一条链，不讲一章**——叙事 > 分类学。
